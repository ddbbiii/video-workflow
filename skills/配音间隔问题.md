# 配音间隔与淡入淡出调整

## 适用场景

多段配音（如 TTS 朗读音频）之间存在过长静音、衔接生硬，或与画面、字幕不同步时使用。

## 操作步骤

1. **先确认音色**：最终视频或 SRT 开工前，先和用户明确本期使用的剪映音色及配速基准。未确认前不做最终时间轴定稿，除非用户明确授权跳过。
2. **获取实际朗读边界**：有最终 TTS 音频时，以波形和最新识别结果确定每段实际起止；若字幕稿与配音逐段对应，直接按原文核对，不为已知文本重复做整段识别。
3. **只裁多余静音**：每段开头、结尾只裁掉确认为静音的部分，留约 0.05–0.1 秒缓冲。保留句内换气、标点停顿和叙事留白；低音量不等于静音。
4. **压缩段间空隙**：将独立配音片段之间调整到约 0.2 秒。关闭不需要的磁吸/联动后，用波纹删除空隙，并让后续字幕和画面同步前移。不要压缩同一句内部的自然停顿。
5. **重新适配画面**：按配音完成后的总时间线调整镜头长度。只有画面自身明显拖沓时才整体变速；不要用加速画面掩盖配音片段之间的空白。
6. **试听与核对**：试听起音、收尾和多个段间衔接，确认没有吞字、断气、爆音或字幕错位；淡入淡出只在需要消除切音时使用。

## 已测音色基准

- `解说小帅`：约 4.60 可见字/秒有效语速。
- `晓辰学姐`：约 4.07 可见字/秒有效语速。
- 档案与测量依据见 `assets/shared/audio/`。有效语速用于未生成音频前估算；有实际 TTS 音轨时以音轨为准。

## 检查要点

- 修改前确认词级识别结果是最新的。
- 移动音频前确认吸附和联动已关闭，避免操作后片段弹回原位。
- 完成后试听片段起音、收尾和段间衔接，并核对字幕与配音是否同步。
- 根据问题根源选择处理方式：配音自带静音过长则裁剪和压缩间隔；画面本身拖沓则评估视频节奏。
