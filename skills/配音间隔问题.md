# 配音间隔与淡入淡出调整

## 适用场景

多段配音（如 TTS 朗读音频）之间存在过长静音、衔接生硬，或与画面、字幕不同步时使用。

## 操作步骤

1. **重新获取词级识别结果**：对全部配音片段做词级语音识别，确认每段第一个词和最后一个词的精确起止时间，据此计算首尾静音。识别结果可能过期，操作前必须重新获取。
2. **裁剪首尾静音**：按词级时间裁掉每段开头和结尾的静音，各保留约 0.05–0.1 秒缓冲，给淡入淡出留出空间。
3. **压缩段间间隔**：
   - **方案 A（推荐）**：先关闭时间线的主轨磁吸、自动吸附、联动，再将每段之间调整到约 0.3 秒。对音频轨和字幕轨的空隙做波纹删除，使字幕跟随配音前移并保持对应。
   - **方案 B（画面节奏拖沓时）**：先分析镜头运动、场景变化和氛围承受力，再考虑整体加快主视频（例如 1.2 倍），让画面时长匹配配音总长。不要把画面拖沓误判为配音静音问题。
4. **统一淡入淡出**：为所有配音设置约 0.2 秒的淡入和淡出，与裁剪时保留的缓冲相匹配。0.05 秒通常太短，听感改善不明显。

## 检查要点

- 修改前确认词级识别结果是最新的。
- 移动音频前确认吸附和联动已关闭，避免操作后片段弹回原位。
- 完成后试听片段起音、收尾和段间衔接，并核对字幕与配音是否同步。
- 根据问题根源选择处理方式：配音自带静音过长则裁剪和压缩间隔；画面本身拖沓则评估视频节奏。
