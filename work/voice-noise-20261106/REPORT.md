## 一、先把“杂音”排除掉

对成片旁白母带（`4/video/final/glacier-river_narration.wav`，35:28.7）、Hook 片头、208 条 TTS 原始件做实测：

| 检查项 | 结果 |
|---|---|
| 削波 | 0 个样本（峰值 −2.27 dBFS） |
| 直流偏置 | −3.7e−4，可忽略 |
| 交流声 50/60 Hz | 占比 < 0.007%，无 |
| 接缝爆音（313 个静音断点） | 断点前后样本 ≤ 0.002（−54 dBFS），无咔哒 |
| 静音段 | 精确数字零，没有底噪 |
| 6 kHz 以上能量 | 0.25% |

**结论：不是底噪、不是电流声、不是爆音。** 你听到的“机器味”来自生成端的气声与拉伸伪影。

## 二、真凶：2026-10-13 换上的“轻语 prompt”

同一句、同 seed、同参考音，只换 prompt：

| 版本 | 谐波间噪声（越低越干净） | 频谱通量 p90 | 时长 |
|---|---|---|---|
| L1 当前：轻语 prompt + 10 步 + atempo | 0.092 | 1.99 | 20.64 s |
| L2 L1 + 后期链 | 0.089 | 2.04 | 20.64 s |
| L3 原版 16 s 参考音当 prompt + 20 步 | **0.076** | 1.72 | 20.92 s |
| L4 L3 + 后期链 | **0.074** | **1.66** | 20.92 s |
| L5 L4 但用 rubberband 变速 | 0.117 | 1.82 | 20.93 s |

- 原版 prompt 比轻语 prompt 少约 **17%–20%** 谐波间噪声；这正是“气息音像机器”的量化对应。
- `rubberband` 反而把谐波间噪声抬高 27%，**不要换**；`atempo` 保留。
- 对已生成音频只做频谱降噪：0.111 → 0.108（几乎无效）。**后期救不回来，必须改生成端。**

> 时间线背景：2026-10-02 批准的原版声线，prompt 用的是 16 s 设计参考音（地磁、蟑螂、章鱼、牛顿、mariana、siffre 都是这套）；2026-10-13 批准“轻语气”，从冰川与编剧3 起换成 3.84 s 的 `light-expression` prompt，气声随之变重。

## 三、可选的三个配方

| 方案 | 内容 | 优点 | 代价 |
|---|---|---|---|
| A 只做后期 | 现有音频 + 高通 55 Hz + 去齿音 + 气息门 | 不动时间轴，可回灌已交付集 | 只能压掉弱换气，气声主体还在（−3%） |
| **B 原版 prompt + 20 步（推荐）** | prompt 换回 16 s 参考音，步数 10→20，加后期链 | 最干净（−20%），回到 10 月前几集的音色 | 离“轻语”稍远；整段时长约 +1.4% |
| C 轻语 prompt + 20 步 + 后期 | 保留轻语，只加步数与后期 | 保留已批准的轻语气 | 气声仍偏高 |

成本：20 步约为实时的 2.4 倍，35 分钟正文约 65 分钟 GPU（10 步约 45 分钟）。

## 四、已交付集不建议重制

改 prompt 或步数会让整段时长变化约 1.4%，镜头时长、字幕偏移、片头接入全部依赖实测时间轴，等于整集重剪重渲。除非你明确要求，否则只把新配方用于下一集（`5/生日悖论`）及以后。
