# 助眠交付规则

> 合并自 `covers.md` 与 `video-workflow.md §2.M` 的助眠交付摘要（2026-11-06）。
> 两件套验收与像素级 QA 的通用定义在 `../../rules/shared/delivery/final-delivery.md`，本文件不重复。

## 交付两件

- 单集 `video/final/` 只放：完整无声无字幕视频（MP4）+ 完整独立配音（WAV）。
- 视频含已批准片头与完整正文，无音频流、无字幕流、无烧录字幕；画面内已批准的账号名/主题标题不算台词字幕。
- 音频含片头与正文口播及停顿，不混 BGM 或音效。
- 两个文件同起点、同时间线，时长容差不超过一帧；用实际帧数/采样数验证，并抽查开头、中段、结尾。
- 不为凑时长截断语音、变速或补大段静音；只在尾部静音区处理舍入差。
- manifest/QA 放单集 `qa/` 或 `logs/`，不放最终输出目录。
- 只有用户确认的终版才登记 `douyin成品.md`。

## 交付前必跑

- 像素级 QA（白/黑屏 ≥1 s、音视差 ≤1 帧、CFR 均匀性）——阈值与实现见 `../../rules/shared/delivery/final-delivery.md`。
- 当前成片统一归档在 `shared/delivery/finals/`，命名 `<episode>_clean.mp4` / `_sub.mp4`。

## 封面

2026-10-08 用户确认地磁封面 r2 的大标题效果，仅适用于助眠系列；共用封面约束见 `../../rules/shared/visual/cover-and-intro.md`。

### 视觉与标题层级

- 账号标识使用「星夜慢谈」作小字辅助主标题，账号资料见 `production.md`。
- 延续电影感科学幻想风格：深青蓝、克制的琥珀金、高细节材质、空间层次、安静绚丽。不要 PPT、图例、箭头、标签框或密集说明。
- 主标题必须占主导，置于中央或中上核心区域；横版通常一行，竖版可分两行。
- 主标题优先沿用片头主题艺术字；副标题和系列标识明显小于主标题。中文文字全部后期独立排版。
- 不重复添加另一份小号主题标题；系列名、集号只在有准确输入时添加，不编造集号。
- 放大后仍检查安全边距、文字碰撞与关键主体可辨认性，按手机缩略图验收。

### 制作与交付

1. 先检查当集已验收高清素材，适合海报则复用；不适合再按已授权生图流程做无字底图。
2. 横版 16:9、竖版 9:16 分别构图；竖版不能直接裁横版导致主体丢失，可柔和延展背景，避免明显贴图边界。
3. 先定大标题位置与占幅，再安排副标题与小系列标识；保留无字来源、字体与可重复执行的排版脚本。
4. 输出版本化 PNG/JPG、低清联系表与 manifest，记录素材路径、尺寸、字体、文案、构图、哈希与验收结论；保留旧版本。
5. 发布文案同步给标题、标签与简介；语气适合助眠，避免灾难倒计时、保证睡眠等无依据表述。
6. 放大输出需注明是插值还是 AI 超分，不能把 4K 尺寸宣称为原生 4K 细节。

### 参数参考

地磁 r2 样例：横版 3840×2160，主标题 700 px、一行居中、占宽约 73%；竖版 2160×3840，主标题 780 px、两行、占宽约 72%。不是固定字号，按字数、字体与背景调整，优先保证标题主导与可读性。
