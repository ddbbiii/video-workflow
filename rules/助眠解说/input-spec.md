# 助眠解说 · 单集输入规范 v2.0（纯正文）

> 目的：把"要做一集助眠"压缩成一份填好的输入单。收到输入单后，执行者从立项做到交付，中途只在硬阻塞时停。
> 2026-11-14 改：成品只含正文，不产片头/配音/字幕烧录；每集只交正文视频 + SRT。
> 真源：流程 `rules/shared/video-workflow.md`；SRT `rules/shared/srt.md`；交付 `rules/shared/delivery.md`；内容/视觉见本目录对应模块。

## 0 使用方式

### 0.1 三步

1. 复制 `shared/workflows/助眠解说/EPISODE_INPUT_TEMPLATE.md`，另存为 `INPUT_<slug>.md`，放进单集根目录。
2. 必填 4 行：标题、主题、引入、章节大纲；后 5 行选填（必须覆盖、必须避免、时长、参考材料、备注）。
3. 把文件路径发我，附一句"按 input-spec 执行"。

表格只列你要填的 9 行；默认值见 §4，不写即按 §4 执行。

### 0.2 我的回执（开工前唯一一次对齐）

收到后先回一份不超过 12 行的回执：slug、题材、时长、门禁模式、预算、已套用的默认值、需要你决定的项（0–3 条）。

- B 模式：待决项为 0 时，回执后直接开工，不等确认。
- A 模式：回执后等你一句"开始"，再进 A 阶段。
- 回执之后不再重复问你已填过的字段。

### 0.3 执行者启动协议（新会话无记忆时按此读）

1. 本文件 + 输入单；
2. `rules/shared/video-workflow.md`（最高优先级）；
3. `rules/助眠解说/production.md`；
4. 当前阶段模块：`narrative.md` / `language-style.md` / `visual.md` / `audio.md`（只读语速）/ `delivery.md`；
5. 出 SRT 时读 `rules/shared/srt.md`；
6. 续跑先读 `PROJECT_STATE.md`、`CHECKPOINT.json`、最近 `REPORT_*.md`，核对实际文件与进程。

不整库通读；按阶段加载。**片头、配音、字幕烧录、成品库的旧规则已归档，不要读、不要当默认。**

## 1 输入分级

| 级别 | 你给什么 | 我做到哪 | 返工风险 |
|---|---|---|---|
| L0 选题 | 一个主题词 | 我出 2–3 个方向给你选，再进 L1 | 高 |
| L1 最小 | 主题（题材、时长我可代定） | 全流程；剧本我原创 | 中 |
| L2 标准 | 主题 + 标题 + 引入 + 大纲 | 全流程，剧本按你的骨架写 | 低 |
| L3 锁定稿 | 完整旁白（+ 事实来源） | 跳过剧本创作，直接分镜 | 最低 |

## 2 必填（四项）

| # | 字段 | 写法 | 校验不通过 |
|---|---|---|---|
| 1 | 标题 | 4–40 字；可暂定但要有信息量 | 空、占位（待定 / 由你拟 / 无）→ 退回；超 40 字 → 提示 |
| 2 | 主题 | 一句话：具体对象 + 一个矛盾 / 问题 | <10 字、品类名或纯名词、无矛盾 → 退回 |
| 3 | 引入 | **正文开头 1–3 句**（约 15–40 秒）；具体场景 / 问题，能直接当开头 | 空、套话（大家好 / 今天聊聊）、无具体场景 → 退回；超 200 字 → 提示压缩 |
| 4 | 章节大纲 | ≥3 章，章名 + 每章一句；或"见锁定稿"+ 路径 | <3 章、无每章一句、路径不存在 → 退回 |

- **"引入"是正文开头，不是片头**：本线不做任何片头视频、钩子卡、标题卡；这几句话直接进正文第一镜。
- 必须覆盖 / 必须避免是选填，默认"无"。

### 2.1 选题准入

| 检查 | 通过 | 不通过 |
|---|---|---|
| 可画面化 | 能用具体场景、物体、动作承载 | 退回或换角度，不用抽象氛围图硬配 |
| 事实密度 | 有可核验的事实、案例或历史节点 | 纯感悟、纯观点不够撑一集 |
| 助眠适配 | 低刺激、无惊吓、无医疗承诺、不做灾难倒计时 | 调整表述或退回 |
| 时长承载 | 内容能撑起目标时长且不注水 | 缩短时长或换题 |
| 素材版权 | 文本、图、音频可用 | 换素材 |

我主动给选题候选时按 `../shared/recommendation.md`：先过时长承载，再一次 10 条、每条一行。

## 3 授权

### 3.1 门禁模式

| 模式 | 停点 | 适用 |
|---|---|---|
| A 分段确认 | 门禁 1 关键动态、门禁 2 正文成片 | 想逐段把关；规则默认 |
| B 一次性授权 | 不停人工门禁；以 QA + 抽帧目检替代，成片统一验收 | "给文档就做完"；本规范主用途 |
| 混合 | 在"备注"写明哪一关停 | 只关心其中一段 |

B 模式是对两道人工门禁的一次性书面批准，仅对本次输入单有效；不取消验收标准，不豁免 §5.2 的 8 种硬停。

### 3.2 降级与回退

| 选项 | 含义 | 触发停的条件 |
|---|---|---|
| 停（规范默认） | 任何 I2V→静帧、换镜、模型降档、时长不足换备选，先汇总清单等我批 | 全部 |
| 允许并披露 | 允许在"不改变关键事实、不改变交付时长、单镜不超原计划 ±20%"内回退，逐条登记并在终报披露 | 关键事实、整段结构、>10% 镜头、累计 >30 s |

无论哪种，都不允许静默回退（`video-workflow.md` §2.D）。

### 3.3 不再委托的项

- 字幕样式、ASS、烧录、对轨：不做。助手只出 SRT。
- 配音、TTS、混音、BGM、封面、发布文案、成品库登记：全部用户手动，助手不代做。

### 3.4 预算与授权

- **生图 API**：填上限（张，2x2 网格图；1 张 = 1 次调用 = 最多 4 个镜头位）。35–45 分钟基准 60–85 张；填上限即视为批准，超出必须停。
- **单位口径**：按"张 2x2 网格图"算，不按单镜成品图。
- **接口异常**：403 / 余额不足 / 鉴权失败视为外部依赖不可用，停并报账，不自动换接口、换模型或降档。
- **GPU**：可填小时上限；不填则按本机队列推进，不设硬上限，但每阶段报实际占用。
- **外部检索**：允许公开网络（默认，需引用）/ 仅用户材料 / 禁止。
- **事实级别**：严格（关键事实逐条有来源，缺则停）/ 标准（默认）/ 轻（只标高风险）。

## 4 默认值

### 4.1 内容

| 字段 | 默认 | 说明 |
|---|---|---|
| 叙事视角 | 按题材（§2） | A 第二人称；B/C/D 非第二人称 |
| 结构 | 6–10 章 + 尾声，每章 2–4 分钟 | 默认骨架；L3 可覆盖 |
| 开头 | 具体场景 / 问题 / 事实 | 不用"今天我们来聊聊" |
| 结尾 | 回收开头意象，不做总结陈词 | 动物演化不用"进化终点" |
| 语言 | 中文普通话；平静、舒缓、具体、少术语 | 反 AI 腔七类禁用见 `language-style.md` |
| 字数 | 30–35 分钟目标约 7,200–8,000 汉字 | 按目标时长与 3.8 字/秒反推 |

### 4.2 视觉

| 字段 | 默认 |
|---|---|
| 画幅 / 风格 | 16:9；深青蓝夜色 + 克制琥珀金；电影感科学幻想；高细节材质 |
| 镜头 | 静—动—静三镜法；逐镜判定，不预设动态比例 |
| 动态 | 仅确有内部运动的镜头进 I2V；其余高清原图单向推拉 |
| 生图 | 默认 2x2 批量；single 仅四类例外 |
| 母题 | 每集 3–5 个贯穿道具，跨镜连续 |
| 禁止 | 图表 / 坐标 / 箭头 / UI / PPT / 画面内文字 / 水印 / 标题 / 章节卡 |

### 4.3 节奏与交付

| 字段 | 默认 |
|---|---|
| 语速 | **3.8 可见字/秒**；只用于排镜头时长与 SRT |
| 停顿 | 句间 0.35 s；章间 0.9–1.2 s |
| 交付 | 正文视频（无音轨 / 无字幕流 / 无文字层）+ 同基名 SRT（正文，0 起点，估算时间轴） |
| 命名 | `助眠_<中文剧名>_正文_<版本>.mp4` / `.srt` |
| 路径 | 视频与 SRT 同放 `video/final/`；不落成品库 |
| 账号 | 星夜慢谈 |
| 调度目标 | 锁定后 ≤24 h（目标非保证） |

`slug` 规则：小写 ASCII、连字符、≤24 字符。

## 5 校验与停止

### 5.1 开工前校验

硬失败（退回，不开工）：

1. 缺 §2 第 1–4 项或必填校验不过；
2. 主题与题材矛盾；
3. 锁定稿与"必须覆盖点"冲突；
4. 要求使用未授权素材；
5. 事实"严格"级但无来源；
6. 预算为 0 或明确禁止生图，却要求成片；
7. 交付要求与规则冲突且未在"备注"写明偏离；
8. 选题准入不过且无法修正。

软缺失（套默认值，回执里列出）：视觉参考、母题、截止时间。

### 5.2 执行中必须停的 8 种情况

| # | 情况 | 我先做什么 | 你至少要回什么 |
|---|---|---|---|
| 1 | 关键事实无法核实 | 停在该镜 / 该段，保留已做部分 | 删 / 改保守表述 / 给来源 |
| 2 | 缺凭据、API、GPU 且无替代 | 保存请求与日志，转做可独立推进的工作 | 补凭据或改期 |
| 3 | 要改已锁定文稿 / 时长 | 列出受影响的镜头、时间轴、SRT | 批准重做范围 |
| 4 | 回退影响关键事实或超 §3.2 阈值 | 汇总镜头、原因、影响时长 | 接受披露 / 重做 / 换方案 |
| 5 | 预算超上限 | 停，报实际与差额 | 追加 / 降镜数 / 停在当前 |
| 6 | 版权 / 许可风险 | 停用该素材，找替代 | 授权证明 / 换素材 |
| 7 | 硬门禁不过且无法修复 | 保留失败版本与 QA | 接受 flag / 重做 |
| 8 | 输入单内部自相矛盾 | 列冲突项，不猜 | 二选一 |

### 5.3 我不问、自行决定并记录的事

风格细节、镜头选择与转场、章节顺序微调、文件名、日志格式、常规错误修复（重试、单镜重跑、脚本修复）、并行调度、缓存与临时目录。判断标准：不改变文本、时长、事实与交付定义。

## 7 冲突裁决

| 冲突 | 裁决 |
|---|---|
| 输入单 vs 规则 | 输入单显式勾选偏离 → 按输入单并记录；未勾选 → 按规则，必要时停 |
| 输入单 vs 你后续口头 | 后续口头优先，记 `CHANGELOG`，重算受影响产物 |
| 输入单内部矛盾 | 停，列冲突（§5.2-8） |
| 锁定稿 vs 必须覆盖点 | 停；不擅自改稿 |
| 目标时长 vs 文稿 | 文稿优先；实际时长报偏差；不加速朗读、不删句凑时长 |

## 8 交付与验收

### 8.1 默认交付

- 正文视频（留单集）：`助眠_<中文剧名>_正文_<版本>.mp4`，无音频流、无字幕流、无烧录文字、无片头/标题/章节卡。
- SRT（留单集）：与视频同放 `video/final/`，同基名 `.srt`，覆盖正文、`00:00:00,000` 起，每条 ≤20 字，注明估算时间轴。
- 不产配音 WAV、不混音、不烧录、不落成品库、不写成品卡、不登记。

### 8.2 验收清单

| 项 | 标准 | 证据 |
|---|---|---|
| 输入一致 | 文案 / 时长 / 视觉与输入单一致 | 回执 + manifest |
| 音频 | 不产出；ffprobe 实测 0 音频流 | `qa/video.json` |
| 视频 | 可解码；1 条视频流、0 字幕流；记录帧率 / 帧数 / 时长 | `qa/video.json` |
| 时长 | 帧数 / 30 与容器时长差 ≤1 帧 | `qa/video.json` |
| 像素 | 白 / 黑 ≥1 s = 0；CFR 均匀 | `qa/pixel_scan.json` |
| 白边 | 四边 2 px 通过（`visual.md`） | `qa/` |
| SRT | G1 100%、G4 零超限；cue 数 = 锁定句数；首条 0.000 | `qa/srt_qa.md` |
| 语言 | `language-style.md` §7 十条全过 | 自检结果 |
| 事实 | FACT_NOTES 覆盖关键事实 | `story/FACT_NOTES.md` |
| 披露 | 所有回退 / 偏离 / 未完成项列在终报 | `REPORT_final.md` |

## 9 变更管理

- 锁定后改文本：重跑受影响单元，重建 SRT 与受影响镜头。
- 改时长：时间轴、SRT 全部重算；不许整体平移字幕。
- 已交付版本不覆盖：旧版留在原目录或 `archive/`。
