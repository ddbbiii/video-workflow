# 助眠解说规则 · 入口

> 本目录是助眠线路规则的唯一真源。2026-11-14 按「纯正文」口径收敛：删片头、配音、字幕烧录、成品库相关模块。
> 重组前原文备份：仓库旁 `../video-archive/20261114-body-only/rules-obsolete/`。

## 模块

| 文件 | 管什么 | 什么时候读 |
|---|---|---|
| `input-spec.md` | 单集输入契约：必填项、默认值、门禁模式、8 条硬停、执行映射 | 收到新单或续跑单时 |
| `production.md` | 账号、调度目标、持续推进、检查点、阻塞上报 | 开工与调度 |
| `narrative.md` | 动物演化（第二人称）与物理数学（非第二人称）叙事 | 写稿 |
| `language-style.md` | 语言风格与反 AI 腔、节奏、科学准确性、出稿验收清单 | 写稿 / 改稿 / 审稿 |
| `visual.md` | 逐镜运动、镜头白名单、三镜法、风格、生图约定、计划完整性、manifest | 分镜与生图 |
| `audio.md` | **只保留语速 3.8 字/秒与停顿**，用于排镜头时长和 SRT | 排时间轴 / 出 SRT |
| `delivery.md` | 本线交付特例：30 fps、白边门禁、路径 | 交付 |

> 字幕不在本目录：规则只有一份，见全局 `../shared/srt.md`。
> 片头、配音、混音、封面规则已废止并归档；默认不读。

## 加载顺序

0. 新单/续跑：先 `input-spec.md`，确认输入单与授权模式后再开工。
1. 全局流程：`../../rules/shared/video-workflow.md`（最高优先级）。
2. 本目录：先 `production.md`，再按当前阶段只读对应模块。
3. 执行件：`shared/workflows/助眠解说/`（命令与参数，不含规则）。

## 边界

- 全局规则（流程、交付、SRT、生图、成本）在 `rules/shared/`，本目录不复制；冲突时以用户最新指令与 `video-workflow.md` 为准。
- 本目录不写单集特例；单集覆盖写进该集 `PROJECT_STATE` 或运行日志。
- 任何与规则不一致的做法都算偏离：先说明偏离点、影响与替代方案，等用户明确同意后再执行，并记录确认；不得先做后报。
- 修改本目录需用户明确要求，改动记入 `rules/shared/README.md` 的"最近写回"。
