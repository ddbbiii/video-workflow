# 助眠字幕规则

> 合并自 `subtitles.md`、`rules/shared/audio/voice-and-subtitles.md` 的字幕部分、`shared/workflows/助眠解说/subtitle-gate-spec.md`（2026-11-06）。
> 原文备份：`shared/archive/rules-premerge-20261106/`。本文件为该主题唯一真源。

## 执行分工

- 2026-10-12 起默认由用户用 Subtitle Edit 识别、校对并导出 SRT；助手不默认运行 ASR 或生成字幕。交接与权限见 `../../rules/shared/audio/manual-post-production.md`。
- 用户明确委托时，才使用已验证的 CPU FunASR 字级对齐流程；不调用付费 API。
- 字幕和片头后期默认用本地脚本/FFmpeg，不调用图片或云端生成 API。

## 样式（style_r4）

- ASS 画布 1920×1080；WrapStyle 2；ScaledBorderAndShadow yes。
- 字体 Source Han Sans SC Heavy 2.005R；字号 96，Bold 0，ScaleX/Y 100，Spacing 0。
- 白字，黑描边 5，阴影 2（约 50% 黑）；BorderStyle 1，无底条；Alignment 2；MarginL/R 96，MarginV 118；默认单行。
- 字体与许可真源：`assets/助眠解说/subtitles/style-r4/CURRENT.md`；通过 fontsdir 加载，不安装到系统，不静默替换字体。
- 其他画幅须重新校准字面、安全区与移动端可读性，不直接照搬 1080p 参数。

## 样式唯一真源与改动纪律（2026-11-07）

- style_r4 的参数只以 `assets/助眠解说/subtitles/style-r4/CURRENT.md` 为准；片头脚本和正文脚本必须引用同一份常量，**禁止在任一脚本里另写 54/72/96 等字号**。
- **片头字幕是预烧层**：`intro.ass` 在生成 `intro.mp4` 时就烧进画面，和正文 `body.ass` 是两条独立轨道。改字幕样式时必须同时重建 `intro.ass` → `intro.mp4` → clean → 字幕版；只重烧正文会留下 0–30 秒旧样式。
- **全片一致性检查**：抽 0–30 秒内每个片头字幕 cue，再抽正文 3 个点，核对字体族、字号、描边、阴影、边距完全一致；任一处不一致判 FAIL，不得交付。
- **偏离须先获批**：任何与本节不一致的做法（改字号/描边/边距、只改正文不改片头、沿用旧版样式、临时脚本替代标准执行件）都必须在执行前说明偏离点、影响范围和替代方案，等用户明确同意后再做，并把确认记入 `PROJECT_STATE` 或运行日志。默认不允许“先做再解释”。

## 文本与时间轴

1. 复用本集锁定口播/台词规划，不另写字幕文案。保持原字词，只做断句与显示标点处理（默认去掉行末逗号、句号、顿号、分号、冒号），不依据 ASR 改写文稿。
2. 在最终剪辑时间线确定后对齐，包含引入、片头与正文。片头或剪辑改动后只重算受影响时间轴，不重配声音。
3. **字幕时间只以最终 `narration.wav`（含片头）为基准**，不用 body 相对时间 + 片头偏移。
4. ASR 结果须结合锁定稿与实际听感校对；疑似非同音差异、长段缺失、不同步区域由用户确认，不能擅自改字幕或配音。
5. 改文本、声线、停顿、片头或正文时长后，必须重建受影响的配音与字幕。

## FunASR 字级对齐要点

- **必须喂 16 kHz 单声道**：把 48 k 母带直接切给 paraformer 会整体错乱（匹配率崩塌、负时长）。
- **必须按单元/段落窗口识别并加窗口偏移**：整段识别时 VAD 段内时间戳会塌缩到前段末尾。
- **混合对齐（推荐）**：单元级时间锚点做硬边界，单元内用 FunASR 字级时间戳细化；无匹配子句按字符占比内插兜底并保留告警清单。实测 204 单元仅 2 处无匹配（99.7%）。
- 行宽不以字数替代：用锁定字体文件逐条实测渲染宽度再定断行。

## 门禁 G1–G7

| 编号 | 内容 | 类型 | 不通过处理 |
|---|---|---|---|
| G1 | 文本完整：cue 去标点 == 锁定句 | 硬 | 阻断烧录，列缺失/多出 |
| G2 | 句界同步：cue 起止 vs 词级 ASR | 硬（阈值内软） | 先全局校正，再逐条吸附；仍超限则 flag |
| G3 | 能量复核：cue 起止 vs 语音包络 | 软 | flag；与 G2 冲突时以 G3 为独立证据 |
| G4 | 断句/折行：词边界、坏边界、行宽、平衡 | 硬 | 自动重排；无法重排则 flag |
| G5 | 独立复听：异常条 ±0.8 s 再识别 | 软 | flag，人工抽检 |
| G6 | 覆盖率/漂移：每 5 分钟分箱误差 | 硬 | 漂移超限 = 时间轴问题，阻断 |
| G7 | **旁白-字幕对应**：逐句贴合实际语音；下一句不得早于上一句语音结束；每条持续到下一句；单行 ≤ 画面 80% | 硬 | 逐句重对齐＋停顿吸附；未通过阻断烧录 |

**G2 阈值**：`|err_start| ≤ 0.15 s` 与 `|err_end| ≤ 0.25 s` 各需 95% 以上 cue 满足；单条最大 `|err| ≤ 0.40 s`，超过 flag；`cue.start` 早于语音起点 >0.30 s 判“早”，`cue.end` 晚于语音终点 >0.50 s 判“拖”。

**全局偏移判定**：`median(err_start)` 在 ±0.20 s 外且四分位距 <0.15 s → 判全局偏移，整体平移重算；四分位距 ≥0.15 s → 判逐条问题，逐条吸附/flag。禁止“用户说早就全片 +1 秒”。

**G6 漂移**：正文按 5 分钟分箱，`max(bin) − min(bin) > 0.30 s` 判时间轴漂移（常见原因：拼接少帧、帧率、atempo、音轨起点），漂移时不允许烧录。

**G3 能量**：cue 起止 ±1.0 s 内用 −40 dB 包络找语音起止；起点前静音 ≤0.35 s，终点后拖尾 ≤0.50 s；与 G2 结论冲突必 flag。

**G5 复听**：仅对 G2/G3 超限或 ASR 句相似度 <0.85 的 cue，截 `[start−0.8, start+0.8]` 与 `[end−0.8, end+0.8]` 各识别一次，起点窗应出现前 2–3 字、终点窗应出现末 2–3 字；不匹配则 flag 并附文本。

**通过标准**：G1 100%；G2 95% 在阈值内且最大 ≤0.40 s；G3 无“早 >0.30 s / 拖 >0.50 s”；G4 零坏边界、零超宽、零单字行、零重叠；G6 分箱漂移 ≤0.30 s；flagged ≤2% cue；人工抽检 flagged + 随机 20 条通过；**G7 100%：逐句对齐、无下一句抢在上一句语音结束前、单行 ≤80% 宽、每条持续到下一句出现、片头与正文样式完全一致**。

## G7 旁白-字幕对应（2026-11-06 新增）

- **逐句独立对齐**：以完整句为单位，用 FunASR 16 kHz 单声道、句级窗口＋窗口偏移取字级时间；禁止整段识别、禁止按字符比例切分、禁止只用 VAD 静音段。
- **停顿吸附**：相邻 cue 的切换点吸附到上一句语音结束后的真实静音起点；下一句字幕不得在上一句语音结束前出现。
- **持续显示**：每条字幕一直显示到下一句字幕出现；允许跨句间停顿，不允许空屏断档，也不允许提前切走。
- **宽度**：单行按锁定字体实测 ≤ 画面 80%（1920 宽约 1500 px）；完整句优先一行；超长句用两行完整显示，不句中切。
- **复核**：随机 20 条做 ASR 回识，字符匹配 ≥0.85；用户指出具体时间点时，按句重对齐，不做无依据的整体平移。
- **样式一致**：片头 0–30 秒与正文的字体、字号、描边、阴影、边距必须完全一致；片头预烧层必须随样式改动重建。
- 修改文案、声线、停顿、片头或正文时长后，G7 必须重跑。

## 断句与折行

**允许断点（按优先级）**：完整句末 `。！？` 才允许切 cue；一条字幕超宽需要两行时，行内断点按 `，；：、` → 词边界；**禁止句中切 cue**（不允许半句换一条）。

**禁止断点（命中即 flag）**：
- 词内部断开；数字与量词/单位之间（三千年、数十米、四摄氏度、百分之…）；人名/地名/专名内部（jieba 词性 `nr/ns/nt/nz`）。
- 行首禁用字：的、地、得、了、着、过、吗、呢、吧、啊、而、却、也、就、还、都、和、与、或、把、被、在、从、向、因、所。
- 行尾禁用字：的、地、得、了、着、过、和、与、或、而、却、因、所、把、被、在、从、向、将。
- 行首是标点/右括号/右引号；行尾是左括号/左引号；单字行。

**行宽与节奏**：以完整句为一条，单行按锁定字体实测 ≤ 画面 80%（1920 宽、54 px 约 1500 px，约 27 字）；超长句最多两行、两行长度差 ≤4 字，必须完整显示整句；每条目标 1.0–6.0 s，完整句跨停顿可延长到下一句出现；CPS ≤9 字/秒；相邻两条零重叠、零负时长、零空白断档。

**长句拆分**：先按句末标点 `。！？` 切完整句；整句宽度 ≤80% 时一行，不切；>80% 时在句中点附近的 `，；：、` 处分成两行，两行都 ≤80%；禁止按字符比例硬切，禁止句中切 cue（一条字幕必须是一个完整句）。

**自动修复顺序**：全局偏移 → 逐条吸附（|err| ≤0.40 s 的 cue 起止吸附到词边界，start +0.03、end +0.12）→ 重排折行 → 技术清理（去重叠、补 80 ms、丢弃 <0.7 s 闪卡并回邻条）→ 每步重算 G2/G3。**不自动改文字**；G1 失败只报告。

## 产物与验收

```text
subtitles/r<n>/
  asr_segments.json  sentence_pairs.json  cues.json
  body.srt  body.ass  fixed.srt  flagged.json  qa.md  burn/
```

`qa.md` 至少含 cue 数、G1–G6 各自 PASS/FAIL、95 分位误差、最大误差、漂移值、flag 列表、是否放行烧录。

- 单集保留干净母片、SRT/ASS、对齐数据/报告、烧录版、QA 与 manifest；工具版本、输入文稿、音轨、字体、样式版本/哈希可追溯；旧版本不覆盖。
- 烧录用本地 FFmpeg/libass；Windows 下字幕目录设为 cwd，滤镜中 ASS 文件名与 fontsdir 用相对路径，避免盘符与中文路径转义。
- 视频重编码，音频 `-c:a copy`；音频流复制后以提取音轨哈希核验，不以容器哈希判断。
- 改字幕文案或样式只重烧录；改时间轴只重建侧车与烧录版；不重做画面、配音或混音。
- 批准样式不等于批准当前单集全片烧录；疑似口播差异由用户决定。
