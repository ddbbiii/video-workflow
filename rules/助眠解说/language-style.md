# 助眠语言风格与反 AI 腔规范 v1.0

> 生效：2026-11-07｜地位：助眠解说全部题材的**语言层唯一真源**，常驻写作规范，不是单集特例。  
> 来源：用户 2026-11-07 转交的《助眠科普剧本｜语言风格与反 AI 腔规范 V1.0》，原文逐字归档 `shared/archive/rule-sources/2026-11-07_助眠科普_语言风格与反AI腔规范_原文.md`（SHA-256 已核对）；本文件是生效版本，两者冲突以本文件为准。  
> 适用：30–40 分钟自然科学、地理、心理、历史、人物类助眠解说。动物演化的第二人称与物理数学的非第二人称仍按 `narrative.md`，本文件在其上叠加，不改视角。  
> 不适用：悬疑线（不自动继承；要继承由用户另行批准）。  
> 分工：字数目标见 §5（7,200–8,000 汉字），语速与停顿见 `audio.md`（只用于排时间轴），证据链与复杂度见 `../shared/script-workflow.md`。本文件只管语言、段落与准确性写法，不新增门禁、不新增 GPU 任务。

## 0 一句话标准

**像一个真正理解科学、也见过生活的人，在夜里用清楚的中文讲述一件奇怪但真实的事。**

风格目标是**原创的硬科幻纪录片叙事感**：物质细节、科学因果、尺度变化、冷静语气、克制情绪。借鉴的是高层创作方法，**不复刻任何在世作家的标志性句法、措辞与段落**。

## 1 六条常驻特征

| # | 特征 | 执行 |
|---|---|---|
| 1 | 先发生，再解释 | 先给实物、动作、地点，再讲原理。能说“泰勒冰川末端的冰被染成红褐色”，就先不说“南极隐藏着生命的密码” |
| 2 | 让事实自己形成反差 | 不加“震撼”“不可思议”“颠覆认知”；低温里仍有液态盐水、白色冰川上出现红痕，本身已经够有趣 |
| 3 | 用证据推动故事 | 发现什么 → 怎么测量 → 结果解释了什么 → 哪里还没弄清，依次推进 |
| 4 | 给尺度一个抓手 | 讲百万年要交代地质变化，讲纳米颗粒要交代显微镜与样本；不凭空谈“时间”“宇宙”“文明” |
| 5 | 自然口语、有完整句 | 长短句交替，但不要每句都断成字幕标语；多数段落能一口气读完 |
| 6 | 情绪不抢戏 | 安静、遥远、孤独一点就够；不强制上价值，不在每章最后写人生道理 |

## 2 硬性禁用（七类）

以下“反例”只用于识别问题，**不得把反例句式搬进正片**。出稿前按 §7 逐条扫描。

### 2.1 “不是……而是……”式强行对照

- 检索：`不是…而是`、`并非…而是`、`从来不是…只是`、`真正的…是`。
- 反例：“冰川流出的不是血，而是历史。”
- 改法：改写成一条正面、明确的陈述——“泰勒冰川末端渗出的盐水含有丰富的铁。它接触空气后，逐渐在冰上留下红褐色的痕迹。”
- 边界：只有在**严谨排除某个科学误解**时才可用一次；本项目优先级是**完全不用**。

### 2.2 物体人格化 ＋ 强行命令的伪深刻句

- 反例：“车不是人，它不会听你的；那就用结构逼着它听。”
- 改法：“汽车发生碰撞时，设计者需要利用车身结构的可控变形吸收一部分碰撞能量。”
- 边界：科学对象可以有运动、变化与作用，但不得有人类意志，也不给物体编台词。

### 2.3 主系表短句连发制造戏剧感

- 反例：“药是热的，人是死的，钱没了。”
- 改法：“钱花出去了，药刚刚熬好，但人已经离开。”
- 问题：省略了自然叙述里最重要的时间顺序与动作。先交代人物、动作、结果。

### 2.4 口号节奏与刻意断句

- 反例：“24 个节拍器……一分半钟——全齐了。全都同步了。”
- 改法：“实验者把多只节拍器放在能够轻微晃动的平台上。起初它们各自摆动，过了一段时间，部分节拍器会逐渐趋于同步。”
- 问题：别把一句正常话拆成三句惊叹；也不要拿特定实验条件当无条件定律。

### 2.5 空泛反问与“悬念机关”

- 反例：“墙没烂，车也不肯烂，那么这一撞最后谁来扛？”
- 改法：“如果车身几乎没有变形，碰撞能量难以通过预设的溃缩区消耗，车内人员面临的冲击风险可能更高。”
- 边界：长片允许提问，但**一个问题提出后必须继续给观察或证据**；不靠连续问号拖解释（“它去了哪里”“是谁做的”“这一切意味着什么”）。

### 2.6 概念拟人化、泛滥的宇宙感与强行升华

- 反例：“南极沉默了。冰川流血了。百万年前的秘密醒来了。”
- 改法：“在泰勒冰川末端，红褐色沉积物沿冰面铺开。科学家在渗出的高盐度水中检测到铁，也发现了微生物活动的线索。”
- 反例：“冰层为这段历史保留了最后一把钥匙。”
- 改法：“冰川内部的盐水及其化学成分，为研究当地过去的海洋环境提供了证据。”
- 边界：“密码、钥匙、秘密、宇宙的回答、文明的回声”不是禁词，但**连续出现**会让剧本失去真实感；能说明白时优先说明白。

### 2.7 廉价情绪安慰与每章固定金句

- 反例：“原来世界再寒冷，也会为生命留下温柔。”
- 改法：“这种盐水环境对大多数生物十分苛刻，但科学家仍在样本里发现了能够适应这里的微生物群落。”
- 边界：结尾不必指向“人类多么渺小”“所以你也要好好生活”“今晚请放心睡去”；一条真实的地质事实也可以自然收尾。

## 3 “硬科幻气质”怎么落到写法上

| 目标气质 | 具体执行 | 例 |
|---|---|---|
| 清晰的物质世界 | 写颜色、地形、温度、样本、结构和动作，少写抽象感受 | “盐水沿着冰川末端的裂隙渗出，在浅色冰面上留下红褐色沉积。” |
| 从小处进入大尺度 | 一个可见异常，逐渐通向地质年代与物质循环 | 红色痕迹 → 冰川通道 → 古代海水 → 微生物群落 |
| 科学因果链 | 观察 → 方法 → 结果 → 尚存问题 | 雷达发现异常带 → 推断含盐水通道 → 解释排水路径 |
| 冷静叙述 | 奇异感来自真实事实，不替观众惊呼 | “即便在严寒环境里，局部仍存在液态高盐度水。” |
| 人物尺度 | 偶尔写实地考察与科研劳动，不写假想对白 | “研究人员带着雷达设备在冰面上移动，记录信号变化。”（若缺画面证据标为演示镜头） |
| 宏观结尾 | 收在具体地理过程与仍可追问的问题上 | “冰川还在移动，盐水偶尔渗出。下一次排放何时发生，研究人员仍在追踪。” |

## 4 段落组织：从真实场景进入科学

每个重要段落按以下顺序组织，**自然融合，不在正文里写成固定八股、不加小标题式提示**：

1. **可被拍到的场景**：谁在哪里，看见什么，发生什么变化。
2. **必要的前置信息**：这件事为什么引起注意；一般情况下会怎样。
3. **研究过程**：采样、测量、比较，拿到什么证据。
4. **目前能解释到哪里**：观测事实、主流解释、研究推断、未知部分分开写。
5. **自然转场**：下一处疑问从上一处发现长出来，不突然喊一句金句。

## 5 节奏与口语（30–35 分钟长篇）

- **前 15 秒**：一到三句具体场景和主要矛盾。手写字幕居中，跟随旁白逐句出现。不要用万能口播模板。
- **前 3 分钟**：交代地点、异常与调查的第一步；不一次宣告所有答案。
- **每 4–6 分钟**：推进一层新证据或解释；**把同一结论换个说法不算推进**。
- **主体**：术语首次出现就地顺故事解释；不密集报论文作者与年份，年份只放在真正有时间意义的地方。
- **尾声约 2 分钟**：回到真实地貌或研究中尚未解决的问题，不突然煽情总结。
- **正文时长**：以纯旁白计字，按 3.8 字/秒折算时长。目标约 7,200–8,000 个汉字（约合 31.5–35 分钟，落在本线 30–40 分钟区间）；若实际时长不同，优先调整信息结构，不要灌水。
- **口语复核**：写给耳朵听，允许自然停顿；**连续三个极短句、连续三个设问句、连续三次同构排比**一律人工复核。
- 每段都要有新信息或推进；只为“高级感”、没有信息价值的句子删除。
- 数字只在帮助理解时出现；不写“几百万年”“几千公里”“无数次”一类未经核实的规模修饰。
- 音乐、字幕、画面可以营造助眠氛围；**旁白不用故意写得朦胧**。

## 6 科学准确性写作要求

1. **观察、解释、想象分开。** 例：“样本检出富铁纳米球体”是观测；“这种颗粒解释了红色来源”是研究结论；“海水被封存的具体时间”若未直接测定，必须保留推断语气。
2. **2026 年新论文须正确介绍取样位置。** 冰川末端受盐水影响的泥、冰和沉积物样本，与冰川深部的高盐度水体不是同一采样环境。不能把末端表面发现的光合真核生物放进完全黑暗的深部盐水里。同一集出现多个采样点或水体时，逐条标注样本来源。
3. **不确定性自然陈述。** “至于每次出水由什么触发，研究人员仍在调查。”一句即可；不为防质疑铺大段免责声明。
4. **引用与画面对应。** 现场真实照片、地图、显微图优先；AI 生成画面标明示意，不冒充实拍；每章写完保存资料链接与原句支持。
5. **不制造虚假采访。** 没有出处的人物对话、感叹、肢体动作、现场气温与准确时间，不能作为纪实事实呈现。
6. **落到 FACT_NOTES。** 以上逐条对应 `input-spec.md` §4.1 的四类标注：已核对来源 / 争议解释 / 待核对 / 叙事情景。用户认可叙事效果 ≠ 事实审核完成。

## 7 出稿后的反 AI 腔验收清单

交稿前逐条执行，并把结果写进当集 `story/` 或终报：

- [ ] 全文检索“不是……而是……”“并非……而是……”“真正的……是……”，改写为自然陈述。
- [ ] 检索“谁来扛”“逼着它”“沉默了”“醒来了”“谜底终于揭开”“一切都在此刻”等演戏式措辞，按事实重写。
- [ ] 没有以“X 是 Y，A 是 B，C 没了”之类主系表短句堆叠制造情绪。
- [ ] 没有连续重复“你以为……其实……”，也没有每章靠同一种反转句收尾。
- [ ] 每段能回答“这一段让观众知道了什么新东西”；答不上就删或重写。
- [ ] 历史日期、地点、研究结论与资料一致，猜测有边界。
- [ ] 科学机制普通听众能听懂，没有为华丽牺牲清晰度。
- [ ] 情绪来自具体事实与人物处境，没有强行安慰、说教与空泛升华。
- [ ] 至少一次通读模拟真实人声；发现别扭短句与字幕口号，合并成完整自然句。
- [ ] 纯旁白稿只含要朗读的文字，不夹“镜头切换”“停顿五秒”等制作指令。

## 8 范例（定风格用，非事实稿）

> 麦克默多干谷的地面上散布着大片裸露的岩石。这里的空气十分干燥，山谷里没有通常能在温带山区看到的植被。泰勒冰川从山间伸出，末端一直延伸到邦尼湖附近。就在这片灰白色的地貌里，冰面上出现了一道醒目的红褐色痕迹。
>
> 研究人员早已知道，这里的冰川能够在极低温度下保存大量古老的冰。但从冰川内部渗出的液态水，仍需要解释。为了弄清水的来源，科学家测量了盐水的化学成分，也使用雷达探查冰川内部。他们发现，冰层中存在与高盐度液体有关的信号，位置能够和冰川末端的出水区联系起来。
>
> 这条水路非常特殊。周围的大部分冰长时间保持寒冷，盐水却能够沿着裂隙移动。盐分降低了它的凝固点，局部结冰释放的热量也参与维持液态环境。水最终来到冰川表面，接触空气，所含的铁逐渐参与新的化学反应。红色就这样留在了冰上。
>
> 但盐水原本从哪里来，仍然需要更长的时间尺度去理解。要回答这个问题，视线得从今天的冰川移开，回到这片山谷曾经与海洋相连的时期。

以上为原创示范段落，**不代表真实考察的逐字现场记录**；正式剧本中的地点表述与科研细节仍须逐项核对来源。

## 9 与其它规则的关系

- **与 `narrative.md`**：视角与题材结构归 `narrative.md`；语言禁令两者叠加，冲突取更严。第二人称叙事同样受 §2 约束。
- **与 `../shared/script-workflow.md`**：证据链、复杂度与“回退简化不打补丁”按该文件；字数目标按本文件 §5，不在此重复。
- **与交付**：本文件管正文语言与开场几句；SRT 与交付见 `../shared/srt.md`、`../shared/delivery.md`；本线不做片头、不做字幕烧录。
- **放宽**：任何一条禁用项要放宽，须用户明确批准并记录到该集 `PROJECT_STATE`，且只对当次有效。
- **新增**：发现新的 AI 腔形态，直接加进 §2 并升版本；不新开文件、不在别处复述。
