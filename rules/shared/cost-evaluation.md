# 成本与工作量评估口径

生效日期：2026-11-05

适用范围：所有线路、工具开发、视频生成、批量任务和 AI 辅助生产。

## 触发条件

用户说“评估成本”“评估工作量”“这条多少钱”“耗时多少”“多久能做完”“工期”“值不值”“单条成本”“批量成本”等，一律按本规则输出。

## 只计算两项

1. **本机占用时间**：任务实际占用这台机器 CPU/GPU/内存/磁盘的时间。
2. **Token 花费**：AI 模型实际消耗的 input/output tokens 及对应费用。

**不计算**：

- 人工审片、人工判断、沟通、等待用户、返工决策；
- 人日、工时、设计师/剪辑师/外包报价；
- 与机器占用无关的行政或管理时间。

用户明确要求时，才另列人工或外包成本，并单独标注，不混入上述两项。

## 工作量怎么说

- 问“工作量”“多久”“工期”时，不换算人日、工时、几天、几个人或外包工期。
- 先给测试轮次、要渲染的条数、单条本机耗时，再给总本机占用时间；批量给“总占用 + 单条均摊”。
- 再给 token 花费；无法取得精确用量时给区间并标注“估算”，不编造账单。
- 人工审片、沟通、等待用户、返工决策不计入工作量。

## 本机占用时间

- 以本机 wall-clock 为准，单位秒或分钟；从任务开始占用 CPU/GPU 到释放为止。
- 排队但未占用资源的等待时间单列，不计入占用；若排队导致无法执行其他任务，可注明“阻塞时长”。
- 同时记录 CPU 核心秒、GPU 秒；必要时记录峰值内存/显存和磁盘写入量。
- 批处理给“总占用”和“单条均摊”两个数。
- 优先实测（进程计时、`Measure-Command`、`ffmpeg -benchmark`、GPU 采样）；无法实测时给区间并标注“估算”。
- 不擅自把机器时间折算成金额；用户提供本机小时费率或明确要求时，才按该费率折算，并写明费率与币种。

## Token 花费

- 按评估时实际使用的模型和官方价目计算；默认当前模型为 `deepseek-flash`（DeepSeek-V4.1-Flash-1017），写明价格快照日期。
- 区分 input cache hit / cache miss / output；区分峰时/非峰时；区分一次性模板成本与单条边际成本。
- 计入工具调用、文件读取、视觉 QA 等产生的 token；渲染、编码、模拟本身不消耗 token，明确写“0”。
- 计算公式：

```text
cost = input_hit/1e6 * hit_price
     + input_miss/1e6 * miss_price
     + output/1e6 * output_price
```

- 同时给 USD 和 RMB，注明汇率；批量按 `一次性成本 / N + 单条边际` 摊销。
- 无法取得精确用量时，给输入/输出 token 区间和假设，标注“估算”，不伪装成账单。
- 价格快照（2026-11-05，USD / 1M tokens，非峰时 / 峰时）：
  - input cache hit：0.003 / 0.006
  - input cache miss：0.15 / 0.30
  - output：0.60 / 1.20
  - 评估时须重新核对官方价目页；价格变化时以最新价为准。

## 输出格式

先给一句话结论，再给表：

| 成本/工作量项 | 实测/估算 | 说明 |
| --- | --- | --- |
| 测试轮次/渲染条数 | ... | 先给规模 |
| 机器占用（单条） | ... | wall-clock / CPU / GPU |
| 机器占用（批量） | ... | 总时长 / 单条均摊 |
| Token（单条边际） | ... tokens / $... / ¥... | input/output 拆分 |
| Token（一次性模板） | ... | 摊销方式 |
| 合计 | ... | 不含人工 |

最后给 2–3 条结论：单条边际成本、批量摊销、主要成本项。

## 禁止

- 不用“人日”“人工工时”“几天”“几个人”作为默认成本或工作量单位。
- 不把 token 成本与机器时间混为一个数。
- 不把等待用户、人工裁定、审片时间算进机器占用。
- 不在没有费率时自行给机器时间定价。
- 不把“工作量”回答成排期承诺；只报机器占用、渲染规模和 token。
