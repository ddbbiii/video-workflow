# 叙事视觉状态规则 v1.1

> 2026-11-15 用户要求：后续视频必须注意人物与环境的状态，避免末世角色和场地过于干净。适用于全线路；画法仍继承各线规则。

## 1. 身份、画法、状态分开

- 身份锁定脸型、比例、发型、基础服装与场地结构；状态表达此刻的疲劳、污损、伤势、维护、使用和扰动程度。
- “clean flat fills / 干净线稿 / 简笔人物”只约束画法，不意味着洁净衣物、无瑕皮肤、整洁环境。人物污渍/破损用克制的硬边色块与轮廓表达；环境材质按线路规则，不以全图噪点代替。
- 身份参考不得抹掉剧情状态。提示词必须明确参考负责什么、允许变化什么；普通配角参考不能单独充当丧尸/伤者等状态参考。反复出现的特殊状态先验证状态样张，并记录适用镜号。

## 2. 开工前状态表与逐镜解析

状态优先直接写进已有事实卡与提示词；跨阶段变化复杂时，可另建 `image/visual-state-plan.json` 便于复用，不以是否另建文件阻断生产。按镜头需要描述：

- `time_stage`：剧情日期、时段、距离事件多久；
- `character_state`：角色身份、身体/面部/衣着状态、可见表现与原因；无人镜显式空列表；
- `environment_state`：场地维护/使用/扰动程度，可见表现与原因；
- `continuity`：沿用的标志、发生变化的触发事件、清洁/修复/回忆重置点；
- `preserve`：不可改的脸、动作、门开闭、道具归属、空间锚点；
- `avoid`：会误导时间、身份、事件或画风的表现。

日常、洁净或状态不可见可明确写出，并说明剧情依据；不强制每镜画脏，不为凑数量添加碎屑。远景不硬塞面部细节，近景不强求展示整个场地状态。

## 3. 以因果和时间控制程度

- 每个状态细节须来自剧情、合理的使用/维护背景或已经确认的美术设定；不得新增打斗、火灾、死亡等未发生事件的证据。
- 区分旧有磨损与本次事件造成的变化；损坏程度应符合经过时间，清洁/修复须有依据。同场跨镜标志保持连续，不随机换污渍、伤口或破损位置。
- 灾变/末世：可用衣物领袖下摆污损、失焦目光与异常肤色、停运垃圾、翻找后的货位/散货、拖擦痕、潮湿与失去维护表现。保留角色画法和可辨识身份；群体避免全部同款整洁衣物/同一污损模板。
- 短期灾变不默认多年锈蚀、建筑普遍坍塌、植物吞楼；持续清洁的避难屋可比公共区域干净，但应体现消耗与困守。正常回忆不继承灾变污损。
- 其他题材同理：工地劳动、病中、旅途、贫困、奢华、无菌场所等分别依剧情表达，不能套统一脏旧模板。
- 不用全片压暗、泛绿、褐色滤镜、血腥或堆垃圾替代状态设计；可读性/色彩合格也不能替代状态合格。

## 4. 提示词与生成记录

- 环境底图prompt必须含已解析的场地状态；人物合成prompt须同时含人物状态及必须保留的环境状态，防止二遍把旧化清洗掉。
- 使用平涂英文风格块时补充：`Clean flat fills describe the rendering technique, not pristine physical condition. Apply the specified story-driven wear, stains and damage using restrained hard-edged shapes; preserve identity and the line's established style.`
- sidecar保存状态计划版本/所引用ID、实际解析数据、完整prompt及参考职责。只在计划里写“末世”而实际prompt未落实，视为未执行。

## 5. 提示词优化与结果诊断（不新增门禁）

- 小样覆盖本集有差异的关键状态：正常/异常、早/晚、公共/私人空间等，按实际剧情选，不能只验身份/动作/色彩。
- 逐镜检查：状态是否可见、是否符合时间与原因、是否保持跨镜连续、是否被参考图洗净、是否破坏画法或新增剧情。
- 对承担状态信息的镜头，遮掉旁白后仍应读出预定状态。例如丧尸能与正常路人区分，失去维护的公共场地不似刚打扫完。无需每张微距插入镜独自说明整部剧情。
- 不要求逐镜状态PASS/FAIL表，不增加独立审批、停机或批次阻塞。发现偏差时记录具体问题，用于下一次提示词优化；保留身份、剧情事实与技术检查。
- 明显偏离用户要求时只修受影响角色、底图或合成阶段；不因细小美术差异反复重抽。用户要求状态样张时先交样张，不提前批量或重拼成片。

## 6. 可直接用于提示词的写法

- 顺序：剧情事实 → 当前人物/场地状态及原因 → 可见区域和表现强度 → 空间/群体关系 → 身份与动作保留项。用明确形状和区域代替“加强细节”。
- 强度按认可样张描述；需要明显破败时，写大块衣料污损、成片墙皮/潮痕、翻空货位等低清也可读的变化，不只加零星小点。强度随题材和剧情调整，不要求所有画面脏旧。
- 群体：围绕吸引源、障碍与通道描述疏密和拥堵；前后错位、相互遮挡、肩线高低和朝向各异。非列队情节避免横排、齐头线、等距网格、统一姿态；不机械随机撒人。队列/军阵等剧情明确要求整齐时按剧情画。
- 检查缩略图仅帮助判断提示词是否表达充分，不作为新增数值阈值或硬性门禁。

2026-11-15 v1.1：按用户指令改为提示词优先，取消独立状态门禁及强制另建状态表，补表现强度与自然群体分布。
