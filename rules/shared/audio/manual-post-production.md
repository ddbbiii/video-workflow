# 用户手动音频与字幕后期

生效日期：2026-10-12。用户最新确认的默认工作流；优先于旧规则、旧交接及脚本中的自动混音/自动字幕要求。既有成品不重做。

## 分工与顺序

1. 助手按锁定内容制作画面与独立配音，内部保留原始素材。默认最终输出仅为完整无声无字幕视频与完整配音，起点与时长一致；BGM 不混入、不额外交付副本。目录及验收真源：`rules/shared/delivery/final-delivery.md`。
2. 用户手动完成配音与 BGM 混音，决定音量、循环接缝、淡入淡出和其他处理。助手不默认运行混音脚本，不自动套用历史增益或响度参数。
3. 用户在最终音频与剪辑时间线确定后，通过 Subtitle Edit 生成、校对字幕并导出 SRT。识别文本以锁定稿为校对参考；疑似口播差异由用户确认，不自动替换原稿或修改配音。
4. 助手接收用户提供的最终混音与字幕文件，按授权做资产登记、样式转换、合成或验收。字幕烧录不因收到 SRT 就自动启动，未明确执行方时先确认。SRT 不保存完整字体样式；需已批准样式时另保留 ASS。

## 交接与验收

- 单集目录保留独立音轨、用户混音、SRT/ASS、干净母片和发布派生版；记录字幕对应的音视频版本、起点与时长，必要时记录哈希，不覆盖旧产物。
- 两个文件验收后可标记“助手交付完成”；用户混音/字幕尚未交回时发布状态仍为“等待用户手动后期”，不声称发布成片已完成，不自动接力生成。
- Subtitle Edit 是制作工具，不是同步保证。核对开头、中段、结尾及剪辑接点，检查持续漂移、重叠和可读时长；不同步处交用户校准。
- 用户交回最终时间轴后，不擅自改配音速度、片头长度、正文时长或整片偏移；确需改动时说明对字幕的影响。
- 助手自动 ASR、混音与脚本校准仅在用户明确委托对应步骤时启用；已有工具与历史脚本保留作为可选工具，不卸载、不作为默认任务启动。
- 自动配音生成、画面制作和已批准的线路字幕样式不因本规则被取消。各线路的选曲规则继续有效，混音控制权归用户。
