# 网格生图与复杂场景提示词规则

生效日期：2026-10-05

适用范围：所有线路的图片 API 生图、`2x2`、`3x3` 及其他多格分镜任务。

## 基本要求

复杂场景不能只用一条总提示词重复生成多个格子。每次网格生图必须同时具备：

1. 整组统一世界观、画风、色彩和技术约束；
2. 每个格子的独立画面文案；
3. 每个格子的视觉事实、构图和镜头信息；
4. 格子之间需要保持或改变的连续性条件；
5. 统一禁止项和格子专属禁止项。

## 每格提示词最低内容

复杂格子至少根据实际需要写清：

- 主体及数量；
- 主体在画面中的位置和占比；
- 前景、中景、远景关系；
- 摄像机位置、观察方向、景别或焦段倾向；
- 主体之间的前后、遮挡、朝向和尺度关系；
- 光源方向、色温、明暗和反射；
- 材质、纹理和关键细节；
- 该格必须让观众看懂的剧情或空间事实；
- 不允许模型自行添加的内容。

简单格子不强行扩写，但不能省略会影响主体位置、数量、状态或剧情理解的事实。

## 网格规格

- 单图：独立完整构图，不添加网格说明；
- `2x2`：四个独立画面，每格必须有独立文案；
- `3x3`：九个独立画面，每格必须有独立文案；
- 每格应注明位置、景别、主体、动作或状态和与其他格子的连续关系；
- 不把格子编号、提示词说明、对白、标签或标题交给生图模型绘制。

## 提示词结构

推荐顺序：

```text
统一世界观与画风
→ 网格布局与画幅
→ 每格视觉事实
→ 摄像机与构图
→ 光线、材质与色彩
→ 连续性要求
→ 全局及格子专属禁止项
```

每格应像一张独立分镜提示词，而不是只写“行星近景”“空间站”“星云”等主题名。

## API 请求与记录

一次 API 请求可以生成单图、四格或九格，但请求前必须先完成对应数量的格子文案。`grid-manifest` 需要记录：网格规格、每格文案、参考图、格子位置、对应镜头编号、拆分文件和连续性检查结果。

## 当前对比测试（2026-10-06 最新确认）

- 目的：通过一次调用生成多个网格场景来减少调用费用，与独立生图比较裁剪后的质量。独立场景文案不等于逐场景调用。
- A 基准：保留已生成的 A01-A09 独立图片；B：一次调用生成完整四格，对应 A01-A04；C：一次调用生成完整九格，对应 A01-A09。B/C 均裁剪为独立文件，不能再替换成独立请求。
- 历史网格与12张独立图均保留为记录；旧 B01/B02/C01 独立图不是本轮 B/C 对比输入。
- 第一轮只比较原图与网格裁剪结果；统一尺寸的预览允许普通插值，但必须标明，不能当作原始像素。下一轮先讨论再执行 AI 超分等优化，不覆盖原图和裁剪图。
- 同一批次中的每个有效格子都要有独立、完整、可直接交给图片 API 的视觉文案；禁止先写一条总提示词再机械复制到各格。
- 统一设定只负责保持世界观、画风、光线基调和资产连续性；每格必须独立决定主体、位置、景别、空间关系和可见细节。

## 验收

## 默认选型原则（2026-10-06 用户采纳）

- 常规环境画面优先考虑四格生成、裁剪后用于1080p；它是成本优化候选，不保证与独立高清图等价，仍需逐格验收。
- 九格优先用于选景、分镜预览、远景和低细节背景，暂不作为统一高清成片方案。
- 复杂几何、关键特写、需要明显推近的镜头优先独立生图。
- 四格硬边结构与一般纹理可使用本地 RealESRGAN_x4plus，检查光晕、假纹理和分块接缝；星云等柔和助眠背景优先普通 Lanczos，避免增强亮点和刺激度。
- 超分不能修复主体、方向、几何或剧情错误；新增细节是模型推断，不代表真实恢复。
- 保留接口原图、裁剪图与优化图，分别记录参数和QA，不覆盖来源文件。实际成本按账单和可用镜头数核算，不能仅以调用次数宣称节省比例。
- 依据：宇宙测试 v3 网格对照、v4 五个超分样本。仅作为当前默认选型，后续按新样本修正，不外推为所有题材的质量保证。

## 选型与调用预算修订（2026-10-19）

用户确认：自 2026-10-19 之后新建的单集分镜起生效；进行中单集按原批准计划执行，不追溯改模式。

1. single 模式改为"需写明理由的例外"，默认 2x2 批量。允许 single 的仅四类：母题定装镜（跨镜同物的首次关键帧）、精密结构（表、仪器等文字禁令特写）、人物正脸/侧脸定装、明显推近的关键特写。分镜计划中每个 single 镜须注明所属类别。
2. 调用预算前置：每集 SHOT_PLAN 顶部必须写"预计 API 调用数 = single 镜数 + ⌈批量镜数/4⌉"，随分镜计划一并报用户批准；未经批准不得开生图。
3. 参考基准：35–45 分钟单集 single 占比目标 ≤40%，整集调用预算约 60–85 次；超基准需说明原因。

## 逐格验收

生成后检查：

- 每格是否表达了独立画面，而不是同一构图的重复变体；
- 统一世界观中的主体、光线和材质是否连续；
- 格子之间的空间关系是否能被观众理解；
- 是否出现文字、边框、编号、错误主体数量或模型擅自补全；
- 单格裁切后是否仍然具备可用构图。

如果一个格子承载的信息过多，即使提示词已经很长仍然不稳定，应拆成多个状态或重新规划网格，不得继续堆叠无效形容词。
