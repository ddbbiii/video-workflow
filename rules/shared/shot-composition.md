# 镜头配比规则（E / M / C · 22 : 53 : 25）

> 生效：2026-11-14 ｜ 2026-11-15 补物件密度与材质、fact 与序列验收 ｜ 适用：**悬疑线、人生体验线**（其他线可自愿采用）
> 起因：用户 2026-11-14 指出「图大多以人物为主导，观众对场景理解不清晰」，定配比 22/53/25。
> 只管**镜头类型与构图**；画风、色彩、动态方式仍按各线规则，本文件不覆盖。

## 一、三类镜头

| 类 | 定义 | 人物在画面里 | 主要任务 |
|---|---|---|---|
| **E** 建立 | 空间为主 | 无人，或只占 1/6–1/5 | 交代"这是哪、多大、往哪走" |
| **M** 中景 | 人 + 环境 | 人占 1/3 左右 | 让人物在看得懂的地方行动 |
| **C** 特写 | 脸 / 手 / 关键道具 | 不限 | 情绪、证据、关键动作细节 |

E ≠ 空镜。**E 里常常有人，只是人在远处**；不许把 E 理解成"去掉主角"。

## 二、配比（全片，允许 ±3 个百分点）

| 类 | 目标 | 210 镜示例 |
|---|---:|---:|
| E | **22%** | 约 46 镜 |
| M | **53%** | 约 111 镜 |
| C | **25%** | 约 53 镜 |

不摊平到每一章：E 集中在**进场**与**空间转折**（上楼、开门、出楼、抵达），单章 E 可以 10%–35%。

## 三、四条硬约束

1. **进场三连**：每进一个新场地，先 E1（全景）→ E2（锚点）→ 才允许 M / C。同一场地重复进入时，至少保留 1 个 E。
2. **不许长时间只有人**：任意连续 **6 镜**内必须有 ≥1 个 E；连续含人物镜不超过 **5 镜**。
3. **人物占比靠构图，不靠压小人**：占比由**机位距离 / 焦段 / 站位 / 前景遮挡**决定（做法见各线 `style.md` 的「构图语法」）。人物尺寸必须符合常识——以同画面里的门作参照，人物高约为门高的 **0.55–0.65**；低于 0.5 视为被压小，返工。
   - E ≤1/5 画面、M 约 1/3、C ≥1/2，指的是**构图占比**，不是把人画成矮子。
4. **景深与空间可读性**：每镜至少 3 层信息（前景遮挡 / 中景主体 / 远景信息），三层各要有**具体物件**；E 镜去掉人物后仍能认出场地与朝向（2026-11-15 v1.1：不再用"物件件数"做下限，改用"去人读图 + 场地锚点"判定，详见 `style.md` §2.1）；底部 1/5 留作安全区，不放关键信息。

## 四、场地锚点

每个场地定 2–3 个**可重复的识别物**，全片至少出现 2 次，且尽量同一角度；锚点写进该集 `image/color-plan.json` 的 `locations`，生图时强制出现。

- 锚点用来让观众记地图，不是装饰。
- **题眼道具不得被主体遮挡**（例：焊死的铁门必须同时看见焊缝、锁、门后通路）。

## 五、构图语法（两条线共用真源，2026-11-14）

**占比靠构图，不靠把人画小。** 人物尺寸必须符合常识：以同画面里的门作参照，**人物高 ≈ 门高的 0.55–0.65**；小于 0.5 视为被压小，返工。

四个参数决定占比：

| 参数 | 选项 | 说明 |
|---|---|---|
| 机位距离 | 近 1–2 m／中 3–4 m／远（贴对面墙、门洞外、走廊尽端） | 决定画面里出现多少空间 |
| 焦段 | 广角 24–28mm／标准 35mm／长焦 50–85mm | 广角拉开空间，长焦压缩背景；各线可只允许部分档位 |
| 站位 | 左/右三分之一线（不居中） | 把另外三分之二让给环境 |
| 前景遮挡 | 门框、桌角、椅背、窗框、扶手、货架边、晾衣杆 | 压住画面边角，承担视觉重量 |

提示词按这个顺序写，**不写百分比**：

```text
机位：<近/中/远>，相机高度 <视平线/略低/略高>，从 <房间另一头/门口/楼梯下> 看过去；
焦段：<24mm / 35mm / 85mm>；
人物：站在画面 <左/右> 三分之一线，身高约为门高的 0.6，不居中；
前景：<门框 / 桌角 / 窗框 / 扶手> 压住画面 <左下/右侧> 四分之一；
环境占画面：三分之二，要能看清 <墙面/窗/床/柜/走廊尽头> 的完整轮廓。
```

三层信息（见 §三.4）在这套语法里落地：**前景 = 遮挡物，中景 = 人物与在用家具，远景 = 窗/门洞/通道**，三层各写具体物件。

各线只调默认档位，不改这四个参数本身：

| 线 | 默认机位 | 默认焦段 | 备注 |
|---|---|---|---|
| 人生体验 | 中/远 | 24–35mm | 见 `rules/人生体验/style.md` §3.1 |
| 悬疑 | 中/远（门外、走廊尽端） | 24–28mm 深焦 | 见 `rules/悬疑/visual.md` §4.1.1；本线不用浅景深 |

### 5.3 每场默认脚手架（不是硬规则）

进场三连（E1 全景 → E2 锚点）之后，默认再给两镜，一场戏的起手是这四镜：

1. **E1 全景**：空间 + 一处损耗；
2. **E2 锚点**：该场地的识别物；
3. **M 界线镜**：人站在这块空间的界线（门框、门槛、栏杆、楼梯口）上；
4. **C / E 结果镜**：他看的东西、或他做完之后的变化。

- 顺序可以按场次改，这不是配比也不是门禁。
- 第 3 镜的判据不是"背影怎么站"，而是**写不写得出他手上在做什么**；写不出，这镜就没有 `fact`，改成 E、删掉或并进前后镜（见 §六）。
- 模板只保证一件事：**人的动作和他看的东西落在同一场里**，不靠观众猜。

### 5.4 序列验收（2026-11-15）

- 构图按 **3–4 镜一组**看，不按单帧判：全景 → 人在界线上 → 他看到的东西；整组读得通才算过。
- 单帧只判**风格与破败**（色盘、平涂、暖光、损耗证据、证据占比），不判"讲不讲得清"。
- 单帧判叙事会两头出错：误杀铺垫镜，放过断掉的组。
- 组的切法：`scene_id` 的进场段（进场三连 + 紧接着 1–2 镜）。
- 起因：2026-11-14 悬疑 8 镜小批 B2（走廊尽端背影）单帧被判"讲不清他在干什么"，但它与 A1、B1 信息重复、`fact` 为空，属于该删的镜，不是该重摆的构图。

## 六、数据与执行

剧本每个镜头在 `visual` 之外补三个字段：

```text
shot_type：E | M | C
scene_id：<场地 ID>，如 502 / corridor / lobby / store / street / gate
fact：<这一镜观众必须看懂的一件事>，一句话，≤40 字
```

script 里一镜一块，`S<编号>` 起头，门禁只认这个格式：

```text
S07 走廊尽端
shot_type：M
scene_id：corridor
fact：他的手停在门把上，门缝里比走廊更黑
```

- `has_character` 未标时该镜不计入「连续含人物镜」，门禁出 NOTE；正式 `image/shot-plan.json` 必须逐镜标。
- `fact` 写**可验证的事实**：他手上在做什么、画面里多了什么、空间哪里不对、谁不在该在的地方。不写"压抑""诡异""过渡""情绪"这类形容词。
- `fact` 是**信息职责**，不是画面描述；画面仍写在 `visual`。空 `fact` ＝ 这镜没有职责 → 先删或并，再谈构图。
- 同一场次内 `fact` 不许重复：同一件事第二次出现，说明后一镜可以并进前一镜（2026-11-15 起因：悬疑小批 B2 与 A1/B1 信息重复）。
- 剧本锁定前，用 `shared/workflows/body-only/check_shot_mix.py` 跑一次配比；
- 出静帧前，同一脚本对 `image/shot-plan.json` 再跑一次（含人物面积与锚点字段）；
- 悬疑线门禁加 `--require-fact`（空 fact 直接 FAIL）；人生体验线暂以 NOTE 提示，该线确认后再转强制。
- 两道门禁都要求配比在容差内、四条硬约束全过。

## 七、验收

- [ ] 全片 E/M/C 比例在 22/53/25 ±3pp 内。
- [ ] 每个 `scene_id` 首次出现时，前两镜为 E1 + E2。
- [ ] 任意连续 6 镜有 ≥1 个 E；连续含人物镜 ≤5。
- [ ] 每个 `scene_id` 至少 2 个锚点被登记，且各出现 ≥2 次。
- [ ] 每镜 `fact` 非空、同场不重复；悬疑线 `--require-fact` 退出码 0。
- [ ] 每场抽 3–4 镜一组看：能读出"这是哪 → 人在干什么 → 他看到了什么"。
- [ ] `check_shot_mix.py` 退出码 0。

## 八、明确不做

- 不为凑配比把关键情绪镜降级成空景；情绪镜不够时，加 E 而不是删 C。
- 不做"全片空镜记录片"（E 上限 30%）。
- 不追加重排已交付成片（2026-11-14 用户指令：旧成品不回改）。
- **不把单镜修辞写成规则或提示词模板**（"背影怎么站、手放哪、隔几步"）：这类问题在写分镜时用 `fact` 与删/并解决，规则只写可判定的共性与验收口径（2026-11-15 决定，起因：8 镜小批 B2）。
