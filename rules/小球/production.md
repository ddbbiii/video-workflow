# 圆环小球制作规则

范围：小球线圆环玩法。用户于 2026-11-24 授权将当前优化持久化。该文件为固定入口；日期用于说明授权，不替代规则入口。

## 运动与参数

- 目标是看得清的内壁反弹、跨内圈飞行、暂时受阻与分段穿层。数值碰撞次数不能代替可见折返，不以极短时间穿完全部层数为首要目标。
- 密集圆环保留，但缺口不能长期形成把小球持续接走的通道。默认采用整体旋转、层间平滑错位和小幅随层号弯曲；不逐层随机转向。
- 正式输入只认一份单集配置；先生成唯一轨迹，再供画面、声音和镜头读取。固定初态与随机种子需如实声明，不能把人为指定初态称为随机抽样。
- 默认向下重力，单位为场景坐标/秒²，屏幕 +y 向下。当前已认可参考值 240，允许按单集调整；480 为翻倍试听，需用户看结果后再升为默认。
- 沿用已认可基准：300 层；球半径 10，初速 430，初始内圈半径 225、下限 205；环距 10、厚 2.4；补入速度 100；缺口宽 0.85 rad、转速 0.6 rad/s、层间错位 0.06 rad、波动 −0.15 sin(0.35×层号)。精确单集值写配置，不把本文当程序配置解析。
- 允许连续速度稳定器，当前回调率 2/s；不在碰撞瞬间强行恒速，不暗中加方向偏置或脱困传送。回调和移动边界都会影响速度，必须称为游戏化物理，不能称严格能量守恒或理想抛物线。
- 圆弧与端点分别检测，计入径向补层和旋转端点速度。当前固定物理频率 4800 Hz、输出 60 fps；更改求解器、步长或参数后重新验收，不能静默切换实现。
- 长轨迹必须跑完整层数。保留实际等待和突破；有明显长等待时报告，不剪掉后声称原速完整。

## 近景构图

- 以正在活动的内圈为主体，不为容纳全部外环持续拉远。默认活动圆直径约占宽度 70%–85%，球径以宽度约 3%–4% 为参考。
- 固定镜头中心，不逐次追球或碰撞时跳变。需要时，依据场景和球的空间范围预计算平滑缩放，允许前瞻以防出画；必须如实说明自适应缩放。
- 外环允许裁切，球必须完整在画内。若长轨迹导致球明显缩小，应报告最小球径和持续时间；不能靠只放大视觉球体破坏缺口尺寸关系。
- 拖尾短而克制，不跨碰撞连接成弯曲假路径；可用短接触闪光帮助识别撞点，不用特效掩盖物理问题。

## 声音与交付

- 默认碰撞与穿环分别发声：碰撞为低/中频短弹击，穿环为明亮短提示，音色易区分。参考长度分别 55 ms / 85 ms，可按单集调整。
- 穿层逐事件触发，不漏播、不为了卡音乐挪动事件。碰撞记录若有去重须声明策略；当前 25 ms 去重，记录数不等同所有求解冲量。
- 默认无旁白、无字幕、无 SRT、无片头和文字层；无音乐，除非用户另行要求。小球线明确需要的事件音效为本线路交付的一部分，覆盖通用静音正文规则，仅限小球线，不扩展到其他线路。
- 含旁白时仍遵守工作区音色/配速确认门禁。无旁白的物理音效视频不需要选择配音音色。
- 输出完整 H.264/AAC MP4，1080×1920、60 fps；单集 `video/` 保存当前有效试听，验收定稿后只留当前有效版本及生产依赖、简明 QA。不因改版自动保留旧成片或归档，仍有效的对照须明确用途。
- librosa 可离线提供音乐节拍参考；真实碰撞声仍与物理事件同步。连续渐强不强制吸附下一拍。当前不因音乐分析而切换物理或渲染框架。

## 验收与变更

- 轨迹层号连续、全部完成，无穿越实体圆弧，求解后残余嵌入在明确容差内；碰后相对法向分离。区分完整内壁反弹与端点擦碰。
- 检查自由飞行、内区/近壁占比、最长持续擦边、最长穿层等待、速度范围、相机缩放和球出画。各指标用于诊断，不把单个阈值冒充观感验收。
- 音效数量与事件一致，按音频采样时间对齐；无截尾，报告重叠数；编码后真峰值不高于 −1 dBTP。
- 实测编码、尺寸、帧率、帧数和音频时长；完整解码、持续黑场/冻结扫描，关键时刻和联系表目检。不能仅检查文件存在。
- 客观数据验收与主观试听分开表述，没有直接听音能力不得声称已试听。
- 新参数先跑轨迹诊断，再出样片；单次尽量只改用户指定变量。当前初态通过不代表全部随机开局或通用求解器稳定。
