# 小球线规则入口

适用范围：`projects/小球/` 的圆环小球制作，以及为该线路维护的相关运行时。不套用到其他视频线路。

- [圆环运动、近景、声音与验收](production.md)：当前正式制作规则。
- 参数参考：[已获认可的 300 层重力 240 配置](../../projects/小球/episodes/20261124-rings-300-gravity/simulation/config.json)。
- 单集机器清单与 Motion Studio 接口仍遵守 [VIDEO_OUTPUT_SPEC.md](../../projects/小球/VIDEO_OUTPUT_SPEC.md)；未知模型未开发适配器前，不宣称已接入 Studio。

2026-11-24 用户明确要求“效果还不错，你持久化一下，改一下我们的规则吧。这把优化很好，但向下的力还不够，翻倍试一下”。据此将已认可的方法固化为小球线规则。重力 480 是本次候选试验，未验收前不代替已认可的 240 基线。改变固定值无需修改整个技术路线，但须重新生成并检查轨迹和声音。
