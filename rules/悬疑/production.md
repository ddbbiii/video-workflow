# 悬疑生产规则

> 2026-11-07 新建；2026-11-14 按「纯正文」口径收敛；当前统一称「悬疑线」，涵盖恐怖与推理。本文件只写账号、单集目标、目录结构与门禁。
> 调度口径、检查点、持续推进、阻塞上报不写——等实际跑起来后按真实问题再补。

## 账号

- 账号名：**空白证词**（沿用，不复用旧系列品牌与人设）。
- 头像、简介、账号标识待定；本线不做封面，账号信息不进入视频。
- 旧《都市异常档案》《转乘站》系列名与编号体系不再使用；单集目录用日期 + 短标题命名。
- **成品视频文件名**按 `rules/shared/delivery.md`：`悬疑_<中文剧名>_正文_<版本>.mp4`，例如 `悬疑_病历对不上_正文_v2.mp4`；不得用纯拼音名交付。

## 单集目标

- 故事总时长按需要确定，原则上不超过 25 分钟，不设 5 分钟最低要求，不为凑时长扩写。超过 25 分钟的故事须压缩或改选，不通过拆集突破总时长上限；
- 成片 16:9 / 1920×1080 / 24fps。

## 目录结构

```
projects/悬疑/episodes/<YYYYMMDD>-<slug>/
  PROJECT_STATE.md      当前阶段、已完成、下一步
  story/                故事包、旁白锁定稿、故事主线大纲、悬念预算表、总字数预算
  storyboard/           镜头节拍、视觉事实卡、CHARACTER_LOCK.md
  image/                参考图、分镜图、通过图；引入图片在 intro/vN/
  video/                动态、剪辑工程、正文成片（final/）；SRT 在 srt/
  qa/                   自查与交付级 QA
  logs/                 运行日志
```

## 人物锚点前置

- 批量生图/生视频前，**主角三视图与 `CHARACTER_SPEC.md` 必须锁定**；未锁定不得开批量。
- 默认按 `visual.md` §六 6.0 精简档：主角 1 张 2×2 拼版、B 档 1 张正面/3-4 参考、试生用前 3 个正式镜。
- 主角复用按 `visual.md` §六 6.6：默认**同脸复用**；同人复用只用于续集；不强行同一人、不改剧本凑复用。
- 本集 `storyboard/CHARACTER_LOCK.md` 未落盘，不得开批量。
- 违反按偏离处理（先说明、获批、记录）。

## 视觉口径

- 每镜提示词 = `visual.md` §二 风格块**原文** + 本镜文案；含人物/手部/证据特写再追加 `CEL_BOOST`；`STYLE_NEG` 以 `Avoid: ...` 追加在末尾。
- 破败与构图按 `visual.md` §三/§四：每镜 ≥2 处损耗证据 + ≥1 处生活痕迹，主体偏置、前景遮挡、证据 ≥1/6。
- 生图只走 GPT 图片 API（`shared/image-api/channel-policy.json`）；**本地文生图禁用**。
- 文书类证据按 `visual.md` §五.7 走后期贴片，不让模型画表格/可读字。
- 每镜 `fact` 非空、同场不重复；锁稿前跑 `shared/workflows/body-only/check_shot_mix.py --script story/script.md --require-fact`，退出码非 0 不得锁稿、不得开批量（`../shared/shot-composition.md` §六–§七）。
- 任何局部覆盖必须先获批再执行，不得先做后报。

## 门禁

- 本线两道：**门禁 A 剧本锁定**、**门禁 B 正文成片**（定义见 `input-spec.md`）。
- 交付三类：引入图片 + 正文视频 + 正文 SRT，具体按 `delivery.md`。引入按当集确认方案单独交付，不制作引入字幕；正文视频 0 秒即正文第一帧。
- 成片沿用 `rules/shared/video-workflow.md` 的相应门禁与 `delivery.md` 的交付门禁。
- 偏离必须先说明、获批再执行，不得先做后报。
