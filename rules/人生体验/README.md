# 人生体验线路规则

> 2026-11-10 建线；2026-11-14 按「纯正文」口径收敛：不做片头、不做配音、不做字幕烧录、不做成品库。
> **2026-11-14 第二次修订：色彩从固定土黄色板改为逐集色彩脚本**（起因：连续两集整片泛黄，98.5% 像素挤在 0–60°）。
> 本目录只写本线特有的东西，通用流程继承 `rules/shared/`。
> 范围：人物启用参考片方向的圆头手绘人物（白灰大圆头、完整着装身体及手绘明暗），背景保留原手绘层次；剧情、身份、结构、节奏、细节、结尾、时长由用户逐期定。
> 人物风格只保留两种：圆头手绘（当前默认）与猫头人（保留可选）；不自动混用。旧成片不自动重制。

## 已定规则

### 叙事口径

- 默认采用第二人称体验叙事：旁白中的“你”就是正在经历这段人生的人，让观众直接进入人物处境。
- 代入感是目标，不等于每集都要写身体感受或动作细节；按题材和段落需要选择人称与细节，只有能推进事件、判断变化或代价时才加入，不为凑篇幅硬写。真实事件遵守 `rules/shared/script-workflow.md` §7.3 的事实与重构边界。
- 默认只制作正文；用户要求准备引入时，按 `intro.md` 提供简短文案及对应画面。正文开头不写“今天要体验的人生副本是”式片头句，直接用简短的第二人称叙述带观众进入事件，并可先交代关键结果。
- 旁白以行动、具体细节和前后变化推进，尽量少用多人对白；必要对白只保留能改变判断、推动选择或制造反差的短句。
- **语言必须自然、直白、首听即懂。** 先写清人物、动作、物件和变化，再考虑修辞；读者若需要停下来解码比喻，或同一句能用更自然的口语准确表达，就改成直说。避免把抽象概念硬写成动作或物件（如“背包里没有装进今晚”）、用诗性说法代替可见变化（如“路在缩短”）、把常用动作搭配写得不合中文习惯（如“向山下说话”）。
- **口语复核：** 每段出稿后朗读一遍；逐句检查“第一次听能否立即明白谁在做什么、发生了什么变化”。凡需回读、脑内翻译或补出隐含主语的句子，优先改写，不以“有氛围”“有文采”作为保留理由。比喻可以用，但必须贴合人物当下能看见或做出的事，且不能替代关键信息。
- 结局服从人物与因果，不要求正向收束；可以停在失败、讽刺、悬而未决或被系统继续吞没的状态。
- 目标是让观众能复述人物经历，并对责任、选择和结果产生讨论；不靠最后一段说教替观众完成判断。
- 旧集按锁定稿执行，不因本口径回改。

## 继承

- 标题创作或改标题时，统一遵守 `../shared/title.md`。
- 旁白：`cue` 只写观众听到的话；写稿后与出 SRT 前各跑一次 `shared/workflows/script-qa/lint_narration.py`。
- 流程：`rules/shared/video-workflow.md`（剧本锁定 → 分镜 → 动态 → 门禁 1/2 → SRT → 交付），另加 G0 剧本锁与 G2 静帧抽检。
- SRT：`rules/shared/srt.md`；每条 ≤20 字、0 起点、估算时间轴（4.8 字/秒）。
- 交付：`rules/shared/delivery.md`；正文视频 + 同基名 SRT 一起放在 `video/final/`。
- 生图：以 `shared/image-api/channel-policy.json` 当前策略为准。
- **静帧生产**：`still-production.md` 是本线生图的必读执行规程；与旧集 README、旧生成脚本注释或单集旧状态冲突时，以当前规则标题版本和该规程为准。
- **镜头配比**：`rules/shared/shot-composition.md`，E/M/C = 22/53/25，每场地进场先 E1+E2；门禁 `shared/workflows/body-only/check_shot_mix.py`。
- **运镜**：继承 `shared/camera-motion/MOTION_GUIDELINES.md`——静态图推拉用 **affine 浮点亚像素后端**、60 fps 渲染、推近 ≥9%／拉远 ≥8%／横移 ≥6%；**禁用 `zoompan`**（整数取整会抖，2026-11-14 实测 MAD 变异系数 0.6–0.7）。
- **不做**：片头、标题页、章节卡、账号卡、配音、混音、BGM、字幕烧录、封面、成品库、成品卡。

## 待补（等对应阶段再写）

1. 时长与镜数：参考片 11:14.8、约 105 镜；本线默认值待用户拍板。
2. 按单集角色需要准备圆头手绘人物的身份、服装、比例和状态参考。
3. 章节切分方式（只在旁白与画面上切，不做章节卡）。

## 明确不做

- 不做真人出镜、不做口型、不做多人对白、不做全片连续动画。
- 不搬运参考片的文案、章节名、画面、服装搭配、音轨、BGM、现成梗。
- 不把参考片任何一帧当素材。
- 不在未锁定剧本前批量生图。
- **不在没有 `image/color-plan.json` 的情况下批量生图；不把色板写回风格块；不用后期 LUT 掩盖生图偏色。**
- 真实人物与灾难事件可以做有来源归因的事实复盘；官方通报是优先核验来源，不是开工前置条件。不得代演真实受害者，不编对白、动机、心理、未公开经历或临终过程；未知事实删去或明确标为不确定。未成年人须额外保护身份与隐私，不呈现不必要的创伤细节。极端减肥、自伤/自杀等内容不提供可操作方法。具体报道文字、照片和视频仍按各自权利状态使用，不因事实可复盘而自动取得素材授权。
