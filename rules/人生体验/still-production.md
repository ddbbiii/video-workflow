# 人生体验线静帧生产规程 v3.0

生效日期：2026-11-20。当前只简化人物；背景保留原手绘画风，旧猫头人专用约束暂时归档。

## 1. 开工核对

- 读取本线 `README.md`、`style.md`、`character.md`、`references.md`、`color-script.md`，及共享 `visual-state.md`、`shot-composition.md`、`script-workflow.md` §15/§15.1、`video-workflow.md` 相关阶段和当前 `shared/image-api/channel-policy.json`。
- 记录实际规则版本，不以旧集状态、脚本注释或记忆替代现行规则。
- 剧本锁定后再批量生图；准备本集 `image/color-plan.json`、角色识别信息与场地连续性锚点。
- 启用旧生成器前检查其风格块、猫脸/猫爪描述、固定参考路径、背景细节与色彩限制；完成适配后才能用于新方案。旧集脚本不因仍可运行而自动合规。

## 2. 事实与参考预检

- 生图前先确定每镜的视觉表达：角色表演、环境/物件证据、主观视点或结果状态；写清观众要看到的具体事实。人物动作、数量、方向、道具关系及全部参考在分镜准备中确定，不交给模型补全。无人镜不得残留人物动作或角色描述。

- 逐镜保留 `shot_type`、`scene_id`、`has_character`、`fact`、`cast`、`closeup_part`、`view_angle` 等共享字段要求。
- cue、visual、fact 与 cast 的人物、数量、动作及道具归属一致，不为调整镜头配比删除必要人物。
- 按当前角色记录检查所需参考是否存在、可读、符合简笔造型；多人镜覆盖在场人物，不能只提供主角。
- 参考锁定身份与画法，人物疲劳、污损、伤势和环境变化按剧情落实；不默认人物或场地始终洁净。

## 3. 提示词与生成

- 最终提示词包含：当集圆头手绘人物画法与原手绘背景画法、镜头构图、场景事实、人物身份与状态、道具归属、颜色与光线意图、无文字约束。
- 人物统一采用参考片方向的圆头手绘人物；完整袖子和裤腿、约3～3.5头身、简洁表情与克制明暗，按当集参考锁定。不得沿用旧生成器的细黑杆四肢、纯白无阴影头、禁止耳朵及5～6头身约束。
- 空镜明确无人，不残留猫头人或其他角色专用块；人物镜表达完整动作与人物/场地关系。
- 不自动拼入旧猫头猫爪块；环境继续使用原手绘背景画法，保留材质、空间、光照及场地锚点。人物简化不覆盖环境层；不靠固定色块数或旧色相阈值判断美术质量。
- 保留可追溯的分层流程：无人镜可一遍出图；人物镜先出无人环境，再结合环境及对应人物参考合成。局部编辑既有图可沿用源图，不强制重做两遍。
- 路由、模型、并发与回退遵守当前通道策略，不硬编码旧配置；保存版本化环境图，避免覆盖已使用底图。

## 4. 小样与记录

- 新人物方案先在同一张保留原画风的背景中比较，避免同时改背景干扰判断；再做覆盖人物动作/情绪、多人关系与场景空间的小样；有需要再覆盖室内外、日夜与不同章节，检查角色可辨认、动作可读及跨镜连续性。
- 样张用于确定当集采用的设计与发现共性问题；不新增固定小样数量、逐镜美术 PASS 表或审批环节。
- sidecar 保存最终完整 prompt、版本/hash、cue/visual/fact/cast/shot_type/scene_id、全部参考及用途、环境与合成路径、生成阶段、channel/model/endpoint、并发队列、请求结果、原始尺寸和归一化方式、实际检查状态。
- 成图检查身份、关键剧情事实、动作与道具、连续性、无文字以及文件/尺寸；进入时间线统一为 1920×1080。原尺寸检查人物，联系表用于全局连续性和初筛。
- 色彩统计如有运行，只作诊断；未执行的检查如实记录，不宣称通过。

## 5. 问题处理

规则冲突、必要数据/参考缺失、cue/cast 冲突、身份或剧情共性错误、最终 prompt 未保存、必要分层缺失或底图被覆盖时，先停止受影响镜头并修正。细小美术差异通过提示词优化，不自动重抽或阻塞其他镜头。
