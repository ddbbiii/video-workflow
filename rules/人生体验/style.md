# 人生体验 · 画风规则（v3.7，2026-11-15）

> 2026-11-15 当前执行：状态、构图、光源数量、固定尺度/色彩数值及配比属于提示词指导和诊断，不作为审美停机/逐镜PASS门禁；以下旧阈值或清单若仍含硬性措辞，以本条为准。保留身份、关键剧情事实、文件引用与最终技术检查。局部编辑既有图可沿用源图，不强制从零重做两遍。


> 2026-11-14 用户逐轮试片后确认：「画风就按照这版持久化下来」。v3 取代 v1/v2；v3.1 补细节预算；v3.2 补构图语法与三层信息；v3.3 补平涂验收；
> **v3.4 改为两层画风：人物是剪纸（平涂），环境是手绘背景（允许渐变、AO、材质、三光源）**——起因：用户指出参考片的环境精致度远高于我们，而 v3.2 把"渐变/质感"连同环境一起禁掉了。
> **v3.5**：把 v3.4 里"每镜 12–20 件物件 / 每镜三色相 / 每镜两种材质"这类数量指标，换成**功能式（去人读图）+ 锚点式 + 负向清单 + 章级统计**——起因：用户指出数量上限会逼模型堆杂物，应按需求来。
> 只管画面与光的写法；主角外形见 `character.md` v7，颜色见 `color-script.md` v1.4，运镜见 `../shared/camera-motion/`。
> 本线不做片头、不做画面文字。

## 一、一句话

**平涂的人物，站在被认真画过的场景里，只有一颗猫头保留细节。**
人物与道具是剪纸：2–3 个平色、硬边、单一线宽；环境是手绘背景：可以有渐变、环境光遮蔽、材质与有动机的光源。两者共用同一条线宽与同一套色板，但完成度不同——这就是精致度的来源。

## 二、画面分层

| 层 | 规则 |
|---|---|
| 线稿 | **单一线宽**（深灰蓝 `#3E464A`），不粗不细、不抖；物体只用必要轮廓，允许少量手绘抖动；不用排线、不用交叉线 |
| 人物上色 | **平色块，每个物体最多 2–3 个色调**；灰连帽衫一块灰、黑裤一块黑，不用渐变、不用软阴影 |
| 猫头（**唯一保留细节的部位**） | 折耳橘虎斑：圆脸厚颊、短口鼻、小耳前折贴颅顶、大圆黑瞳 + 窄琥珀边 + 一点高光、粉鼻、奶油口鼻垫、白胡须、胸口白围兜、额头 M 纹；毛用 2–3 个平色 + 几笔短线表现，**不做写实毛、不做照片感** |
| 手/脚 | **猫爪**：圆润短爪、三趾线、一点粉色肉垫；**没有人手手指、没有人脚趾、不穿鞋**；裤脚收在踝上 |
| 背景 | **按 §2.1 环境规格执行**：允许柔和渐变、AO、材质与多光源；不再是"一块平色 + 大面积留白" |
| 光 | 按场景选择主光和必要补光，不固定光源数量，有衰减、接触阴影与投影；**人物身上仍是硬边阴影** |
| 质感 | 人物与道具：不加胶片颗粒、不加纸纹；环境允许灰尘、碎屑、木纹、金属拼缝等材质，但**不加颗粒噪点滤镜** |
| 色彩 | 冷中性基调，白墙白纸是中性白（不是米黄）；色相按章约束，不按镜（§2.2）；高饱和只留一处，由该镜 `color-plan.json` 指定 |

### 2.1 环境层规格（v3.5：改成功能式 / 锚点式 / 负向式，不再数物件）

参考片对照结论：**人物是剪纸，环境是手绘背景。** 环境不靠"数够多少件"来保证，靠下面四类可判的约束：

**A. 功能式——去掉人物还读得懂**
- E 镜：把人从画面里去掉，**仍能认出这是哪、往哪走**；
- M 镜：**能看出人物正在用哪件家具或陈设**；
- C 镜：关键细节（脸 / 手 / 道具）占得住画面，背景可以空；
- 判定方式：每 24 镜一批，抽 3 张做"去人读图"，读不出就补，**不数物件**。

**B. 锚点式——用可重复识别物代替数量**
- 每个场地定 **2–3 个可重复锚点**（见 `shot-composition.md` §四），全片至少出现 2 次、尽量同角度，生图时强制出现；
- 物件多少是锚点是否到位的副产品，规则不写数字。

**C. 负向式——四条禁止，可判、不逼人堆料**
- 不许"**空墙 + 一个人**"：墙面必须有一处结构或挂件；
- 不许"**画面里没有可见光源**"：至少看到一盏灯、一扇窗或一处漏光；
- 不许"**纯平背景**"：背景至少一处材质或明暗变化；
- 不许"**整幅只有两个色块**"：人物与背景不能同色同明度。

**D. 明暗与纵深（保留）**
- 环境允许柔和渐变与 AO，**人物与道具的阴影仍为硬边**；要有接触阴影与投影；
- 建立空间时可用三层和前景压边（特写不强求）：前景家具/门框压住边缘 → 中景人物 → 远景窗 / 门洞 / 通道；底部 1/5 留安全区。

### 2.2 色相：只按章约束（v3.5）

- 单镜**不设色相下限**：夜戏、绿光楼梯间、手电特写允许只有 1–2 色；
- 章级统计：参考每章平均 ≥3 色相、全片 R/B ≤1.15、平均亮度 ≥0.45；这些是历史诊断参考值而非审美硬门禁，并且**不许整片单色**；
- 需要刻意压成单色时，在该镜 `color-plan.json` 里写 `"muted": true` 声明，不算违规；
- 物件数、材质数、色相数仍会统计，但**只进体检报表，不做门禁**。

## 三、构图与镜头

### 3.1 构图语法（2026-11-14 定版，替代「人物占画面几分之几」）

> 真源：`../shared/shot-composition.md` §五（悬疑线与本线共用；本线只调默认档位）。

**人物尺寸由场景尺度决定，不得为凑构图把人物压小。** 占比靠四个参数控制：

| 参数 | 选项 | 作用 |
|---|---|---|
| 机位距离 | 近（1–2 m）／中（3–4 m）／远（贴对面墙或门洞外） | 决定画面里出现多少房间 |
| 焦段 | 24–28mm 广角／35mm 标准／50–85mm 长焦 | 广角拉出空间、长焦压缩背景 |
| 人物站位 | 左三分之一线／右三分之一线（**不居中**） | 把另外三分之二让给环境 |
| 前景层 | 桌角／椅背／门框／窗框／楼梯扶手／货架边 | 压住画面边角，承担视觉重量 |

每镜提示词按这个顺序写，**不写百分比**：

```text
机位：<近/中/远>，相机高度 <视平线/略低/略高>，从 <房间另一头/门口/楼梯下> 看过去；
焦段：<24mm / 35mm / 85mm>；
人物：站在画面 <左/右> 三分之一线，身高约为门高的 0.6（正常成年比例），不居中；
前景：<门框 / 桌角 / 窗框 / 扶手> 压住画面 <左下/右侧> 四分之一；
环境占画面：三分之二，要能看清 <墙面/窗/床/柜> 的完整轮廓。
```

E / M / C 与参数的三档对应：

| 类 | 机位 | 焦段 | 站位 | 前景 | 人物占画面高 |
|---|---|---|---|---|---|
| E | 远 | 24–28mm | 边缘或不在画 | 门框/栏杆 | ≤1/5 |
| M | 中 | 35mm | 左右三分线 | 桌角/窗框/门框 | 约 1/3 |
| C | 近 | 85mm | 可居中 | 虚化一点 | ≥1/2 |

### 3.2 空间层次提示词建议（按镜头需要使用）

| 层 | 要求 | 例 |
|---|---|---|
| 前景 | 一件压住画面边角的具体物件 | 掀开的桌角、翻倒的收银台、锈扶手、地上的锤子 |
| 中景 | 人物正在使用或刚用过的家具/陈设 | 床、桌、货架、台阶、背包 |
| 远景 | 一个能定位的窗口或通道 | 窗、门洞、走廊尽头、街口、门后的长街 |

只写"背景是一个房间"不合格；要写到**能数出物件**（"床下塞着纸箱""墙上贴着一张表""窗台摆着绿植"）。

### 3.3 其它构图约定

- 16:9 横版；中景/全景为主。
- 情绪镜才用近景：整颗头占画面 1/3 以上，靠眼皮、瞳孔、嘴角演。
- 常用「门/窗/洞口/车厢」做画框。
- 第一人称插入镜（手捧物件、推门、伸手）：**手是猫爪**，爪要画清楚，不画成肉团。
- 光影方向每场只定一个。
- 画面底部约 1/5 留作安全区：不放关键信息（用户后期可能加字幕）。

### 3.4 细节控制

人物与道具保持简化平涂；环境按 §2.1 的功能、锚点和负向清单完成，不用物件数或细节数凑丰富度。环境允许渐变、AO、材质和投影；全图仍禁止胶片颗粒、纸纹、厚涂、无关装饰和任何文字。

## 四、风格块（英文，直接进生图 prompt）

### 叙事状态补充（v3.6）

人物平涂、线稿干净是画法要求，不要求衣物/面部/场地始终洁净。按 `../shared/visual-state.md` 设计并验收人物与环境的当下状态；污渍、破损可用克制硬边色块表现，不增加写实皮肤、喷枪或噪点。保持正常/异常、早期/后期和公共/私人空间的差异。身份参考不能覆盖剧情状态。

风格块**不含任何色名**；颜色由每镜「色彩与光线」行给（见 §六）。人物/道具与环境分层描述，禁止使用“一切平涂”“整幅禁渐变”一类会覆盖环境规则的全局表述。

```text
Two-layer hand-drawn 2D illustration, 16:9. Clean flat fills describe the rendering technique, not pristine
physical condition. Apply the specified story-driven wear, stains and damage using restrained hard-edged shapes;
preserve identity and the established style. Characters and props use flat fills, at most two or three
hard-edged tones per object, one consistent dark grey-blue outline weight; no gradients, airbrush, soft shading,
paper texture or film grain on characters or props. The environment is a carefully painted background and may use
restrained gradients, ambient occlusion, material texture, depth and motivated lighting appropriate to the scene. Show a visible
light source, its falloff, contact shadows and cast shadows. Keep character shadows hard-edged. Use the episode's
palette and light plan; do not impose a global colour grade. Avoid empty wall plus person, featureless flat
backgrounds, and frames made of only two large colour fields. Keep the location and viewing direction readable.
No text, letters, numbers, subtitles, watermark, logo, UI, comic symbols or sound-effect marks.
```

> v3.3 的禁止喷枪/柔光/AO 只约束人物与道具。v3.4 起环境允许 AO、渐变和材质；不得把人物的负向限制复制到环境层。

主角块（含猫头细节与猫爪）见 `character.md` §五；负面同文件。

## 五、不同场景的加法

| 场景 | 加什么 | 不要什么 |
|---|---|---|
| 出租屋（室内） | 以 `color-plan.json.locations` 的门牌/入口识别、折叠桌、铁架床、掉皮墙角为可复用锚点；至少有可见窗/灯光源 | 空墙+人物、无功能堆料 |
| 楼道/楼梯 | 防火门、应急灯、楼梯走向；体现墙面和地面材质 | 把楼道画成无出口的平墙 |
| 街道 | 楼体墙根、车辆/路沿、可读的道路去向 | 招牌文字、无关碎屑堆料 |
| 便利店 | 歪招牌、货架、收银台按 `locations` 重复出现；门口光源可见 | 可读包装字、价签、无关商品细节 |
| 铁门/结尾 | 双开结构、焊缝、新锁；门后空间方向清楚 | 遮住焊缝/锁的前景或装饰 |

## 六、生图约定

- 生图原始尺寸与通道按 `shared/image-api/channel-policy.json` 当前 active 策略；进入本线视频时间线的静帧统一验收为 1920×1080，并在 sidecar 中记录原始尺寸与归一化方式。
- **脸/表情参考**：一律使用 `image/refs/ref-face.png`（唯一脸部参考，1024²，由用户那只猫裁出）；表情靠提示词写（只动眼皮/瞳孔/嘴角），**不发任何表情拼图**。
- **站姿/全身参考**：需要 v8 四视图（猫爪、赤脚、平涂），**v8 未出前站姿/全身镜不得开跑**；配角镜附 `ref-helper-a/b/c.png` 对应定装。参考组合与全部源图记进 sidecar；缺图即停。
- **每镜提示词** = 风格块（§四，无色名）+ 场景事实卡 + 「色彩与光线」行 + 对应角色/角度/表情参考说明 + 道具归属 + 负面。以实际发送给 API 的完整 prompt 验收，不以模板存在代替。
- **分层生成**：`cast=none` 且 cue/fact 确认无人时一遍出图，使用 rich 环境和明确无人约束；`cast` 含角色时走两遍——先生成无人环境底图，再以「场景｜全部角色参考」合成单幅画面。无人镜不得残留任何角色专用描述。具体预检与停机条件见 `still-production.md`。

### 6.1 参考图验收（2026-11-14 新增）

人物与配角参考图会被每一镜继承，**人物参考不合格等于整集不合格**。出批量前逐张过：

- [ ] 每部位 ≤3 个平色，**没有喷枪式过渡**（脸颊、鼻梁、衣服褶皱上不能出现平滑灰阶）；
- [ ] 没有柔光边、没有 AO、没有环境光漫射；
- [ ] 线宽一致、没有粗细变化；
- [ ] 与 `ref-face.png` 并排看是同一张脸。

任何一条不过 → 先修参考图，再谈批量。2026-11-14 EP03 v3 就是标准脸带柔光，导致全片偏"3D 渲染"。
- 「色彩与光线」行必填三段（色值取该集 `image/color-plan.json`）：

  ```text
  色彩与光线：<时间段 + 主光方位/类型 + 色温K>；只用这五个颜色 <#.. #.. #.. #.. #..>（其余压成灰阶/低饱和）；
  全图只允许一处高饱和，且只能是<这一镜的主体>。
  ```

- **表情行必填**，六档取自 `character.md` §六，逐镜在 `story/expressions.json` 里定；只动眼皮、瞳孔、嘴角。
- **道具归属**：画面里谁拿什么，写进 `story/props.json`，并加一句「不要把道具塞进另一个人手里」。
- 不把文字、编号、字幕、logo 交给模型；**画面内不做任何文字层**。
- 同一场的光源方向、时间、天气写进事实卡，避免一镜一变。

## 七、检查与优化（身份/剧情/技术要求保留，美术建议不自动触发重出）

- [ ] **叙事状态**：按 `../shared/visual-state.md` 将时间原因、面部/衣物/场地状态和群体关系写进提示词；用缩略图辅助定位明显偏差，不增独立状态门禁。
- [ ] 人物与道具：线稿单一线宽、平涂 2–3 色、硬边；没有排线、没有喷枪过渡、没有柔光边。
- [ ] 主角是 `character.md` 的折耳橘虎斑猫头；脸与参考图并排看是同一只猫。
- [ ] **手和脚是猫爪**：三趾线、肉垫；没有人类手指/脚趾，没有鞋。
- [ ] 表情落在该镜指定的那一档（平静/疲惫/发愣/难堪/勉强笑/发憋），1080p 下能分辨。
- [ ] **环境层达标**（§2.1）：去人读图能认出场地与朝向；锚点到位；四条禁止项都没犯（空墙+人 / 无可见光源 / 纯平背景 / 只有两个色块）。
- [ ] **构图语法落地**：机位/焦段/站位/前景四项都有，人物不居中、不被压小（见 §3.1）。
- [ ] **人物尺度合理**：在提示词中用同深度门/家具说明角色尺度，结合透视与遮挡判断，不用固定像素比自动判返工。
- [ ] **色彩**（§2.2）：章级色相、R/B、亮度等作为偏色诊断参考，不单凭数值返工；单镜不卡色相数（刻意单色需在 `color-plan.json` 写 `muted: true`）。
- [ ] 画面无文字、水印、logo、边框、漫画音效符号。
- [ ] 同一角色跨镜一致（头型、眼距、毛色、服装、爪）；配角是**简笔圆头小人**（`character.md` §4.1），不是写实真人。
- [ ] 量化色检跑过（`qa/audit_color_v3.py` 同口径），`qa/color_audit.json` 用于定位偏色，不单凭数值阻断全量。
- [ ] 构图与三层信息用**联系表人工过**；像素占比类自动指标只作参考（木器会被误判为主角）。
- [ ] **人物镜必须 1:1 目检**（原尺寸看脸与手）；24 格联系表只做初筛，缩略图看不出木偶手、柔光与换衣（2026-11-14 EP03 教训）。
- [ ] **平涂度**：人物脸上不能有平滑灰阶过渡、衣服不能有柔光边；不过即参考图或提示词有问题，不是"模型风格"。

## 八、明确不做

- 不做 3D、不做写实、不做日漫、不做厚涂、不做 Q 版吉祥物。
- **不给环境做"平涂省事"**：避免无意的空背景和零材质；单光源可按剧情使用，不以光源数量判断质量（v3.4 起）。
- 不把色板写进风格块；不做「整集一个调色」；不用后期 LUT 掩盖生图偏色。
- 不做「一人一档画风按题材选」；本线只有这一种画风。
- **不用「人物占画面几分之几」这类指令控制构图**；不为中心构图把人物压小。
- **不用 `zoompan` 做推拉**（整数取整会抖），按 `../shared/camera-motion/MOTION_GUIDELINES.md` 走 affine 浮点后端。
- 不在未锁剧本前批量生图。
