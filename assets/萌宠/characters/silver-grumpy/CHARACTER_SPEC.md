## 身份锚点（缺一即换）

| 项 | 定义 |
| --- | --- |
| 品种 | 长毛银渐层（金吉拉型，波斯系扁圆脸） |
| 毛色 | 中等银灰底；头顶、背、体侧、腿有深灰毛尖；白色只在下巴、胸前毛领、腹部 |
| 花纹 | 额头 M 纹，腿部淡虎斑，尾巴深灰渐层、极蓬松 |
| 脸型 | 扁圆、短口鼻、宽颊、眼距宽；耳相对头偏小，耳尖略尖（不是折耳） |
| 眼睛 | 金黄偏琥珀；不绿、不蓝、不荧光 |
| 鼻子 | 暗粉/砖粉鼻镜，鼻梁有深色纹延伸 |
| 体态 | 毛量大显圆，四肢短粗，尾巴如羽扇 |
| 神色 | **天生臭脸**：眉压低、嘴角平、常半眯眼。这是辨识点和喜剧资产，不要修成可爱无辜脸 |

## 禁止项（出现即废片）

- 蓝眼、绿眼、荧光黄绿眼
- 短毛、圆眼大眼无辜脸、尖脸大耳
- 大面积白斑（白只允许在下巴、胸前毛领、腹部）
- 折耳、布偶猫花色、橘猫/狸花花纹
- 文字、水印、项圈、衣服（镜头明确要求除外）
