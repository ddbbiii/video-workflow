# 悬疑单集输入单

> 填完存为 `INPUT_<slug>.md`，放进单集目录，发我路径。

| # | 项目 | 必填 / 选填 | 说明 |
|---|---|---|---|
| 1 | 标题 | 必填 | 4–40 字 |
| 2 | 故事母题 | 必填 | 一句话 ≤40 字：谁遇到什么异常、做了什么、付出什么代价 |
| 3 | 故事主线 | 必填 | 按事件/情节点写，≥6 个节点；标出反转与每条物证落在哪个节点；不按段、不标时间 |
| 4 | 主悬念 / 次悬念 / 反转 | 必填 | 三行；主悬念一个，次悬念最多一个；反转写清“哪条证据改写了前面哪个理解” |
| 5 | 三条可拍物证 | 必填 | 每条 = 具体物件 + 在哪个节点出现 + 印证什么；至少一条要改写理解 |
| 6 | 结尾 | 必填 | 停在哪个画面或哪句话；留 1–2 个未知 |
| 7 | 来源与授权 | 必填 | 原创 / 公版（写出处）/ 外部素材（subreddit · 作者 · 链接 · 授权状态） |
| 8 | 目标时长 | 必填 | 8–20 分钟，写分钟数 |
| 9 | 必须覆盖 | 选填 | 一行一条 |
| 10 | 必须避免 | 选填 | 一行一条 |
| 11 | 参考材料 | 选填 | 原文路径 / 链接 / 截图 |
| 12 | 备注 | 选填 | 画面氛围、参考材料、其他要求；交付固定为正文视频 + SRT，不写声线/片头 |
