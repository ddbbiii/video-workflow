# 助眠单集输入单

> 填完存为 `INPUT_<slug>.md`，放进单集目录，发我路径。
> 其余按 `rules/助眠解说/input-spec.md` §4 默认值执行。

| # | 项目 | 必填 / 选填 | 说明 |
|---|---|---|---|
| 1 | 标题 | 必填 | 4–40 字；不能写“待定 / 由你拟 / 无” |
| 2 | 主题 | 必填 | 一句话：具体对象 + 一个矛盾 / 问题 |
| 3 | 引入 | 必填 | 1–3 句、40–200 字；具体场景 / 问题，能直接当正文开头；不要“大家好 / 今天我们来聊聊” |
| 4 | 章节大纲 | 必填 | ≥3 章，章名 + 每章一句；或“见锁定稿”+ 路径 |
| 5 | 必须覆盖 | 选填 | 有必须讲到的事实 / 场景就写，一行一条 |
| 6 | 必须避免 | 选填 | 有不能讲错的、不能出现的画面 / 说法就写，一行一条 |
| 7 | 时长 | 选填 | 有分钟数就写；不写按稿定 |
| 8 | 参考材料 | 选填 | 有资料写路径 / 链接 / 书名；不写默认允许公开检索 |
| 9 | 备注 | 选填 | 画面氛围、参考材料、特殊要求；配音/字幕/封面/片头不做，写了也按规则不产 |
