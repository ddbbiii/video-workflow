# 视频工作区

整个工作区采用 projects/、assets/、rules/ 分层布局，目录真源：indexes/DIRECTORY_STRUCTURE.md。

- projects/对应线路/：项目、单集、草稿、日志、归档。
- assets/对应线路/：可复用角色、声线、场景和道具。
- rules/对应线路/：线路规则；rules/shared/：全局规则。
- assets/shared/：共用素材；shared/：工具、工作流、运行时、GPU 队列、交换与工作目录。
- indexes/：线路、文档、资产索引。
- todos/：全部线路和共用事项的统一待办入口。

线路为助眠解说、悬疑动漫、猎奇、创意、音乐线、抖音特效；状态见各项目 LINE_STATE.md。外卖之谜位于 projects/unassigned/外卖之谜/。旧线路根目录已物理迁移，不保留兼容别名。

根目录规范包含 projects/、assets/、rules/、indexes/、shared/、todos/ 和本文件。完整职责与子目录规则见 indexes/DIRECTORY_STRUCTURE.md。
