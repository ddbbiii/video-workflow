## 终端交付（2026-11-14，全线路）

- **每集只交两件**：`video/final/<线路>_<中文剧名>_正文_vN.mp4`（无片头、无标题、无字幕、无文字层、无音轨、无字幕流、无烧录）＋ `video/srt/` 下同基名 `.srt`（覆盖正文，`00:00:00,000` 起，估算时间轴）。
- 用户原话：「成品视频只包括完整的正文，不包含引入+标题+字幕+配音，只输出一个视频+对应的SRT文件就行」「配音我自己解决，不再需要本地生成」。
- **不产**片头/引入/标题卡/章节卡、配音/TTS/WAV/分轨、混音/BGM、字幕烧录/ASS、封面、预览、成品卡、成品索引；不落 `shared/delivery/`，不登记 `douyin成品.md`。
- 配音、混音、BGM、烧录、发布全部用户手动，助手不代做、不提醒接力。
- 旧成品不回改、不重制（2026-11-14 用户指令：「旧成品不用再改」）。
- 真源：`rules/shared/video-workflow.md`、`rules/shared/delivery.md`、`rules/shared/srt.md`。

## SRT（2026-11-14）

- 只覆盖正文，时间轴从 0 开始；文本只取锁定稿 `cue`；每条 ≤20 可见字（汉/数/字母各计 1，标点不计）；单行、80% 宽内；只在分句标点拆条。
- 默认语速：助眠 3.8 字/秒、悬疑约 3.6、人生体验 4.8；注明「估算时间轴，未对真实人声校准」，不跑 ASR。
- 全部 cue 去标点拼接 == 锁定正文；`check_srt.py` PASS 才交付；SRT 与视频分目录（`video/srt/` vs `video/final/`）。

## 门禁

- 两道人工门禁：关键动态、正文成片；没有片头门禁。
- 交付前：`ffprobe` 0 音频流/0 字幕流；像素白黑屏 ≥1s 为 0；CFR 均匀；时长=帧数/帧率；SRT 门禁 PASS；助眠白边门禁照旧。

## 旁白硬规则（2026-11-11 事故后）

- **`cue` 只写观众要听到的话**；镜头/画面/转场/字幕/音效/BGM 这类制作术语一律不得进旁白与字幕。
- 真源 `rules/shared/script-workflow.md` §12；工具 `shared/workflows/script-qa/lint_narration.py`（检查）/ `guard.py`（脚本调用即阻断）。
- 写稿后、出 SRT 前各跑一次；命中即停。
