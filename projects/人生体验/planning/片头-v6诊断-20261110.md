## 一、量测：这一版「静」到什么程度

同一把尺子（1920→320×180 灰阶，逐帧差分均值）量 v6 与原片片头：

| 时间窗 | v6 | 参考片 | 判读 |
|---|---|---|---|
| 0.0–2.0 s | 0.25–0.26 | 5.7 / 13.3 / 16.7 / 12.2 | **v6 只有颗粒噪点在动**，参考片是每帧重画 |
| 2.0–4.0 s | 0.25–0.26 | 8.4 / 3.0 / 2.4 / 5.6 | v6 仍是同一张图 |
| 4.0–6.2 s | 10.3–12.9 | 1.9–5.6 | v6 靠**切**，参考靠**连续运动** |
| 6.2–6.6 s | 20.8（峰值 132） | — | 白闪，不是运动 |
| 7.0–9.4 s | 0.30–0.32 | 0.001–0.25（黑卡） | **和「什么都没发生」同级** |

- 我们自己的颗粒是 σ=2，落到帧差就是 0.25–0.32。**静止段的数值正好贴着这个底噪**——意思是画面里一个字都没动过。
- 参考片 0.37–1.80 s 之间有 **44 次 >8 的跳变**（约每 1.3 帧一次，等于每帧重画）；全片头 60 次。v6 全片只有 **19 次**，且全部集中在 4.1–6.6 s。
- 结构性重复：
  - `IDS[0] = "S21"` 与 0–4.1 s 的开场图是**同一张**，4.10 s 的第一个「短切」只是把它从 1.02 倍退回 1.00 倍 → **第一次切等于没切**。
  - 0–4.45 s 是同一张图（4.45 s，47%）；
  - 卧室画面合计约 **7.9 s / 9.4 s = 84%**（S21 床铺 4.45 s + S59 房间 0.35 s + C 宿舍床 3.13 s）。
  - 片头一共 **5 张唯一画面**（S21 / S27 / S35 / S38 / S43 / S59 里 S21 出现两次）。

> 观众前 4 秒看到的是一张夜景插画 + 一条字幕，没有任何「信息在推进」的信号。这就是「效果差」的第一因，跟调色、字体关系都不大。

## 二、P0（不改就不算修好）

### P0-1 69% 时长是静止画面

- 证据：0–4.1 s 帧差 0.25（推近只有 1.00→1.02，即 4.8 px/s，肉眼读不出运动）；7.0–9.4 s 帧差 0.32。
- 参考片同一段是 13–16，靠「切片逐块展开 + 每帧 RGB 撕裂 + 1–2 px 抖动」撑住。
- 修法：把「一张图 + 慢推」换掉。任一 0.5 s 窗口内必须 ≥6；不能靠加噪点凑。
- 验收线：`窗口帧差 ≥6`、`静止段连续 ≤0.5 s`。

### P0-2 规则里的三段结构全丢，且系列标记消失

| 规则 intro.md 锁的 | v6 实际 |
|---|---|
| 0.12–2.0 切片拼贴（6 块从细缝展开） | 一张静帧，无切片、无撕边、无面板 |
| 1.80 / 2.20 / 2.60 三次故障硬切（同一张主视觉） | 4.10 起 6 张**不同**静帧切（不是同一张，也不是故障） |
| 1.5–4.2 红字两行钩子骑在拼贴上 | 2 行金黄字在 6.27 s 才出，压在一张不动的床上 |
| 4.4–5.2 灰白关卡号（副本 No.001 / 第一级） | **完全没有** |
| 5.2–6.4 红字章节名 + 灰残影 | 无（与标题合并） |
| 6.4–6.6 收尾 → 硬切正文 | 9.4 s 硬切（无收尾设计） |
| 钩子 / 关卡号 / 章节名**都必须有人声** | 只有 2 句 VO；关卡号没词 |

- 「副本 No.001 / 第一级」是这条线的系列记忆点（`LINE_STATE.md` §已定：「片头不出现账号名，只放副本号或第一级」）。v6 把它整段删了 → 每期片头将没有可累积的识别符。
- 修法：要么按规则重做（见 §五 A），要么先把规则改成实际做法再继续——现在是「规则写一套、脚本做一套」，下一集还会漂。

### P0-3 红字变金黄 + 黑粗边，质感直接跑偏

- 规则：钩子 `#E01B12` 红，黑边 4 px，黑挤出 5/9 px，深灰残影 blur 5 px，±2–3 px 正弦横移，RGB 分离。
- v6 `draw_title2()`：字身 `#F2C230` 金黄、`stroke_width` 7/9 黑、偏移层用 `(192,57,43)` 红。**金黄 + 粗黑边 = 综艺花字**，与参考片的红毛笔不是一个语域。
- 缺三件：灰残影、正弦横移、RGB 分离（逐帧抖动也没有）。
- 字号 172 / 158 px（字高≈170）比参考 110–130 px 大一档，两行占画面高 32%，手机上看是一块「字墙」。
- 修法：换回 `#E01B12`；字号降到 130–140；保留黑挤出 5/9 + **一层**灰残影（左下 20–30 px，blur 5）；加 ±2 px 抖动。
- 验收：抽标题帧取色，R>190 / G<60 / B<45；灰残影可见且只有一层。

## 三、P1（观感与技术的硬伤）

### P1-4 「6 短切」= 6 张静帧 ×0.35 s + 每张前 3 帧 4×4

- 0.35 s = 10 帧，读不出画面内容；每张前 `local < 2.2/30` 的 3 帧网格 = 100 ms，**16 格一张也读不出来**。
- 观感是「静—闪—静—闪」，像渲染丢帧，不像蒙太奇。
- 4×4 每格 466×256，在手机上等于缩略图墙。
- 修法（二选一）：
  - (a) 网格给够 0.40–0.60 s 并配一记 hit（才叫「人生碎片闪现」），6 次减到 2–3 次；
  - (b) 去掉网格，6 张静帧改成 6 个**有运动**的短切（推/拉/横移，0.20–0.30 s），靠运动而非闪烁制造节奏。

### P1-5 白闪 2 帧 + 铺垫不足 = 「炸帧」

- 6.20–6.27：1 帧 82% 白 + 1 帧 0.55 模糊，窗内峰值帧差 132（全片最大）。
- 前面只有 0.45 s / 0.20 增益的 whoosh，riser 没到位就白了。
- 修法：去掉纯白闪，改「0.25 s 渐亮到 0.9 + 1–2 帧黑」；riser 从 5.6 s 起爬到 −18 dB，闪帧处落 hit。

### P1-6 标题用位图逐帧缩放，0.35 s 后硬刹

- `draw_title2()` 每帧 `crop → LANCZOS resize → paste`，paste 的 y = `int(250 + (1-scale)*90)`。
- 结果：6.27–6.62 字在持续放大约 4%（≈4 px/帧，全帧都在重采样 → 边缘爬行），6.63 一步收住，该帧帧差 9.4——是字卡段唯一一次跳帧，正好在观众读字的时候。
- 规则本来就禁「位图逐帧缩放」；正确做法是 ASS/libass 矢量 `\t`（本手册 §3 第 6 条），或一次预渲染 + 亚像素定位。

### P1-7 标题比口播晚 0.85 s，且闪切段一个字都没有

- VO 第 2 句入点 5.35（实测语音 5.42 起），标题 6.27 才出、alpha 0.10 s → **0.85 s 时差**。
- 5.42–6.27 这段是网格闪切，画面上无字幕无标题 → 观众听到「毕业找不到工作」，不知道该看哪。
- 修法：标题起点 = 口播起点 +0.2 s（5.55–5.60），或把 VO 第 2 句推迟到 6.05。

### P1-8 片头→正文接缝有 0.196 s 绝对数字静音

- 实测：`9.404 s` 起连续 0.196 s 采样全零（−99 / −173 dBFS）；片头 SFX 尾在 8.9 s 已掉到 −49 dBFS。
- 听感是「咔」一下断掉再进正文；正文本身是干声（`qa.md` 已知问题 5），接缝前后两段底噪还不一样。
- 修法：片头尾 0.5 s 用 drone 收而不是静音；跨接缝延续 0.3 s 底噪或用一声过渡 hit；正文补 −38 dB 室内底噪（待定项，建议这版就定）。

### P1-9 中间产物过载 + 侧链是死代码

- `intro-v6-mix.wav` = **−10.95 LUFS / TP −0.44**，规则是 −15±1 LUFS / TP ≤ −1.0；且全程 `tanh(x*1.08)` 软削波，会咬口播齿音。
- 成片因为整体 loudnorm 到 −16.17 才没爆（正文 −15.91），所以现在**听不出**；但只要有人直接拿 `intro-v6-mix.wav` 拼接就会爆。
- `build_intro_v6_audio.py` 里 `env` 侧链算完没用（第 96–100 行，注释写着 do not duck）→ 口播其实没有 ducking。
- 修法：mix 阶段直接出 −15 LUFS / TP ≤ −1.5，去掉 tanh，侧链接上。

## 六、建议新增的 5 条自动门禁

1. **运动**：任意 0.5 s 窗口帧差 ≥6；连续静止 ≤0.5 s（脚本见 `work/intro-v6-audit-20261110/analyze.py`）。
2. **接缝**：全片任意 >50 ms 的数字静音 = FAIL（`silence.py`）。
3. **响度**：中间产物也要 −15±1 LUFS / TP ≤ −1.0，不只测成片。
4. **字词同步**：标题/字卡起点 = 对应口播起点 +0.2 s，误差 ≤0.1 s。
5. **字色**：标题帧取色 R>190 / G<60 / B<45（红），灰残影可见。
