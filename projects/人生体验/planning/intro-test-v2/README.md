## 4×4 pre-roll

用户 2026-11-10 追加：在主片头前先铺 4×4 拼图轮换，再进主片头。

- 16 格，格 466×256，边距 16 / 格间 8；每格从主视觉的不同裁切里轮换。
- 格内每 0.22 s 换一张；每 0.55 s 整行横向轮换一次；白框高亮按 0.07 s/格扫过。
- 1.35–1.8 s 放大到约 2.0 倍并压黑；硬切主片头的 0.12 s 黑场。
- 声音：12 Hz tick + drone + riser，1.62 s 一记 hit。
- 执行件：`shared/compositing/grid_prelude.py`；拼接版 7.22 s。

## 这一版的关键技术点

1. **6 块大面板 + 摄影机拉回**：0.6 s 时只看到 3–4 块大窗（左手/车/城市），不是 11 块小拼贴；摄影机 1.35→1.00、中心从 (0.30,0.65) 移到 (0.50,0.50)，0–1.9 s 完成。
2. **运动拖影 + 早期虚拟快门**：前 1.28 s 把当前帧与前 2 帧按 38%/22% 混合，再叠 0.8–2.2 px 递减高斯模糊；这是第一版最缺的“电影感”，也是 0.6 s 看过去不像原片的主要原因。
3. **散点出现**：6 块面板的 delay 是 0.05/0.15/0.25/0.35/0.55/0.65，不是从左到右依次出现。
4. **故障只在边缘 + 三次 hard cut**：1.80 / 2.20 / 2.60 s 三档；burst 时噪声 12、Unsharp 70%，非 burst 时轻拖影；2.7 s 后画面收住，只用静态颗粒。
5. **红字提前到 1.5 s**：参考片的红字在面板还没拼满时就出现；本验证同步到 1.5 s，3.6 s 收。
6. **红字**：200 px、`#E01B12`、黑挤出 5/9、黑边 4、灰残影、±2.5 px 正弦错位。
7. **调色**：亮度/对比/饱和、冷暗部/暖高光、局部暖光、线稿锐化。

## 解说与音效（本次新增）

### 口播

- 引擎/声线：CosyVoice3 0.5B，**复用助眠线 `b2-warm-male-cosy3`** 参考音，`speed=1.20`；占位文案，不锁最终词。
- **3 句完整话**（WAV 时长；纯口播实际语音更短）：

| 句 | 文案（占位） | WAV 时长 | 入点 |
|---|---|---|---|
| 1 | 这是你剩下的世界。 | 2.20 s | 0.30 |
| 2 | 城市空了，只剩你一个人。 | 2.62 s | 3.30 |
| 3 | 第一级，空城的回声。 | 2.92 s | 6.10 |

- 口播门禁：`check_title_vo.py` 在 **`vo_only.wav`** 上跑，标题窗 3.3–8.2 s；`max_silence 1.74 s`、`title_silence 0.28 s`，**pass**。
- 注意：不能拿全混音跑这个门禁——SFX 会把静音窗填满，测出来“假通过”；必须用纯口播 stem。

### 音效

全部用 numpy 合成，不引用参考片音轨、不引用外部 SFX 库：

- 底：36 Hz 开场 sub + 42/84 Hz drone + 低频风声。
- pre-roll：12 Hz tick、纸片翻动（1.1–5.2 kHz 带通噪声）、riser、1.70 s 一记 impact。
- 主片头：2.35–3.30 riser；3.60 / 4.00 / 4.40 三记 impact（sub + 短 crack + 金属泛音），同步画面故障；4.45 tape stop；4.85 起 heartbeat；8.00 收尾低 boom。
- 混音：bed 在口播下侧链衰减 55%，hits 衰减 35%；loudnorm 后 **−15.2 LUFS / 真峰 −3.4 dBFS**。

## 没有验证

- **口播是占位**：3 句只为卡时间与门禁，不是最终解说词；最终词随当期剧本重写。
- **音效是合成近似**：按参考片的“drone + tick + riser + impact + static”结构做，不引用参考片音轨，也不等于原片听感。
- **没有主角三视图**：主视觉是第一人称手部，不是 `character.md` 的空白头主角。
- **没有正式文案**：钩子/章节名是占位。
