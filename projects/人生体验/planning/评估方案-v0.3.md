# 「人生体验」线路评估方案 v0.3

- 日期：2026-11-10（v0.3：参考片换成《世界上只剩下你一人的人生》，旧两条参考、旧 A/B 画风、旧片头 v1 全部删除）
- 性质：**评估与建线提案，不是开工授权**。付费生图、批量配音、整集生产都要你单独点头。
- 事实依据：`参考拆解-20261110-末日独存.md`；`片头切片-开源方案.md`；`rules/人生体验/`（intro v2 / style / character）；`rules/shared/douyin-reference.md`。
- 成本口径：只算本机占用与 token，不算人工、审片、沟通。
- **范围（2026-11-10 用户定）**：参考片只用于**片头手法、画风、主角**；剧情、人物身份、结构、节奏、结尾、时长由用户逐期定。

## 0 结论先行

1. **新参考 11:14.8、16:9、1080p/30 fps，8 章、105 个正文切点**；不是旧结论的 6:01、4 秒一镜。
2. **片头是 5.4 s 的「切片拼贴 → 红字钩子 → 关卡卡」**；旧 12.4 s 钩子 + 0.25 s 快切标题作废。
3. **画风只有一种**：简笔空白人 + 高细节 2D 手绘废土；旧 A 半写实 / B 条漫分档作废。
4. **主角是系列固定「空白头」载体**：换装、换年龄，不换头、不加鼻、不加发。
5. **切片可开源落地**：FFmpeg + Python（Pillow/NumPy）自建合成，162 帧、分钟级；不需要剪映/CapCut，不需要 Remotion。
6. **先做两件不依赖剧本的验证**：主角三视图 1 张、片头 8.4 s 样片 1 条（4×4 pre-roll 1.8 s + 主片头 6.6 s）；过了再谈整集。

## 3 片头：为什么值得单独做

参考片的片头不是「标题卡」，是**用一张主视觉做一次 2 秒的「展开」**，再用两行红字把前提钉住，最后用关卡卡把「游戏开始」的感觉做出来。它的成本不在拍摄，在合成：

- 6 块面板、逐块展开、错位、撕边、RGB 撕裂、条带位移、噪点、暗角；
- 红字两行 + 灰白关卡号 + 红章节名，三种字、三种运动；
- 5.4 s / 162 帧，逐帧可控。

**可复用件**：`shared/compositing/slice_intro.py`（主片头）+ `grid_prelude.py`（4×4 pre-roll），Pillow + NumPy + FFmpeg，参数写 JSON，每期只换主视觉、文案、时长。已跑通 1.8 s pre-roll + 6.6 s 主片头 = 8.4 s 的解说音效版（`planning/intro-test-v2/`；主视觉 1 次 `new1`，0.02 元）。详细对比见 `片头切片-开源方案.md`。

## 4 画风与主角：为什么这次能收敛

旧 A/B 的问题不是「哪种好看」，是**人物一致性**：半写实脸一换镜就漂，条漫虽然稳但质感低。新参考用「空白头」把这个问题绕开了：

- 没有鼻子、没有发型、没有写实皮肤 → 模型没有多少东西可漂；
- 头型、眉眼间距、肤色、比例四个锚点就够；
- 换装、加皱纹、加伤都不影响「还是他」；
- 观众投射更强，第二人称更成立。

代价：空白头容易显得「廉价/偷懒」。对策是**背景必须够细、光必须够硬、情绪必须靠眉嘴演到位**；这三件里缺一件，画风就塌。

## 6 成本（估算，未实跑）

口径按 `rules/shared/cost-evaluation.md`；生图按 `new1` 0.02 元为主，`old` 0.16 元只兜底。

| 项 | 6 min 试水（约 60 镜） | 11 min（约 105 镜） |
|---|---|---|
| 生图 | 1.2–2.4 元 | 2.1–4.2 元 |
| Token | 5–7 元 | 8–12 元 |
| 片头合成 | 本机 1–2 min，0 元 | 同左 |
| 本机（走 API） | 8–12 min | 12–18 min |
| **合计** | **6–9 元** | **10–16 元** |

- 章节卡 8 张只增加文字合成，不增加生图；每张 2.2 s，从正文总时长里扣。
- 真实成本以首集实测替换；`new1` 额度耗尽即停，不静默降级。

## 7 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 11 分钟太长，前 30 s 流失 | 完播低 | 片头 8.4 s 内给「拼图世界 + 前提 + 关卡」；第一章 90 s 内给一个具体奇观 |
| 空白头显得廉价 | 画风塌 | 背景细节、硬光、情绪三件必须到位；G2 抽检加「背景三层/硬阴影」两项 |
| 章节卡打断节奏 | 跳出 | 卡只 2.0–2.6 s，且必须有口播；不做纯静音卡 |
| 切片合成参数太碎 | 每期调试久 | 参数 JSON 化；面板数/时长/错位三档预设 |
| 毛笔字授权 | 不能商用 | 先用 OFL 的 MaShanZheng 加粗；正式字族确认授权后再换 |
| 末日/灾难题材审核 | 限流 | 不影射真实事件/地区；不渲染自伤方法；结尾不宣扬虚无 |
| 画风被误认「低幼」 | 点击低 | 封面用高细节背景 + 红字钩子；正片前 3 s 给灾难奇观 |

## 8 现在要拍板的

1. **时长**：11 分钟级（跟参考）／6 分钟试水。
2. **章节卡**：做 8 章／不切章。
3. **关卡号**：`第一级`（参考片）／`副本 No.001`（系列号）。
4. **主角性别与年龄跨度**：默认中性偏男、青年→老年；首集是否要女性。
5. **片头口播**：先沿用试音里的哪条声线（或等选定后再做样片）。
