### 3.2 「切片」到底怎么切

不是把视频剪碎，也不是直播切片，而是**把一张主视觉切成矩形块，逐块展开**：

1. 一张 16:9 主视觉（第一人称、手部在前景、废城在中景）。
2. 切成 5–7 块不等大的矩形，块与块之间留 6–20 px 黑缝；不是规则网格，边缘故意不对齐。
3. 每块从自己的中心或一条边**从 1–3 px 细缝长到最终大小**，用时 0.25–0.60 s，错峰 0.06–0.12 s；先中间、后四周。
4. 展开时块整体带 3–10 px 位移，滑到最终位置；边缘有 1–3 px 浅灰「撕纸」描边。
5. 全部块在 1.9 s 左右拼满画面，接 3 次故障硬切；随后整张图做一次 1.00→1.03 的缓慢推近。

### 3.3 故障层参数（目测）

| 层 | 量级 | 说明 |
|---|---|---|
| RGB 通道错位 | ±8–20 px | 红/蓝通道左右分离，整段持续 |
| 横向条带位移 | 2–8 条，±6–30 px，6–15 Hz | 像信号撕裂；条带高度 10–60 px |
| 噪点 | 3–8/255 | 全画面，暗部更明显 |
| 扫描线 | 每 2–4 px 压暗 3–8% | 轻，不糊字 |
| 暗角 | 边缘 −15–25% | 把注意力压到中间 |
| 推近 | 1.00→1.03 / 3.6 s | 只在整个主视觉段 |

### 3.4 文字

- 钩子：红 `#E01B12` 附近，毛笔/手写粗体，两行，字高约 110–130 px（1080p），黑色描边 4–6 px，下面垫一层深灰残影；字本身有 ±2–4 px 抖动与红蓝分离。
- 关卡卡：`第一级` 灰白（约 `#B8B8B8`），字高 120–140 px；章节名红色，字高 130–150 px，灰色残影向左下错位 20–30 px。
- 字体不是思源黑体，是**粗毛笔/手书**；具体字族待授权确认，见 `rules/人生体验/intro.md` §六。

**结构手法（可借）**：

1. **每 80–90 s 一张黑底章节卡**，把 11 分钟切成 8 个可吞咽的小段；卡上只写一句意象，不写「第一部分」。
2. **每章内部是「先给一个具体动作，再给一个系统级后果」**：开香槟 → 供暖停；吃泡面 → 黄金无用；打猎 → 变异野猪；看铁塔 → 铁塔倒。
3. **章与章之间用「时间/空间跳格」**，不解释过渡；靠字幕一句「半年后」/「第 60 天」完成。
4. **结尾回到开头**：新的人推开同一扇门、读同一本日记；不总结、不说教。

## 五、画风

### 5.1 一句话

**「简笔空白人 + 高细节手绘废土背景」**：人物极简（白灰圆头、无鼻、点眼），背景是线稿清楚、层次很足的 2D 漫画；整体低饱和土色，火/血/警示用高饱和红橙顶出来。

### 5.2 分层

| 层 | 特征 |
|---|---|
| 线 | 深褐黑描边，人物线 4–6 px、道具/建筑 2–4 px（1080p）；线不抖、不草，接近 ligne claire |
| 人物上色 | 平涂 + 一层软渐变；皮肤白灰 `#D9D9D9`–`#EDEDED`，暗部偏冷灰 |
| 背景上色 | 大面积平涂 + 局部渐变 + 交叉排线；材质（锈、霉、雪、灰）靠纹理叠 |
| 光 | 强方向光、硬阴影、边缘光；夜戏用红/橙光源，雪地用冷青 |
| 质感 | 轻胶片颗粒 + 轻微纸张纹理；不是 3D、不是厚涂、不是日漫赛璐璐 |
| 色彩 | 主色土黄/灰绿/褐（`#8C8476`、`#6D655D`、`#343738`）；强调红橙（`#9A4444`、`#C0392B`）；雪地冷青（`#303E46`、`#B5C7D4`） |

### 5.3 构图

- 16:9 横版；中景/全景为主，人物常只占画面 1/6–1/3，背景承担信息。
- 关键情绪用**大特写**：整颗头塞满画面（如 3:20 的崩溃脸），靠眉眼和汗滴演。
- 第一人称插入镜：手捧罐头/水瓶、推门、翻日记；手部画得比人物身体细，但结构清楚。
- 常用「门/窗/洞口」做画框，把人物框在中间；废墟用透视线拉到深处。
- 字幕压底部，人物眼睛不低于画面 55% 高度，避免被字挡。

## 六、主角

### 6.1 外形

| 项 | 规格 |
|---|---|
| 头 | 白灰、近圆、颅顶饱满、下颌略收；**光头**，无发 |
| 五官 | 无鼻；两颗小黑椭圆眼（带一点白高光）；细眉各一条；嘴是简单线/椭圆，张嘴时黑底 + 粉舌；小耳 C 形 |
| 比例 | 约 2.8–3.2 头身；头高约占全身 1/3；肩窄、四肢细、手小脚小 |
| 皮肤 | `#D9D9D9`–`#EDEDED`，暗部冷灰；无毛孔、无颧骨结构 |
| 基础服装 | 灰连帽衫 + 黑裤 + 黑鞋；随章节换浴袍、军大衣、背包、破布、兽皮 |
| 老化 | 加皱纹、法令纹、老年斑、胡茬；**头仍然光、仍然无鼻**；眼型不变 |
| 表情 | 只靠眉、眼、嘴三个部件；惊恐=眉上扬+嘴大张，绝望=眉下垂+嘴一条线，笑=嘴弧+眼弯 |

### 6.2 为什么这样设计（可借的理由）

1. **空白头 = 观众投射位**：第二人称「你」需要一个不抢身份的脸；没有五官细节，观众容易把自己放进去。
2. **极简脸 = 一致性便宜**：不用担心换脸、崩脸；三视图只要锁头型、眉眼间距、服装。
3. **反差 = 记忆点**：极简人物压在高细节废土上，一眼认得出，也压得住大场面。
4. **换装不换人**：同一颗空白头可以从连帽衫换到军大衣到破布，跨 10 年不漂。

### 6.3 明确不做的

- 不加鼻子、不加日漫大眼睛、不加发型（老年也不加）。
- 不做 3D、不做写实皮肤、不做厚涂。
- 不让主角变成「可爱吉祥物」：身体可以小，但情绪要真，不做夸张 Q 版表情包。
- 不抄参考片的具体服装搭配与场景构图；只锁「空白头 + 简笔身体」这一层。

## 七、字幕与声音

### 7.1 字幕

- 白色粗黑体（与 style_r4 同族），黑描边 5–6 px，单行，底部居中；字号按 style_r4 的 96 上限走，超宽逐句缩，不换行。
- 每条 2–4 s；一句一个完整句；CPS ≤9。
- 字幕不写「他/她」，全篇第二人称「你」；不写「我们」。
- 字幕压在画面下 1/5，人物眼睛在 55% 线以上；不与章节卡同屏。

### 7.2 声音

- 单人口播，低男声，基频约 112–122 Hz；语速偏慢、克制，句间留 0.1–0.2 s。
- 口播下持续有低频/环境铺底，没有整段静音；片头是 drone + 撕裂噪声 + 3 记 hit。
- 不追求「搞笑音效」；情绪靠低频、留白、突然的金属/爆炸声。
- 章节卡也有口播（或至少一声低频 + 旁白念卡名），不做「纯静音标题卡」。

## 八、能借 / 不能借

### 8.1 能借（形式层）

- 片头的**切片拼贴** + 红字钩子 + 关卡卡结构。
- **8 章 / 每章 80–90 s** 的黑底章节卡节奏。
- **空白头主角**与「简笔人物 + 高细节背景」的画风分层。
- 低饱和土色 + 红橙强调的调色。
- 第二人称、单人口播、低频铺底。
- 每章「具体动作 → 系统后果」的写法。

### 8.2 不能借

- 不搬任何旁白句子、章节名、画面构图、角色服装搭配、音轨、BGM。
- 不搬「世界上只剩下你」这个具体设定与末日桥段；只借「一句话前提 + 章节推进」的形式。
- 不使用参考片任何一帧作为素材（包括片头主视觉、章节卡底图）。
- 不学它的错别字、病句、宗教/政治符号；字幕必须过 G7。
- 不把「第一级」这种游戏化措辞当成唯一选项；可以用「副本 No.XXX」替代，见 `rules/人生体验/intro.md`。
