## 问题归纳

1. **叙事角色与画面身份脱节。** 猫头人被提示为“真实事件之外的观察者”，出现在桌面山地模型前；真实队员则变成无脸背影。猫头人既不是第二人称体验者，也没有稳定地带观众进入事件。
2. **人物规格互相冲突。** 旧本集规则写“禁用猫头人、自然比例人物”；当前线路规则写猫头人归档；旧版已验证方案却是猫头人主角、简笔圆头人配角。生成任务同时继承了这些不同代际的提示词。
3. **配角缺少定义与参考。** `shot-plan.json` 中部分群体被写成 `neutral trail tokens`，生成结果像白色棋子；没有对应 `character_id` 和人物参考。规范提到的 `ref-helper-a/b/c.png` 不在共用角色目录，不能假定当前任务已提供。
4. **提示词比规则更具体，图像检查没有拦住错误。** 例如分镜提示明确要求桌面模型、无脸背影；S05 生成图还出现了定装规则禁止的尾巴。现有“通过”记录没有覆盖对照原图的这些问题。
5. **单镜事实没有被角色约束保护。** 群体人数、2 人回撤与 3 人继续、后来 1/1/3 分散等事实主要靠自然语言提示；缺少统一的角色 ID、人数核对与跨镜状态表。

## 统一角色方向

- **猫头人是“你”的视觉化身，计入五名队员之一。** 只代表匿名体验视角，不还原获救队员真实长相，不作为第六人、旁观者或桌面模型讲解员。
- **猫头人身份锁定**沿用正式参考：折耳橘虎斑头部、既定头身比例、猫爪、无尾巴、统一线稿和平涂。为冬季高海拔场景另做一套本集户外服装参考；它是虚构化的通用造型，不宣称对应真实队员实际穿着。每镜沿用同一套服装、装备和状态，不让模型自行换装。
- **队员和救援人员统一用简笔圆头人。** 圆头、点眼、短线嘴、白手套式手部、简单纯色衣物；与猫头人使用同一套二维线稿、轮廓粗细和色块语言，不画写实脸、写实皮肤或电影写实身体。
- **不臆造个体特征。** 只使用报道支持的人数、性别构成、年龄范围、分组和行动。报道没有说明的个人脸型、发型、衣服颜色、品牌装备、性格和表情，不设成角色身份特征。服装只做中性、连续的通用山地穿着。
- **参考资产按本线共用或本集新建。** 不从其他单集直接借用配角定装。正式进入生成前，为本集建立 `catman-aotai` 户外定装，以及 `hiker-male`、`hiker-female`、`rescue-worker` 等简笔角色参考；每个参考记录用途、允许锁定的特征和禁止推断的内容。

## 分镜与生成

1. 先锁定扩写稿，再重建与稿件一致的 53 镜 shot plan；每镜填写 `fact`、`scene_id`、`cast`、人数、人物动作、`view_angle`、引用来源和参考图路径。分组镜用结构化人数记录，不能把人写成 `token`、棋子或装饰物。
2. 猫头人出现时必须有 `catman` 角色 ID 和对应参考；在人群中作为五人之一计数。无猫头人的空镜明确 `cast=none`。群体角色仅调用已建立的简笔参考，不因镜头临时发明新配角。
3. 视觉方向沿用统一的二维手绘体系：环境保留冬季山地的手绘空间、材质和光照；猫头人和简笔人保持同线宽、同平涂逻辑。取消观察室、桌面山模、模型小人等与事实现场无关的重复表达；如需交代路线关系，单独画无人地形图，不放棋子人。
4. 运镜和章节构图服从事实与人物可读性。正面及三分之四面作为常规角度，避免持续背影；背面只用于交代行进方向、空间尺度或遮挡。匿名人物仍应看得出稳定的简笔头身、衣着和动作。
5. 先做 6 镜样张：五人凌晨进山、雾雪后 2/3 分流、两人共同过夜后分开、打火机与避风处、获救、获救后回看搜救节点。样张至少覆盖远景、多人中景和猫头人正面/三分之四面。
6. 样张检查通过后再生成其余镜头；保留背景底图与角色合成的分层记录，所有结果写进新版本目录 `image/assets-v3/`，不覆写 v1/v2。

## 逐镜验收

- 猫头人对照三视图：折耳、脸部虎斑、比例和猫爪稳定；无尾巴、无真人手脚、无临时换装。
- 所有配角对照对应简笔参考：同一画法、同一角色连续性；没有无参考的写实配角或白色棋子人。
- 镜头人数与事实矩阵一致：进山 5 人；分流为 2+3；回撤组再分开后为 1+1+3；搜救结果和阶段严格按稿件。
- 场景与视角支持旁白：猫头人是体验锚点，不在事件外讲解；并行搜救只在稿件切入处展示已确认节点，不做救援队的全知视角。
- 逐张人工看原尺寸图片，而不以 API 状态、提示词完整或抽样统计替代视觉验收；身份、人数、角色风格任一不符即修正该镜及同类提示词。
