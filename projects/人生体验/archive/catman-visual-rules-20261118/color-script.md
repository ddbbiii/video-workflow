## 〇、每集必须先有 `image/color-plan.json`

没有这份文件不许批量生图。字段：

```json
{
  "plan_version": 1,
  "episode": "<集名>",
  "chapters": {
    "<章标题前缀>": {
      "plate": ["#高光", "#中间调", "#暗部", "#环境辅色", "#近黑"],
      "accent": "全章唯一允许的高饱和色（写清是什么物件）",
      "day_out": "<时间段 + 主光方位/类型 + 色温K>",
      "day_in": "…", "night_out": "…", "night_in": "…"
    }
  },
  "shots": {"S11": {"light": "…", "accent": "…"}}
}
```

- 章按剧本 `## ` 标题前缀匹配；`shots` 逐镜覆盖，优先于章默认值。
- 生成器只读这份文件，不许把色值写死在代码或风格块里。
- 一集之内，`accent` 是**唯一**允许的高饱和色；换章可以换，换镜只能在 `shots` 里显式改。

## 一、诊断：不是画风问题，是色板被写死了

对两套成品逐张算「饱和度×亮度加权」的色相分布（12 个 30° 桶），99 张一起看：

| 图组 | 平均色相 | 平均饱和 | 平均亮度 | 0–60° 占比 | 帧间平均色差 ΔE |
|---|---|---|---|---|---|
| `stills`（半写实） | 32.4° | 0.226 | 0.495 | 87.6% | — |
| `stills-2d`（2D 手绘） | 32.4° | 0.446 | 0.617 | **98.5%** | 13.5（中位 11.9） |

- 六章分章的色相分别是 33.2° / 33.2° / 32.9° / 31.8° / 31.5° / 31.9°——**从报志愿到提桶跑路，色相一动没动**。
- 绿、蓝、青三个方向合计不到 0.5%；橙桶（0–60°）一个人占了 98.5%。
- 帧间平均色差 13.5，中位 11.9（ΔE>10 才算明显可辨）——观众看到的是「同一张调色反复 99 次」。

夜戏其实有做暗（夜戏平均亮度 0.451 vs 日戏 0.667），但**只是变暗，没有变冷**：夜戏平均色相 28.8°，日戏 31.4°，还是同一个橙。

### 病根在提示词的三处

1. **色板写进了每一镜的风格块。**
   `gen_stills_2d.py` 的 `STYLE` 里固定一句「低饱和土色系（土黄、灰绿、褐），只在必要处用一点暖橙」，
   这句话 99 次出现在最前面（模型对 prompt 开头最敏感），等于给整集下了统一滤镜令。
   这句话本身是从废土参考片继承来的（`style.md` §二），对「一人一城一废土」成立，对「一个人十几年、跨四季跨昼夜」不成立。
2. **`visual` 字段没有可执行的色彩指令。**
   99 条 visual 里只有 23 条提到时间/光，且是叙事性的（「窗外天已经黑透」「灯下」），
   没有一条给色温、光位、主色；模型只能回落到风格块那句土黄。
3. **参考图把色调又锁了一次。**
   `/images/edits` 带 `refs/cat-face-crop.png`，它的橘猫、暖背景、纸纹都会渗到成图里，
   而 prompt 里没有一句把「参考图只管脸」这件事说清楚。

## 二、改法：画风锁死，颜色逐镜给

### 2.0 色相只按章约束（2026-11-15 v1.4）

「全片统一成棕黄」被禁止，**「全片统一成中性灰」同样不合格**——v2 成片就是这个病：R/B 0.97 合格，但每场只有一个灰，色系单调。

- 色相**不在单镜设下限**：夜戏、应急灯绿光、手电特写允许只有 1–2 色；
- 章级统计：**每章平均 ≥3 色相**、全片 R/B ≤1.15、平均亮度 ≥0.45，**不许整片单色**；
- 刻意压成单色时写 `"muted": true` 声明；
- 全片仍只有**一处**高饱和（按 `color-plan.json` 逐章指定），环境色不算高饱和；
- 提示词保留「其余压成灰阶或低饱和」，但要加一句「允许环境里出现第二个色相，不要整片同色」。

已验样张（`image/pilot-v5`、`pilot-v9`）：木色+军绿、冷白+包装黄、锈棕+日出金，R/B 1.03–1.24。

一句话：**线稿、平涂、禁止项整集不变；颜色和光按「章 × 日夜 × 室内外」逐镜改。**

- 五色板决定这一章的主调，`accent` 是全章**唯一**允许的高饱和色（通常就是红桶 #C0392B）；
- 「唯一高饱和」是这条线的叙事锚点：全片只有红桶是艳的，走到哪一章都认得出它；
- 参考图说明改成「只锁定这张脸和花纹，不锁定画面色调、背景颜色与光」。

### 每镜的「色彩与光线」行

不写在标题里，写成 prompt 里独立一段，格式固定三段：

```text
色彩与光线：<时间段 + 主光方位/类型 + 色温K>；只用这五个颜色 <#.. #.. #.. #.. #..>（其余压成灰阶）；
全图只允许一处高饱和，且只能是<这一镜的主体>。
```

四类光的写法（章节各自给一条，脚本按关键词自动挑）：

| | 室外 | 室内 |
|---|---|---|
| 日 | 正午 5500K 顶光，硬阴影、地面反白 | 板房内 4000K 灯管，桌面亮、角落暗 |
| 夜 | 钠灯 2000K 暖橙 + 天空 `#1E2A38` 冷蓝黑 | 一盏白炽灯 3000K，床铺亮、墙根暗 |

已写死光的 48 镜（深夜自习室、工地夜灯、手机屏幕特写、清晨工地等）逐镜覆盖，不套章节默认值；其余按关键词推。

## 三、落地位置

- 规则：`style.md` 的当前有效章节、`character.md` 当前有效章节；静帧执行步骤见 `still-production.md`。
- 每集数据：`projects/人生体验/episodes/<集>/image/color-plan.json`（见 §〇），**唯一可改色值的地方**。
- 每集生成器必须读取 `color-plan.json` 的章节五色板、唯一 accent、四类光、`locations` 和逐镜 `shots` 覆盖；人物镜与无人镜都必须收到适用的色彩信息。
- 不指定某个历史生成器文件名、风格常量名或试跑参数为永久接口；生产前由 `still-production.md` 检查当前实现并保存实际 prompt。
- 色值只在 `color-plan.json` 里改，**代码与本文件都不再写死色卡**（旧口径「文档与代码同源」改为「数据与代码分离」）。

## 四、色彩诊断（量化辅助，不单凭数值返工）

### 4.0 批量前与批次验收的证据要求（2026-11-15）

- 小样与每批静帧必须运行 `qa/audit_color_v3.py --src <本批输出目录>`；报告须包含全片及分章 R/B、饱和度、亮度、色相直方图/色相数和图像尺寸。
- 不得用只统计全片平均饱和度或 R/B 的简化脚本，替代本文件的章级色相检查。
- 若指定审计脚本缺失、报告缺字段、样图不足以覆盖某章，如实记录未完成的审计范围；不因此阻断生成，也不伪称审计已执行。
- sidecar 必须保留实际发送的完整 prompt；颜色审计报告记录输入目录、镜号、计算口径和输出路径。

> 当前诊断以 v1.5 为准：按章统计色相（每章平均至少 3 个色相），同时检查全片 R/B、饱和度、亮度和高饱和点缀；历史 v1.1/v1.2 的单镜色相说明不再覆盖章级规则。

- [ ] **全片平均 R/B ≤1.15**，且不得出现整片单色相（v1 两集 1.83 / 1.67 属失败；v3 定版样张 1.00）。
- [ ] 平均饱和 ≤0.15；单帧高饱和像素（S>0.6）占比 ≤8%，且只出现在该镜约定的那一处点缀物上。
- [ ] 平均亮度 ≥0.45（简填色应当偏亮；v1 的 0.43 是"压暗的土黄"）。
- [ ] 夜戏（`color-plan.json` 标了「夜」且画面无主角的）冷色占比 ≥20%；
      人物镜因橘猫毛色天然偏低，不单独卡这条，改看「背景是否偏冷」（同图取四角采样）。
- [ ] 相邻两章平均亮度或平均色温至少有一项不同；首末两章必须有明显差异（日→夜、冷→暖）。
- [ ] 画面里不出现漫画音效符号、感叹号、情绪记号。
- [ ] 同一角色跨镜脸型/花纹一致（原有验收项，不因换色而放松）。
- [ ] 画面无文字、无水印、无 logo，底部 1/5 不留关键信息。

## 五、明确不做

- 不做「每章换画风」：线稿、平涂、颗粒、纸纹整集一致，只换颜色和光。
- 不做整集统一 LUT 或后期调色糊过去——生图阶段就分开，后期只做轻微统一。
- 不让「唯一高饱和」变成多个：避免多处艳色争夺注意；按镜头主题选择，不按点数判失败。
- 小样用于确定色彩方向，既有用户认可样张可复用；量化偏离用于排查原因，不直接阻断全量。
