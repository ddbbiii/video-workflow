| 故事母题 | 埃文查明灯塔为何多出一个人，保住航路后熄灯，没能救回三名守塔人。 |
| 主线 | 登岛 → 三本日记 → 船长证词 → 两表验证 → 重读末页 → 交接航路 → 回船记下结尾；见[已确认大纲](../../planning/第四位守塔人-剧情大纲.md)。 |

| 结尾 | 埃文写下「我熄了灯。他们还在等人接班。」不知道三人熄灯后还在不在。 |
