# 《你先吃，我马上回来》场景设定 v2

## 餐厅固定平面

餐厅位于老商场负一层，完全是封闭室内空间，不出现窗外树木、自然天光或地面层街景。入口接旧商场公共走廊；入口内侧左手是收银台和空托盘架，再往里是双人卡座区。故事中的双人桌靠近一根贴过胶带的黄色方柱，桌右侧为磨砂隔断；红柄酸梅汤机在座位区右后方，隔着取餐口能看见。两排长方形不锈钢冰柜组成中央取餐岛台，遮住座位区看向出口的视线。沿冰柜边缘绕行可从卡座到饮料机和肉柜，再从岛台尽头折返。

玻璃门位于中央岛台后方的通道尽头。它不是普通餐厅正门；异常发生后才从熟悉的取餐路线尽头出现。门外仍是同一座负一层商场，扶梯、深色栏杆、缺角石材基座的位置保持不变。

## 场景锚点

| 场景 | 必须一致的识别物与关系 |
|---|---|
| mall | 旧商场负一层；扶梯在画面左侧；栏杆在右；扶梯旁深色缺角石材基座；封闭室内，无户外景 |
| entrance | 入口通向公共走廊；收银台在入店左侧；托盘架靠收银台；向内可见取餐岛台 |
| table | 同一组蓝绿色双人卡座、棕色方桌、两只小钢锅；黄柱在卡座左侧、胶带印朝向座位；磨砂隔断在右；饮料机从右后方取餐口可见；岛台挡住出口 |
| counter | 两排平行不锈钢冰柜围成一条可往返的窄通道；饮料机靠座位区一端；胶带黄柱在远端转弯处；无窗、无室外景 |
| drinks | 同一红柄饮料机、两只透明方形料桶、金属接水盘；位于座位区右后方，不能改成独立房间 |
| threshold | 餐厅出口是带单根竖向推杆的落地铰链门，门扇向商场走廊打开；画面不得出现容易误认的冷柜玻璃门。门外是同一负一层扶梯和栏杆；地砖连续跨过门槛 |
| mall_after | 与 mall 同一机位关系和建筑骨架；翻修后的地面和护栏，缺角石材基座仍在原位；旧餐厅店面位置变成药店 |
| service | 翻修后的负一层服务台，靠近扶梯和缺角石材基座；旧传单、文件夹和座机在同一柜台；不误画成餐厅或药店内部 |
| noodle | 商场楼下的独立小面馆；两人面对面坐在同一张旧方桌旁，醋瓶在远处柜台；与自助餐厅不共享家具或道具 |

## 画面递进

- S01-S12：餐厅仍像一间普通但老旧的自助小火锅店；留住可辨识的完整空间和正常用餐暖光。
- S13-S27：不改变平面，只逐步减少人物周围的空隙，用冰柜端头、柱体和桌沿形成遮挡；冷灰蓝环境光加重，人物和关键证据保持可读。
- S28-S31：通过同一玻璃门和同一扶梯建立前后对照；商场的主要建筑锚点不移动，只更新装修与店面用途。
- S32-S41：柜台、扶梯和缺角基座维持同一相对位置，重点放在陈默的证据与重逢反应。
- S42-S44：面馆以较暖、较安静的局部灯光收束，但仍保留旧物磨损；腕部动作必须能由桌上醋瓶的位置解释。

全片保持调查漫画式赛璐璐；压抑通过封闭空间、遮挡和光区控制完成，不靠整幅压黑或添加新剧情地点。
