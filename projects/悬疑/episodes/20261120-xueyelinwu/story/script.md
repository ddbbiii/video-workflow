# 《雪夜林屋》正文稿

大学时代的最后一场冬雪，我和老赵、大孙三人去长白山徒步野营。

没想到下午突然起了暴风雪，我们在原始森林里彻底迷失了方向。眼看天色全黑，气温降到了零下二十度，就在我们快要绝望冻僵的时候，我们在山坳里发现了一座石头砌成的守林人木屋。

木屋里只有一个脸上有刀疤的独眼老头，正在火炉旁抽着旱烟。他默许了我们进来避寒，但语气极其生硬地警告了我们一句：

“山里的风雪不干净。太阳落山后，这扇木门我已经从里面挂上了铁门闩。记住，无论半夜听到门外有什么动静，哪怕天王老子来了，都不准开门。谁开门，我先一枪崩了谁。”

<span style="color:#d93025">老头说完，走到门边，当着我们三个人的面检查了一遍铁门闩，又用力推了推门，确认门闩卡牢了。</span>

老头把一把双管猎枪抱在怀里，靠着火炉闭上了眼睛。

我们三人又冷又累，没把他的话放在心上，裹着睡袋在火炉另一侧沉沉睡去。

到了凌晨两点多，我被一阵刺骨的寒意冻醒。我揉了揉眼睛，借着炉火的微光，发现睡在我左边的大孙不见了，睡袋敞开着，里面是空的。

我心里一紧，赶紧推醒了旁边的老赵。老赵一看大孙没了，脸色煞白。

“他是不是出去上厕所了？”老赵压低声音问我。
我看向那扇厚重的木门。门栓依然死死地挂在原位，根本没有被人从里面打开过的痕迹。那大孙是怎么出去的？！

就在我们两人惊疑不定的时候，门外突然传来了沉闷的拍门声。

“老赵！开门啊！快开门！”

是大孙的声音！声音里透着极度的恐惧和绝望，伴随着呼啸的风雪声。
“那个老头是个杀人犯！我在屋后的雪地里发现了好多人骨头！他想把我们困在屋里药死！快开门让我进去，我们一起把他制服！”

听到这话，老赵头皮发炸，猛地转头看向火炉旁。
那个独眼老头不知什么时候已经站了起来，双手端着那把猎枪，黑洞洞的枪口直指着门的方向。他死死盯着那扇门，额头上竟然全是冷汗。

“别听他的。”老头咬着牙对我们低吼，“门外的东西，早就不是你们的朋友了。”

“你放屁！”老赵是个暴脾气，一把抓起火炉旁的劈柴斧头，指着老头骂道，“那是大孙的声音，连我的外号都叫对了！你把枪放下，不然老子先劈了你！”

“老赵，别急！”我一把拉住老赵，强迫自己冷静下来。此时门外的大孙还在疯狂哭喊求救，而屋里的老头端着枪的手也在微微发抖。两人之中，必定有一个在撒谎。

<span style="color:#d93025">我深吸一口气，对着门外大声喊道：“大孙！你别慌！那老头现在用枪指着我们，门栓太重了，被火炉挡着，我们在里面根本拔不开！你力气大，你从外面使劲推门！只要你用力推，把门框撞松，我们就有机会拉开它！”</span>

“好！好！我推！你们坚持住！”
门外的大孙急切地答应了。紧接着，整扇厚重的木门开始剧烈地颤抖起来。

“砰！砰！砰！”

沉闷的撞击声不断从门外传来，每一下都带着巨大的力量，仿佛外面有人正在用肩膀疯狂地撞门。

老赵听得红了眼，举着斧头就要冲上去帮大孙开门，顺便砍死那个挡路的老头。

但我却死死抱住了老赵的腰，浑身的血液在这一刻瞬间冰凉，眼泪不受控制地夺眶而出。

“别去……老赵，千万别去……”我死死咬住嘴唇，不让自己哭出声，声音抖得不成样子。

老赵愣住了，不解地看着我：“你疯了？大孙在外面拼命撞门，再不帮忙门就要被撞开了！”

我脸色惨白地指着那扇正在被疯狂撞击的木门，绝望地摇了摇头。

<span style="color:#d93025">我盯着那根仍挂在原位的铁门闩，声音抖得几乎听不清。</span>

<span style="color:#d93025">“可门闩还在原位。大孙要是从屋里出去，这根门闩怎么会一点都没动？”</span>

<span style="color:#d93025">门外又一次响起大孙的哭喊。我看着那根没有被拔动过的铁门闩，终于明白：门外那个东西想骗我们亲手把它取下来。</span>
