# 悬疑单集输入单：《她只会叫我开门》

| # | 项目 | 内容 |
|---|---|---|
| 1 | 标题 | 她只会叫我开门 |
| 2 | 故事母题 | 丧女母亲在暴雨夜被地下室怪物用亲人声音诱开门，她查证并逃生，却发现怪物已学会更多声音。 |
| 3 | 故事主线 | 1. 暴雨导致老楼地下室积水，物业撑开铁门抽水；母亲独自在三楼收拾搬家物品，反复播放女儿旧手机视频。物证：旧手机视频提供声音样本。2. 门外出现女儿声音，说没带钥匙；母亲差点开门，发现女儿钥匙一直收在书桌抽屉。物证：旧钥匙否定门外身份。3. 母亲回看视频，门外又复述视频里接栗子纸袋的原话；母亲打给丈夫陈叔，电话里说到蓝胶带纸箱后，门外立刻复述同一细节。物证：视频、蓝胶带纸箱与通话内容构成声音来源线索。4. 母亲用两人私藏的蜗牛名字试探，门外答不出，只反复要求开门；它模仿的是声音和情绪，不知道女儿真正记忆。5. 门外换成陈叔声音称警察到了；手机视频确认陈叔在医院且没有说话，母亲改用文字联系。物证：实时视频与门外声音矛盾，确认外面有东西在模仿。6. 警员到达楼梯间，母亲在卧室打字时，楼道出现她自己的求救声；警员靠近矮墙后被贴地怪物抓住袖口，袖子撕裂，怪物脸部多张嘴显形，手中留着布料。物证：撕裂袖口与布料显示它会抓取材料。7. 母亲按指示从阳台由消防员救出；怪物先喊救命，再用栗子视频里的原话诱她回头，她继续向消防员求助。8. 次日监控显示怪物从被撑开的地下室铁门爬出，上楼后又在天亮前爬回；现场检查在旧集水坑发现污泥、头发和无法辨认来源的衣料。物证：监控与集水坑残留说明它来自地下室，但无法确认其原本身份。9. 母亲搬离老楼，带走女儿的旧手机和蜗牛盒；她终于把女儿的故事讲给丈夫听，不再守着门等待回应。反转：所谓亡女回家不是女儿归来，而是怪物用母亲最容易相信的声音把她引到门边。 |
| 4 | 主悬念 / 次悬念 / 反转 | 主悬念：门外的声音是谁，它想让母亲做什么？\n次悬念：地下室的东西如何学会女儿和母亲的声音？\n反转：旧手机视频、实时通话矛盾、警员袖口和楼门监控共同改写“女儿回家”的理解：怪物从地下室出来，靠偷听和取得衣料逐步仿声；具体由哪些遗骸形成仍未知。 |
| 5 | 三条可拍物证 | 1. 女儿钥匙串：开场确认女儿去世后仍留在书桌抽屉，证明门外“没带钥匙”的说法不成立。2. 手机视频与视频通话：栗子视频提供原声样本，陈叔视频证明门外声音不是实时的他本人。3. 警员被撕开的袖口及监控：袖口碎片留在怪物手中，监控又拍到它从地下室出入，支持“取材模仿、地下室来源”的判断。 |

| 7 | 来源与授权 | 原创故事；人物、情节、怪物规则均为本集创作，无外部改编素材。 |

## 必须覆盖

- 母亲差点开门的情感动机明确，不能只靠“她很想女儿”解释。
- 警员被抓袖口到看清怪物的部分留足多个连续镜头。
- 怪物的多张嘴只长在脸上；不出现其他部位长嘴。
- 地下室积水和铁门被撑开要在开头出现，监控在后段回收。
- 先称“下到一楼”，不写“下到地面”。

## 必须避免

- 不把未知来源讲成现实民俗或真实案件。
- 不让怪物靠任意新增规则推动剧情；需要理解的规则不超过 3 条。
- 不把怪物设定解释成一大段旁白；用现场动作和物证呈现。
- 正式分镜画风服从 `rules/悬疑/visual.md`；本次概念图不作为正式风格覆盖。
