# 单集输入：《纸替》

- 标题：纸替
- 母题：奶奶出殡后，主角在老屋遇见一只会移动的小纸替，最后发现离开房间的人用了自己的声音。
- 主线：床脚矮凳上的纸人消失；交代纸人来自奶奶的葬礼；纸人出现在床边；主角身体无法动弹；纸人脸上渗出墨水；纸人到了枕边；门外传来二叔的声音；门开后有人离开；主角发现自己成了纸替；门外传来自己的声音。
- 主悬念：小纸人如何从摆设变成正在替代主角的东西。
- 次悬念：门外离开的人与床上的纸替是什么关系。
- 反转：出门的人用主角的声音答话；床上的主角已经成了纸扎的一部分。
- 三条可拍物证：仍插着的门闩与空矮凳 / 纸人脸上的墨水落在枕边 / 纸手腕口露出的竹篾。
- 结尾：停在纸手与门外远去的声音，不解释交换机制。
- 来源与授权：原创故事，核心设定与视觉方向由用户确认。
- 目标时长：约3分钟；按用户确认采用本期短片时长例外。
- 必须覆盖：纸人固定约45厘米高；从矮凳移到床边、枕边；全程旁白；结尾只用轻提示留白。
- 必须避免：真人高纸人、纸人尺寸改变、用声线特效解释身份互换、追加规则说明、配音或混音。
