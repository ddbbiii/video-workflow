# 《废弃工单》氛围版样张 v0.1（段 1 + 段 3 前半）

- 日期：2026-11-12
- 目的：验证"恐怖氛围"的写法能不能立住，立住了再铺全稿
- 与 v0.2 的区别：不是加事件，是换写法——放慢、给身体、给温度、让他看不懂

## 段 1 冷开场

楼道里没有风。

手电光照过去，光纤箱的盖子歪在一边。锁扣是从里面顶开的，铁片往外翻着，像被什么东西从箱子里推了一把。

箱子里没有光纤。

一束旧铜线盘在箱底。铜芯还是亮的。

亮得不该。

铜线底下垫着一层土。红的，干得发白。他用指背蹭了一下，土是潮的。潮得像刚从地里刨出来。

手电再往里照。光进去，散在里面，照不到底。

箱子里响了一声。

很轻。像有人在很远的地方，用指节敲了一下桌子。

他屏住气。

隔了两秒，又一下。

这一回他听清了。不是敲。是打字。很慢，一个字，一个字。

拿手电的那只手，停住了。

他跟自己说，楼道里除了他，没有别人。

然后他回头了。

身后什么都没有。

感应灯灭了。

## 段 3 前半（楼道到四零四）

铁门的漆掉了一半，露出底下的锈。他侧身挤进去。

楼梯间比外面冷。

不是夜里那种冷。是没有人住的房子才有的冷，从墙里往外渗，贴着皮肤走。

他走到第三级台阶，四楼的感应灯才亮。

灯管两头都是黑的。黑得像烧过。可它亮了。

他咳了一声。

声音出去，撞在墙上，就没了。不是轻，是短。像这面墙后面什么都没有，声音一出去就被吃掉。

他抬手，在墙上敲了两下。

是实的。实心的，没有空腔。

老楼的墙不这样。老楼的墙里走线，走管，敲上去是空的。

他收回手。

台阶中间有一道印子。湿的，从楼上一直拖下来，拖到箱子底下。

他蹲下去看。

不宽，一巴掌左右。边缘是齐的。

像一捆线拖过去的时候，蹭出来的。

四零四的门关着。

门缝里没有光。他把手贴上去，门板是凉的。

他敲了两下。

门里响了一声。

像有人把椅子往后拖了半尺。

他站住。又敲了三下。

里面没有声音了。

他把耳朵贴上去。

门缝底下有一股风，很轻，吹在他手背上。凉的。

他按单子上的号码拨过去。

空号。

## 换掉了什么

| 原来的写法 | 现在的写法 | 为什么要换 |
|---|---|---|
| 箱子里没有光纤。 | 箱子里没有光纤。／一束旧铜线盘在箱底。铜芯还是亮的。／亮得不该。 | 给一个"不该"，让叙述本身不安。三个短段，读的时候会自己慢下来 |
| 土是潮的。 | 他用指背蹭了一下，土是潮的。潮得像刚从地里刨出来。 | 加触觉；"像刚从地里刨出来"把箱子和地下接上，但不说破 |
| 箱子深处响了一声。很轻，一下。 | 像有人在很远的地方，用指节敲了一下桌子。 | 比喻让声音有空间感；"很远"和"在箱子里"矛盾，这种矛盾才吓人 |
| （没有） | 他屏住气。／这一回他听清了。不是敲。是打字。很慢，一个字，一个字。 | 身体反应；而且让声音有个"升级"——先错认，后听清 |
| 拿手电的手停住了。 | 他跟自己说，楼道里除了他，没有别人。／然后他回头了。 | 手比脑子诚实。他先说服自己，身体却先回头——这是恐怖最省力的写法 |
| 台阶中间有一道湿印子。 | 他蹲下去看。／不宽，一巴掌左右。边缘是齐的。 | 让他"研究"它，读者跟着测量，恐怖就有了长度 |
| 四零四的门关着，门缝里没有光。他敲了两下，没人应。 | 他把手贴上去，门板是凉的。／门里响了一声。／像有人把椅子往后拖了半尺。 | 触觉；给"里面有人"的假象，让观众等门 |
| 他按单子上的号码拨过去，空号。 | （另起一段）空号。 | 单独成段，两个字砸下来 |

## 悬念这边改了什么

1. **不再让他一眼看懂。** v0.2 里他一眼认出"选项三年前删了""这是设备地址"。氛围版先让他"觉得不对"，认出来的动作往后推——认出来的那一刻才有分量。
2. **每个小节收在一个没完成的动作上**（他回头／他蹲下去看／他贴上去听），不收在结论上。结论会关掉悬念，动作会开着。
3. **声音先错认，再听清。** "不是敲，是打字"——错认的那两秒，是观众自己吓自己的时间。

1. 保 15 分钟，砍掉一个情节（我建议砍"配线表"或"倒计时"其中一个）；
2. 降到 12–13 分钟，情节全留。
