# 《废弃工单》结尾方案 v1

- 日期：2026-11-12
- 起因：v1 成片停在「空号」，只把门关上，没有回答前面埋的问题
- 结论：v2 只重做尾段（约 35–40 s + 10 镜），前 3:30 全部复用

## 一、现在为什么不行

前面埋了六个问题，v1 一个都没回答：

| 埋点 | 观众在等什么 |
|---|---|
| 作废工单被重新派出、没有报修人 | 谁派的？为什么没有报修人？ |
| 锁扣从里面顶开 | 什么东西从箱子里出来过？ |
| 没有光纤，只有旧铜线 | 线去哪了？铜线是什么？ |
| 箱子里极慢的打字声 | 谁在打？打的是什么？ |
| 湿痕从楼上一路拖到箱下 | 拖的是什么？拖到哪去了？ |
| 404 门缝无光、椅子挪动、门缝来风 | 里面是谁？为什么不回应？ |

「空号」是**关门**，不是**回答**。要了结，至少要让其中四条在同一分钟内对上，并留一到两个不解释。

## 二、三条硬要求

1. **回收四条**：报修人是谁、打字声是什么、湿痕拖的是什么、404 是什么；
2. **留两个未知**：门里到底有什么、这栋楼为什么吃人——不解释，只留画面；
3. **可回看**：结尾的解释必须能倒推回前面的至少两处画面（锁扣从内顶开、湿痕到箱下），不能空降新信息。

## 三、三个方案

### 方案 A（推荐）《到岗》——系统闭环

**一句话**：工单不是派给他的，是**写给他的**；打字声是在填这张单，湿痕是上一根被收回去的线；404 是这根线的另一头。

**回收**：
- 报修人 = 四零四（地址自己报了修）；
- 打字声 = 工单被一个字一个字填完；
- 湿痕 = 铜线被从楼上收进箱子、再收进门里；
- 404 = 线的另一端（门里没有房间，只有线）。

**留下**：门里是什么、线通向哪里。

**结尾文案（接「空号。」，约 120 字）**：

> 忙音还在响。
> 他把手机从耳边拿下来。
> 屏幕自己亮了。
> 那条灰掉的工单，跳到了最上面。
> 报修人一栏，多了三个字：四零四。
> 受理时间：现在。
> 技师：他。
> 结果那一栏，也已经填好了——已到岗。
> 楼道里，打字声停了。
> 门里，椅子又挪了一下。
> 他抬头。
> 门开了一条缝。
> 缝里没有光。
> 一根铜线，从门里伸出来，湿的，搭在他鞋面上。
> 铜线在往回缩。很慢。
> 他后退。
> 手机掉在地上。
> 屏幕朝上，还亮着。
> 工单最下面，多了一行：下一单，四零四。
> 技师一栏，空着。

**为什么这样收**：开头是「工单灰在列表底端，姓名栏空白」，结尾是「下一单，四零四，技师一栏空着」——同一个画面闭环，观众立刻明白：空白不是没填，是**还没轮到人**。

### 方案 B《替班》——人闭环

门里是上一任技师，坐在没有窗的机房里打字，穿一样的工装；回头，脸是他自己。打印机吐出「替班已到」。

- 回收：404 是谁、打字声、湿痕（上一任被拖进去）；
- 留下：这间机房是什么、为什么需要替班；
- 风险：靠「脸是他」制造冲击，接近怪物揭示；且需要一张正脸特写，与全片「不露正脸」的视觉策略冲突。

### 方案 C《线》——物理闭环

湿痕其实是线，从箱里往外长，缠住脚踝；他和门里的人各扯一头；线缩回去，楼道干净了，箱里多一张写着他名字的工单。

- 回收：湿痕、铜线、箱子；
- 留下：门里的人是谁；
- 风险：解释力最弱，「报修人为什么空白」仍然没答；画面容易变成触手系。

## 四、推荐执行：A + C 的一个动作

采用 A 的全部文案，只借 C 的一个动作：**铜线从门缝里伸出来、搭在鞋面上、慢慢往回缩**。这样箱子和 404 在画面上真正连成一根线，而不是靠旁白说。

1. 四条回收是否在画面上各有一镜（不能只在旁白里说）；
2. 「下一单，四零四 / 技师一栏空着」是否与开头「姓名栏空白」形成回看闭环；

4. 结尾不出现怪物、不出现跳吓、不压黑。
