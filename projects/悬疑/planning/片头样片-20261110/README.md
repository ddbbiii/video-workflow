# S1 悬疑片头样片（2026-11-10）

- 用途：给用户看「A 血墨艺术字 + 标题落墨冲击」的方向样片，**不是成片、文案未锁定**。
- 结构：3 句钩子（大字 + b2 旁白）+ 1 张标题卡 + 4 s 正文接缝；片头 14.3 s，成片样片 18.3 s。
- 规格：1920×1080 / 24 fps / H.264 + AAC；背景取自《夜跑路线》37 张静帧，过正文同一 GRADE。
- 艺术字：Ma Shan Zheng；钩子骨白 `#E9E3D7`，标题血红 `#8E1B1B` + 冷灰外圈 `#C4CCD2`；标题 190 px。
- 标题动效：`fscx/fscy 110 → 100`（200 ms）+ 100 ms alpha；之后完全静止。
- 音效：标题处 45 Hz 正弦 + 140 Hz 低通棕噪，1 s 衰减；BGM 0.55，标题处下压 0.15、0.47 s 回升。
- 旁白：CosyVoice3 b2（`profile-b2-suspense.json`，speed 0.95），三条钩子单独生成；正文接缝用《夜跑路线》原旁白前 4 s。

## 已知限制

1. 片头 14.3 s 略短于 15–17 s 目标；正式版可拉开句间留白到 0.7 s，或加一句短钩。
2. 标题外圈偏亮、偏“描边感”；是否收细/去掉待定。
3. 文案为样片文案，不是锁定稿；背景取帧仅用于样片。
4. 标题字形 V1/V2 沿用 Ma Shan Zheng；V3 起标题改用香萃积雪宋，详见 `v3-intro/README.md`。
