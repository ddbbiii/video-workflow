## 二、承载与结构

| 项 | 标准 | 出处 |
|---|---|---|
| 时长 | 按故事需要确定，不设 5 分钟最低要求，故事总时长原则上不超过 25 分钟 | input-spec §2、§4 |
| 原文长度 | 正片只收原文 ≥800 字、扩写位 ≥6；不够降为短片或冷开场 | 待办池 §五.6 |
| 单点题 | 只有“一个物件 + 一个反常识点”的，只够 10–15 分钟，不列 | recommendation §3.1 |
| 主/次悬念 | 1 个主悬念 + 最多 1 个次悬念 | narrative §一 |
| 规则 | 超自然规则 ≤3 条，每条必须能被一个画面或一个动作单独证明 | narrative §一 |
| 物证 | ≥3 条可拍物证，互相印证，至少 1 条改写前面的理解 | narrative §二 |
| 结尾 | 10 分钟以内短篇优先留白但保留理解线索；超过 10 分钟长篇优先讲清因果、回应核心悬念并回收前文 | narrative §一、ending §二 |
| 一句话复述 | 谁 / 遇到什么 / 做了什么 / 付出什么代价 | narrative §一 |

## 三、结尾

| 项 | 标准 | 出处 |
|---|---|---|
| 线索回收 | 长篇须回收关键物件、证据或动作；短篇可用意象回扣，不强求解释异常来源 | ending §一–二 |
| 一句话复述 | 结尾能用一句话复述；长篇的主要因果必须讲通，短篇留白不得遮住已发生事件 | ending §一–五 |
| 落点 | 落在物件或动作上 | ending §六 |
| 最后一击 | ≤15 秒，说完就切 | ending §六 |
| 反应 | 关掉声音看，起鸡皮疙瘩或鼻酸就过 | ending §六 |

> 2026-11-11 用户删除四条：不解释机制、不转温情、不给“从此安全”/威胁仍在、最后 3 秒留声音或空镜；`ending.md` 已升 v3。

## 五、当前冲突 / 待拍板

1. **温情恐怖**：`ending.md` v3 已删“不转温情”与“威胁仍在”，不再冲突；还剩平台尺度（孩子死亡算不算虐童）与老帖曝光度两条要定。
2. **原创档**：`input-spec` §3 仍保留 `original` 这一档；但你 2026-11-11 明确“不要通过原创”绕过源头。
   - 现行执行：必须有原帖链接，原创不能作为准入理由；
   - 建议：把 `original` 限定为“你逐条确认后的独立原创”，否则从准入里删掉。
3. **授权硬停**：`input-spec` §7.1 要求许可；但你 2026-11-09 说“授权的事我会搞好”，现行执行是“记 `authorization-pending`，不阻塞结构，许可由你闭环”。
4. **孩子死亡**：Milk and Cookies 这类最容易哭，但 recommendation §2.1.4 把“虐童”列为不列；孩子意外死亡算不算“虐童”，没有定义，需要你给一句边界。
5. **老经典 vs 曝光度**：越能哭的故事越老、越可能被搬运；现行“中文曝光度多的一律不进”会把 Milk and Cookies、Auntie Bells 这类挡掉。是否允许“老帖 + 重写度高”破例，需要你定。

## 六、一句话总结

现行标准 =
**知乎优先且原文可核验 + 中文没人做透 + 单集按故事需要定长且不超过 25 分钟 + 不碰血腥/虐童/自杀/真实案件 + 1 主 1 次悬念 + ≤3 条规则 + ≥3 条物证 + 短篇可留白但线索可理解、长篇因果闭环并回收前文。**

温情恐怖已不受 `ending.md` 限制；孩子死亡与老帖曝光度仍需你定边界。
