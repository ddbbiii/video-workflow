## 二、结论

**v1 把"写实"按下去了，但没给出"特色"；v2 的专色是唯一在缩略图上还成立的签名；v3 修掉了 v1/v2 的副作用，代价是气氛被削平。**

判据是缩略图（每格 300px，见 `thumb-260.png`）：

- v0 列：柔光、青灰、体积感，标准"番剧背景美术"，缩略后认不出作者。
- v1 列：墨线与平涂立住了，硬边出来了；但整组偏绿，灯泡还在发光。
- v2 列：A1 黄凳、C1 红绳是整张图里第一眼看到的东西——**这就是签名**；B2 的暖光和专色混在一起，"唯一彩色"不成立。
- v3 列：冷灰蓝干净了，红点统一了（A1 凳、C1 绳、D1 桶、B2 电表指示灯）；但 C1 发白发灰、B2 整体偏亮（lum 96），恐怖感被抽走一截。

## 三、必须记住的三个副作用

1. **"screen-printed"在模型那儿只是一层滤镜。** v1/v2 的灯泡周围仍有光晕和渐晕，地面仍有明暗过渡；不加"no glow / no halo / light is a flat shape"这类明确禁止，体积光不会自己消失。v3 就是靠这三句修掉的。
2. **换风格块会降低构图约束力。** B2 四版里没有一版保持原机位（走廊尽端、人物右三分、门后楼梯）；新风格下模型更愿意"重新取景"。正式集要重锁锚点、留更多重抽预算。
3. **`mean_sat` 不能当"低饱和"的判据。** v3 的 A1 sat=50，比 v0 的 34 还高——因为红凳把均值拉上去了。低饱和要按"除专色外"分区测，或干脆人眼判。

## 五、建议

1. **基底锁 v3**：冷灰蓝 + 墨线 + 平涂三阶 + 灯是哑光白 + 每帧只有一个红点（红点跟着证据走）。
2. **补一个结构装置，否则仍只是"精致的滤镜"。** 三选一，成本都是 4 张 ≈ 0.07 元：
   - **A 纸感错版**：纸纤维 + 套印偏移 1–2px（risograph 味，动态下比网点稳）；
   - **B 阴影粗网点**：只压阴影区，点径 ≥6px（1080p 下不闪），近景/特写专用；
   - **C 墨边**：每帧四周压一条不规则墨边，像印刷页裁切。
3. **锚点要重做**：现有三视图是柔光赛璐璐，套进印刷风会打架（B2 已见）。重做只需 1 张 2×2 拼版/主角。
4. **2×2 网格不要用于新风格**：网点 + 828px 单格必然糊。

## 六、B 方案：阴影区粗网点（2026-11-15 追加）

用户选定 B。先按"烘焙进提示词"出了 4 张（v4 = v3 + `coarse halftone dots in shadow areas only`，dot ≈6px）：

- 出图：网点确实落在墙上、门上、暗部，红凳/红绳仍是唯一彩色；比 v3 更像印刷品。
- 但**网点不是只在阴影**：模型把中灰墙面也铺满点，等于整幅加了一层印刷纹理。
- 实测点距 **6.0 px**，与要求一致。

### 关键风险：烘焙网点会爬纹

用 0.4% / 0.8% / 1.2% 的亚像素推近模拟慢推（`motion_risk.py`，取墙面平坦区）：

| 版本 | 高频能量 | 0.4% 推近后像素差 |
|---|---:|---:|
| A1-v3（无点） | 380 | **3.75** |
| A1-v4（烘焙点） | 2800 | **13.29**（3.5×） |
| A1-v3-post（后期点） | 657 | **4.59**（1.2×） |

烘焙网点每推进 0.4% 就重采样一次，点阵被打散；后期网点固定在输出网格上，不随镜头动。

### 结论：B 成立，但必须放后期

`post_halftone.py`：屏幕空间 AM 网点，只压暗部（阈值 lum<0.38、点径 9px），并且**保护饱和像素**——专色不印点。

- 烘焙版：网点满地、爬纹 3.5×，只适合静帧/定帧。
- 后期版：点只在阴影，红点干净，爬纹 1.2×，可动。
