# 怪物造型方向测试

本批为造型方向草图，不是正式分镜素材。视觉结果偏厚涂，正式镜头仍需回到悬疑线赛璐璐风格规则。

| 文件 | 方向 | 设计重点 |
|---|---|---|
| `01-drainage-composite.png` | 排水淤泥拼接体 | 湿发、污泥、旧衣料形成贴地的人形 |
| `02-long-arm-crawler.png` | 贴地长臂型 | 先以长臂抓袖口，再显露伏地轮廓 |
| `03-stolen-voice-material.png` | 取材模声型 | 抓取布料后贴近喉部，脸部像未完成的声音面具 |
| `04-wrong-joints-mouths.png` | 错位关节型 | 反向折叠的四肢与重叠嘴形，突出模仿不准确 |
| `05-multi-mouth-edit.png` | 拼接体 + 多嘴 | 基于 01 编辑，保留贴地姿势和排水淤泥主体，在脸、颈侧、肩背增加多张不对称的人嘴 |
| `06-face-only-multi-mouth.png` | 全新文本概念：脸部多嘴 | 不使用参考图，融合淤泥拼接体与错位关节；所有额外嘴仅位于脸部 |
| `07-dreadful-face-mouths.png` | 加重恐怖感：畸形脸部多嘴 | 纯文本生成，强调湿发遮挡、压低机位、腐败质感和挤压错位的脸部嘴群 |

共同提示词方向：成熟简化赛璐璐动漫、低饱和冷灰蓝、旧地下室、潮湿材质、单幅横构图；恶心压迫但不露骨血腥。正式视觉规则中的怪物禁项仅在本次概念探索中临时越过。

05 编辑提示词：保留原图怪物身份、整体姿势、湿发、排水淤泥身体、前景伸出的手、地下室排水口、光线、配色、漫画插画风格和构图。在脸部、颈侧和肩背增加至少五张大小与形状不同的人嘴：脸颊一张、颈侧两张、肩背不规则分布两张；嘴唇不匹配、少量参差牙齿，部分闭合，一张微张像正在说话。嘴要融进潮湿皮肤和污泥，不悬浮、不对称排列。保留贴地爬行姿势，让一处手肘和一处膝盖轻微反向弯折。恶心诡异但非露骨，不出现开放伤口、血液或内脏；不加额外肢体，不改场景、不裁切，不加文字或水印。

06 文生图提示词：全新怪物概念，不使用或模仿任何现有参考图。成熟简化赛璐璐动漫漫画，平涂色块、硬边阴影、干净墨线、低饱和冷灰蓝，受控暖光。旧公寓地下室积水中，一个由溺亡残骸、黑色排水淤泥、湿发和浸透工作服碎片构成的贴地爬行人形；躯干低伏，手肘和膝盖轻微错位反折，双臂向前伸。怪物只有一张可辨认的脸，额外嘴全部长在脸部范围内：五张大小不一、形状不匹配的人嘴，分布在脸颊、下颌和额头，部分闭合，一张微张像在说话；没有嘴长在颈部、肩膀、背部、手臂、躯干或腿上。嘴融入潮湿皮肤，嘴唇不齐，少量参差牙齿；恶心诡异但非露骨，无血、伤口或内脏。三分之四侧视，全身轮廓清楚，背景可见地漏、水渍、起皮墙面和发黄塑料凳。避免照片写实、3D、CG、油亮皮肤、卖萌比例、血浆、身体其他部位长嘴、额外人脸、文字、水印、拼贴。

07 文生图提示词：纯文本创作全新怪物，不使用或模仿参考图。成熟赛璐璐恐怖漫画，密集墨线、硬边阴影、炭灰、冷蓝黑、污灰色，只留微弱病黄灯光。积水老公寓地下室里，一个由溺亡残骸、凝结黑色排污泥、湿发和腐烂工作服组成的低伏爬行怪物，沉重宽阔，紧贴湿地面，四肢长短不齐且关节以令人不适的角度错位弯曲。怪物低头，头几乎被湿发和污泥埋住；脸部畸形、不对称、压扁、被遮挡，不俊美、不干净，浑浊不一的眼睛。多张额外人嘴只长在脸部，挤在额头、脸颊和下颌，嵌入不规则错位，大小不同、方向歪斜，部分封闭、部分微张，其中一张张得更大像在尝试说话；湿白嘴唇、参差小牙、深色口腔，像拙劣复制的人脸特征。颈部、肩背和身体其他部位绝不长嘴。通过潮湿、腐败和错误解剖产生强烈压迫与恶心感，不出现露骨血腥、喷溅血液或外露内脏。贴近地面的低机位三分之四视角，怪物占据前景但爬行全身轮廓仍清楚；旧地漏、积水、剥落墙皮、锈管可见。避免美型、漂亮脸、对称脸、干净人像、化妆特效感、整齐排列的嘴、照片写实、3D、CG、油亮皮肤、卖萌比例、血浆、文字、水印、拼贴。
