## 这版的物理模型

- 土豆不是脚本路径，而是**约束在同一条阶梯表面上的圆**：位置用弧长 `s` 表示，速度沿切向，重力按切向分量作用。
- 相邻土豆发生**一维冲量碰撞**：按质量、恢复系数交换速度；撞击后目标土豆先保持 4 秒，再被释放，形成接力。
- 土豆沿路径位移产生**角度**，渲染时贴图旋转，形成滚动。
- 撞击时间来自仿真事件，再构建 0.75x 时间轴；音效/镜头/慢放都对真实碰撞。
- 土豆数量 `STEPS` 参数化；10 个和 3 个共用同一套碰撞逻辑。

## 当前不足

- 这是**轨道约束**，不是完整 2D 刚体；能保证不跨台阶、不跳过，但接触处的挤压/分离还比较粗糙。
- 撞击时两个土豆仍可能重叠；目标土豆释放后的速度需要再调。
- 阶梯线目前整体清晰；参考里“线随深度变糊”还没做分段模糊。
- BGM 是占位合成节拍，撞击音效是占位合成 potato。

## 运行

```bash
python make_staircase.py
```

依赖：Pillow、numpy、ffmpeg（NVENC）。

## 实测

- 单次完整渲染（42.4s / 2544 帧）：本机 wall-clock 约 **40 秒**。
- 10 个土豆与 3 个土豆共用同一套逻辑，Token 不随数量线性增长。
