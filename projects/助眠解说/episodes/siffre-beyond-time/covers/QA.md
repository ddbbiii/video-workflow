# QA｜siffre-beyond-time 封面（covers/）

- 日期：2026-10-20
- 概念：黑暗中一点暖光（本集母题②"那盏灯"）——近黑深青蓝空间 + 单一琥珀光点，大量留白。
- 规范依据：`rules/shared/visual/cover-and-intro.md`（封面硬约束）、`rules/shared/memory/sleep-aid-visual-style.md`（深青蓝夜色+琥珀暖光、画面内禁文字）。
- 文字全部为 PIL 独立排版层（`layers/<id>/*.png`），生图画内零文字（API prompt 明令 no text/letters/watermark，四张目检复核无伪文字）。

## API 生图

- 模型 `gpt-image-2.5-sunburst` @ `https://dklapi.com/v1/images/generations`。
- 密钥：任务指定 `IMAGE_RELAY_KEY_1V`，该变量在 bash 与 Windows 用户/机器环境均不存在；脚本回退到仓库既有约定 `IMAGE_RELAY_KEY_1K`（与本集 runs/20261018-sbt-b01 静帧生图同一端点同一密钥族），已正常出图。
- **实际调用 4 次（预算 6），零重试、零补救**：h-a/h-b 尺寸 2048x1152（16:9 原生），v-a/v-b 尺寸 1152x2048（9:16 原生，API 接受，无需裁切）。
- 脚本：`gen_bg.py`（`bg/manifest.json` 记录逐张 QA）。
