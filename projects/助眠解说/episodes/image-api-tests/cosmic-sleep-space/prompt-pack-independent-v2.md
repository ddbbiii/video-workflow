### A02 三环空间站

### A03 冰卫星地貌

### A04 极光边缘

### A05 稀薄星云

### A06 远处彗星
深空超远景，唯一一颗低亮度彗星位于右上，占画面很小，短而淡的透明尾迹斜向左上延伸。摄像机静止，左下有极淡紫蓝星云，其余为黑色深空与少量星点。彗核不出现火焰，不靠近任何行星，不画成巨大流星雨或运动模糊。

### A09 遥远的行星
