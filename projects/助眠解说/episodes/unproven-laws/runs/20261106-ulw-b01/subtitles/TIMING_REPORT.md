# 字幕时间轴复核（2026-11-06）

## 方法

1. 以 `narration_body.wav`（无 BGM 母带）为基准，逐条 cue 用 FunASR 重新识别起点窗与终点窗，取实际字级锚点。
2. 起点取该句前 2–4 字的识别起点，终点取末 2–4 字的识别终点；匹配失败保留原值。
3. 相邻 cue 单调化，切换点吸附到真实静音起点。
4. 用能量包络独立复测（不依赖 ASR）得到起点滞后中位数 180 ms，统一前移 120 ms 作补偿。
