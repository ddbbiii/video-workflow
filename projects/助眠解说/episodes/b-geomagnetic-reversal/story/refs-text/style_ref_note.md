# 老大给的风格参考（2026-10-01 10:52 北京时间）
来源：老大私聊发来的抖音视频「睡与深空」全文（讲费米悖论/哈特论文，约 90 分钟版），只作风格参考，不复制原文句子。
全文保存在老大的聊天记录里，这里只记风格要点：
- 开头：一句反常识结论做钩子，再预告时长和主线问题。
- 推进：具体人物 + 论文 + 年份，带争论和反转（谁先下结论、谁算出同一笔账却保持开放）。
- 叙述者用第一人称「我」，有「我查资料时发现…」式的真实思考，偶尔抒情一句。
- 结构：把长内容拆成「三笔账」之类的骨架，先预告再逐笔展开，每笔结尾小结。
- 比喻日常化（派对、账单、装修中的宴会厅、太平洋舀一杯水）。
- 假说当场标明「这只是假说，没有证据」。
- 信息密：几乎每句都带一个事实或推理步，很少纯氛围句；段落间用设问衔接。
- 结尾：回到人类自身，温柔收束，「晚安」。
- 节奏：老大要求约 25–30 字/10 秒（不严格），图不用密，开头一句一图。
