# 真实图生视频比例计划

更新：2026-10-06。此计划只约束当前由本助手负责的《地球的磁场会翻转》视觉重制，不改变其他助手或其他线路的默认规则。

## 目标

- 全集 63 个镜头中，真实图生视频目标调整为 **约 13–19 个**，约占 20–30%；高清图片 + affine 是正式默认。
- 其余镜头使用静态图、affine 运镜或受控后期动画。
- 真实视频候选必须保留原图构图和科学事实；出现新增物体、数量变化、几何变形、文字伪影、闪烁或事实表达改变时淘汰，回退静态/受控方案。
- 图生视频只负责自然内部运动或真实镜头变化，不负责精确磁极方向、地图路径、实验数量、公式和标签。后者继续用受控图层。

## 首轮候选分层

### A 类候选池：优先做真实视频（最终从中选择 13–19 个）

这些镜头有自然运动来源，且运动不需要改变科学结构：

`c04, c07, c08, c09a, c09b, ch2-c03, ch2-c04, ch2-c06, ch2-c08, ch3-c03, ch3-c04, ch3-c05, ch3-c07, ch3-c08, ch3-c09, ch4-c03, ch4-c08, ch4-c09, ch5-c02, ch5-c03, ch5-c04, ch5-c05, ch5-c06, ch5-c07, ch5-c08, ch5-c09, ch6-c02, ch6-c03, ch6-c04, ch6-c07, ch6-c09`

典型运动包括火焰、烟雾、海浪、云层、极光、人物微动作、液态金属、地球缓慢转动和稳定轨道运动。`c09a`、`c09b`、`ch3-c05`、`ch6-c07` 属于高风险候选，需重点检查主体身份和几何稳定性。

首轮优先队列（16 个，仍需逐批验收，不代表全部最终采用）：

`c04, c07, ch2-c03, ch2-c04, ch2-c08, ch3-c03, ch3-c07, ch3-c09, ch4-c03, ch4-c08, ch5-c02, ch5-c06, ch5-c07, ch6-c02, ch6-c03, ch6-c09`

首轮暂不生成 `c08`、`c09a`、`c09b`、`ch3-c05`、`ch6-c07` 等高风险镜头，除非低风险批次证明工作流稳定且仍需要补足比例。

### B 类：可用真实视频，但先做短样片（目标 8–12 个）

这些镜头有运动潜力，但容易改变事实或结构：

`c01, c02, c06a, c06b, c14, ch2-c01, ch3-c01, ch4-c01, ch4-c04, ch4-c06, ch4-c07, ch5-c01, ch6-c01`

优先只允许微弱环境运动、亮度变化、云层或场线的受控变化；不允许模型自行改变指针方向、极点数量、卫星数量或磁力线拓扑。若模型无法保持这些约束，改用静态底图加后期动画。

### C 类：默认静态或受控动画（约 18–25 个）

`c03, c05, c10, c11, c12, c13, c15, ch2-c02, ch2-c05, ch2-c07, ch2-c09, ch2-c10, ch3-c02, ch3-c06, ch4-c02, ch4-c05, ch6-c05, ch6-c06, ch6-c08`

这些镜头包含精密示意、层理/样品对比、对称条带、地图或数量事实。若需要动态感，使用受控图层、局部亮度或 affine 运镜；不把模型生成的随机变形当作科学变化。

分层不是最终硬编码：若候选样片失败，直接回退高清静态图 + affine，不为凑比例牺牲清晰度或事实稳定性。真实视频比例只作为上限参考，不是必须完成的配额。

## 执行批次

1. 每批 3–4 个横屏、5 秒左右样片，使用同一 LTX-2.3 工作流和独立输出目录；每批开始前提交 GPU 队列请求，获准后才运行。
2. 按首轮优先队列验证自然环境、火焰/烟雾、水面、云层和液态金属，暂缓高风险人物/仪器/卫星运动。
3. 每批检查完整解码、首尾连续、主体变形、数量/方向保持、闪烁、亮度跳变和画面是否仍符合旁白。
4. 合格镜头再延长或按配音时长生成；不合格或有争议的镜头保留视频输出并明确标记、汇报，但正式成片默认回退 affine，不覆盖底图。
5. 最终建立逐镜 manifest，记录 `mode=real_video|controlled_animation|affine|still`、模型、seed、prompt、QA 结论和回退原因。

当前已完成的 3 个样片（地球、罗盘灯焰、矿井人物）保留作质量对照；它们已证明真实视频会牺牲高清细节，不代表应扩大到大多数镜头。
