# 助眠解说 · 项目入口

## 目录

- `episodes/`：单集。
- `characters/`：角色资料。
- `assets/`：资产索引和参考资料。
- `drafts/`：未锁定草稿。
- `logs/`：运行记录。
- `archive/`：旧版本与暂停内容。

## 交付

每集只交 `video/final/助眠_<中文剧名>_正文_vN.mp4` ＋ `video/srt/` 同基名 `.srt`。
不产片头、配音、混音、BGM、字幕烧录、封面、成品库。

目录布局见 `../../indexes/DIRECTORY_STRUCTURE.md`；资产验收以项目状态和 manifest 为准。
