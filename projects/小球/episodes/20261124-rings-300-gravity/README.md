## 选择依据

实际比较了多档向下重力。同一初态下，代表性结果如下；表格仅说明当前轨迹，不表示重力越大结果单调变化。

| 重力 | 完成 300 层 | 最长穿层等待 | 下半场停留占比 |
|---:|---:|---:|---:|
| 0（基线） | 159.35 秒 | 13.31 秒 | 50.0% |
| 80 | 138.68 秒 | 29.63 秒 | 50.2% |
| 140 | 199.80 秒 | 30.90 秒 | 50.1% |
| 220 | 220.34 秒 | 31.83 秒 | 53.3% |
| **240** | **161.94 秒** | **12.64 秒** | **55.2%** |
| 320 | 293.69 秒 | 20.96 秒 | 55.2% |

选 240 是在下坠效果、完整时长与等待之间取折中，不是选最快通关的参数。以基准速度 430、内圈半径约 205–225 计，重力曲率尺度 v²/g 约 770，约为内圈半径的 3–4 倍，属于适中的弯曲。

若无其他力且飞行 0.5 秒，240 的额外下坠为 30 个场景单位；但当前有连续速度调节，实际轨迹并非严格抛物线。保留原 `speedRelaxation=2`，逐渐向基准速度回调，也保留移动圆环做功，所以不能把本版称作纯重力、严格能量守恒模拟。这里的单位不是米/秒²，不与地球 9.81 直接比较。

本次没有改变缺口或调初态来保证成功；在选定单一固定初态下选参数，没有验证全部随机开局。不同重力造成后续碰撞顺序分化，不宜仅用总通关时间判断物理好坏。
