# 阶梯接力：渲染对照测试稿

状态：待用户确认；确认前不进入候选视频渲染。

## 测试目标

用同一组 Pymunk 轨迹，比较三种画面实现：旧式 Pymunk + Pillow 基线、改进版 Pillow、Pymunk + Motion Canvas。比较只针对渲染层，不更换物理模拟。PixiJS 暂不列入首轮，除非前述方案无法达到画面要求。

## 一句话故事

一颗橙色球沿阶梯滚下，依次撞动蓝球和黄色球，最后一颗球落进阶梯底部的杯中。

## 画面约束

- 竖屏 1080 x 1920，30 fps，约 15 秒；固定机位，一镜到底。
- 同一套阶梯几何、三颗球的尺寸与材质、球体轨迹、灯光方向、阴影范围和杯子位置，供每种方案使用。
- 场景为简洁的实体小球与阶梯，不出现文字、标题、logo、水印或 UI。
- 重点观察球体接触边缘、碰撞瞬间的轻微挤压感、接触阴影、阶梯远近层次和连续运动是否稳定。
- 物理轨迹由同一份 Pymunk 模拟结果提供；渲染器不得自行改球的位置、碰撞时刻或结局。
- 正文视频静音；独立 SRT 仅供用户后续配音，不烧录进视频。

## 镜头节拍

| 时间 | 画面 / 动作 | cue |
|---|---|---|
| 0–2 秒 | 画面完整展示阶梯、橙球、蓝球、黄球与底部杯子。三球静止，观众能看清路径与终点。 | 这场阶梯接力，能成功吗？ |
| 2–6 秒 | 橙球从顶端滚下，逐阶碰撞，在中段撞上蓝球；橙球停在中段缓冲位，蓝球沿阶梯继续下滚。 | 橙球滚下，撞动蓝球。 |
| 6–10 秒 | 蓝球撞上黄色球，黄色球改变方向，向底部杯子滚去；接触瞬间清楚可见，不遮挡球体轮廓。 | 蓝球又把黄色球撞了出去。 |
| 10–13 秒 | 黄球落入杯中，杯子轻微晃动后停稳。 | 最后一颗，落进了杯子。 |
| 13–15 秒 | 所有物体完全静止，保持终局构图。 | 三颗球，各自停稳。 |

## 连续性与物理要求

- 橙、蓝、黄三球从头到尾保持颜色、半径和材质一致。
- 每次碰撞必须可见前后因果：接触前有间隙，接触时轮廓相交不穿模，接触后被撞球获得速度。
- 不允许球无接触突然变向、瞬移、变形或穿过阶梯。
- 结尾杯中只有黄色球；橙球停在中段，蓝球停在下段阶梯。
- 如果 Pymunk 参数无法自然实现指定节拍，先调整轨道/碰撞参数并锁定唯一轨迹；不得在不同渲染方案中各自补动画。
