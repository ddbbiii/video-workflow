## 长轨迹调整

原 C 的长跑出现移动墙持续做功、速度失控和远离近景的问题，因此本次采用连续速度稳定器，逐渐向基准速度 430 回调；不在碰撞瞬间强制归一，不加入任意转向或脱困偏置。它是明确的游戏化规则，不声称严格能量守恒。采样速度实际约 255–766。

相对原 C：补入速度 35→100，转速 0.42→0.6，缺口宽度 0.68→0.85 rad，层间错位 0.1→0.06，缺口波动幅度 −0.3→−0.15，物理频率 1200→4800 Hz。其余球半径 10、环间距 10、初始内径半径 225、半径下限 205、零重力、初态位置与方向等保留。精确真源为 [config.json](simulation/config.json)。

镜头固定中心、不横移追球；根据活动圆环和球的空间范围预计算平滑缩放，带离线前瞻，防止集中穿层后出画。球径约 22.5–37 px；低于 26 px 的区间约 2.08 秒，低于 30 px 约 9.08 秒，绝大部分仍维持近景。外圈可出画，当前球体全程完整在画内。

完整保留等待、折返和突破，不裁切、不变速。最长两次穿层间隔约 13.31 秒，位于 145.98–159.29 秒，末段等待是否过长需用户判断；不能声称全程紧凑。

## 复现

从工作区根目录依次运行：

```sh
node projects/小球/episodes/20261124-rings-300-sfx/scripts/prepare.mjs
shared/runtime/librosa/bin/python projects/小球/episodes/20261124-rings-300-sfx/scripts/audio.py
node projects/小球/episodes/20261124-rings-300-sfx/scripts/render.mjs
python3 projects/小球/episodes/20261124-rings-300-sfx/scripts/qa.py
```

预生成轨迹是画面、相机和两类声音的共同时间源。依赖当前工作区已有 Playwright 与隔离 Python 数值环境，不依赖原试听片音轨或配乐。
