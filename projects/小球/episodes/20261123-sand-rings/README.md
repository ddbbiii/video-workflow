- 完整性：1000 个实际逻辑层全部耗尽，层号连续且无重复；677 次有效反弹。1000 次穿层分别触发 1000 次 `老吴_07.wav`；原速、原音高、完整重叠，不漏播、不合并事件，不剪短；最多 83 声同时叠加。统一降低增益防止爆音。
- 视觉：密集彩色圆弧、逐层错位旋转缺口、发光方块与拖尾、穿层后沿原弧分布的颗粒。固定缩放 0.72，通关前方块始终在画面内。
- 限制：方块仍使用包围圆作保守碰撞边界，旋转为视觉动画，并非完整角点刚体模拟；碰撞后恒速是明确的美术运动规则，非严格能量守恒。粒子不参与刚体碰撞。尚未接入 Motion Studio。

## 可调设置

运行 `node preview.mjs` 打开其返回的本地地址。面板提供开局编号、圆环层数、弹射速度、补入速度、缺口宽度、旋转速度、起点随机范围；“换个随机开局”重新生成全程，“应用设置”使用所填编号重算。调整只影响交互预览，已导出 MP4 不随之改变。

批量渲染的配置真源是 `simulation/config.json`。依次运行：

1. `node simulation/generate_trace.mjs`
2. `node audio/render_sfx.mjs`
3. `node renderers/canvas/render.mjs`
4. `node audio/render_music_mix.mjs`
5. `node qa/validate.mjs`

音乐混音脚本以 `video/candidates/sand-rings-1000-laowu.mp4` 作为画面与穿层音效底片；该底片需先按前 3 步生成。当前试听沿用早期版本的方块球、固定缩放和圆环视觉，主要用于判断连续音乐与阶段混音是否符合预期。

脚本复用工作区现有 Playwright。图像、音效、轨迹和配置保存在本单集。
