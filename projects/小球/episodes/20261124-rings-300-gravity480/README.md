# 300 层重力翻倍试听

状态：重力从已认可的 240 翻倍到 **480 场景单位/秒²，向下**。本次是单变量试验，待用户审看后决定是否替代 240 默认参考。

用户于 2026-11-24 明确要求“持久化一下，改一下我们的规则……向下的力还不够，翻倍试一下”。现行规则已写入 `rules/小球/`；480 未自动升为默认。

- [完整试听](video/小球_300层_向下重力480.mp4)：1080×1920、60 fps、14637 帧、243.95 秒（约 4 分 4 秒）。
- 300 层在 243.297 秒穿过，音效按新事件重建：300 次穿环、332 次记录碰撞。
- 只改 gravity 240→480，其他配置、初态、速度回调、相机算法及音效设计不变。模型仅修正频率注释，不改求解行为。
- 完整保留等待，不剪辑、不加速；施加重力翻倍不等于最终合加速度翻倍，因连续调速和碰撞仍参与运动。不是理想抛物线或地球重力模拟。
- 相比 240，完成时间增加约 81.36 秒，不能宣称节奏全面改善。成片最低球径约 17.4 px，低于 24 px 约 1.43 秒，主要出现在逃出尾段，并非整片变远；这次不改镜头掩盖单变量结果。最长穿层等待约 32.44 秒（46.50–78.94 秒），明显长于 240 版。
- 当前轨迹检测 0 出画、0 剩余嵌入，碰后分离通过；290 次记录内壁碰撞、42 次端点碰撞。事件记录有 25 ms 去重。
- [物理检查](qa/physics.json)、[声音事件](audio/cues.json)、[编码与解码检查](qa/media.json)。未声称主观听音验收。
- 最终完整解码通过，无持续 1 秒以上黑场/冻结，AAC 真峰值约 −2.4 dBFS；全片联系表与关键帧已目检。632 次音效与事件匹配，尾音完整。
