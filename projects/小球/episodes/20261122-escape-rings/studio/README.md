# 单集 Studio 数据

本目录保存本期单集清单与 Motion Studio 写入的数据，不包含桌面软件源码。

- `episode.json`：遵循小球线产出规范的单集清单；指定模型适配器、轨迹、默认参数与输出规格。
- `project.json`：Motion Studio 保存的用户设置与素材索引。
- `assets/`：本期导入的图片和音频。首次用 Motion Studio 打开时会放入默认球体贴图与背景图。
- `previews/`：Studio 生成的预览成片。

Motion Studio 的源码与安装包由独立项目维护，索引见小球线入口 `projects/小球/README.md`。
