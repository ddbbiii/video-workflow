# 物理动画桌面工作台：唯一技术方案

状态：工作台正在按小球线 `VIDEO_OUTPUT_SPEC.md` 接入严格清单协议；当前适配十重圆环案例。

## 产品边界

桌面工作台负责素材导入、单集参数调整、轨迹预览、视频生成、任务进度、取消任务和项目配置保存。每期的物理模型与特殊动画继续由该期工程实现。第一版不是通用时间线剪辑器，也不能把任意剧本、源代码或 `.motionpkg` 直接拖进去执行。

## 技术选型

- 桌面壳：Electron，内置 Chromium，当前构建 macOS Apple Silicon 与 Windows x64 包；Intel Mac 构建可单独生成，当前未交付。
- 界面：Vite + React + TypeScript；面板与渲染进程均在本机运行，不调用按次计费服务。
- 本期视频绘制与导出：Motion Canvas；运动轨迹由独立 Matter.js 模拟预先生成，Motion Canvas 不修改物理结果。
- 视频与音频：随应用打包 FFmpeg/FFprobe；本期默认按 60 fps 输出，项目帧率、帧数由单集清单提供默认值并可在高级设置覆盖；导出后依据本次设置验证并完整解码。
- 状态与素材：选择单集源目录后，项目配置、导入素材和预览文件保存在该源目录的 `studio/`。

## 当前工作台

- 左侧：拖入或选择 PNG/JPEG/WebP/GIF 图片与常见音频文件，图片可指定为球贴图或背景，音频可指定为撞击音效。
- 中央：十重圆环轨迹播放、播放头、时间轴事件标记和导出视频预览。
- 右侧：回放速度、球体统一样式/尺寸、拖影、背景色、撞击效果和音效调整；球体设置应用于当前场景中的所有球体。
- 顶部：保存项目、撤回/重做和生成预览；支持 macOS `⌘Z`/`⌘⇧Z`、Windows `Ctrl+Z`/`Ctrl+Y`，按钮与快捷键共用最多 100 步的会话历史。连续滑杆拖动合并为一步；保存点可继续撤回，恢复到保存状态时清除未保存标记。
- 任务状态：渲染显示实际可取得的进度，否则使用活动指示，不伪造百分比；任务可取消。
- 实时预览和成片渲染复用同一份含固定随机种子的物理轨迹；渲染帧率高于轨迹采样率时按相邻状态插值。
- 速度和球体尺寸支持手动输入；输出帧数和帧率位于折叠的输出设置中。

## 操作和文件

启动对应平台的 Motion Studio 应用，打开符合小球线视频产出规范的单集源目录，导入素材后选择用途，调节面板，点击“生成预览”。项目参数写入 `studio/project.json`，素材写入 `studio/assets/`，MP4 写入 `studio/previews/`。

单集导入清单为 `studio/episode.json`，字段约束见线路级 `projects/小球/VIDEO_OUTPUT_SPEC.md`。当前打包应用只接受匹配的 `matter-ring-escape-v1` 适配器；其他物理模型须先开发并打包对应运行时，不能通过清单伪装成兼容单集。

## 已知限制

- 当前 Windows 交付为 x64 免安装 ZIP，未在真实 Windows 设备上启动验证；macOS 包未签名/公证，操作系统可能显示首次打开提示。
- Windows ZIP 体积约 500 MB，内含 Electron、Motion Canvas 依赖及 FFmpeg/FFprobe。
- 项目和素材仅保存在本机，不提供云同步、用户账号、多项目管理或跨电脑自动迁移。
- 面板参数只作用于当前固定案例；碰撞分裂数等本期不存在的物理规则不会显示成通用控件。
- 尚无通用 `.motionpkg` 导入器、源代码编辑器、后台任务队列或安装程序。撤回历史只保留在当前应用会话，不跨重启保存。

## 后续扩展约束

新单集接入时，先明确本期 controls、素材槽、参数作用方式、模拟与渲染适配器以及任务前校验。仅把确实跨案例通用的工作台能力抽象出来；不会把每期独有的碰撞或拖影强行变成全局设置。
