# 小球流沙圆环：镜头与碰撞试片

当前视频：`video/candidates/ball-physics-test.mp4`，约 16.02 秒、1080×1920、60 fps，Canvas；1000 层逻辑场景，短测不代表完整通关。

## 当前行为

- 开局编号 1873287513，穿过 232 层，记录 16 次碰撞，其中 14 次方向变化超过 45°。当前开局未触发游戏化脱困。
- 圆环颜色逐层平滑变化；2160×3840 离屏绘制后缩小至成片尺寸。屏幕间距过小时，细线渐隐，连续宽色带渐入，保留缺口几何。该处理牺牲远处逐线分辨率，减少高频纹理；实际摩尔纹仍需结合播放器尺寸评估。
- 镜头开局缩放 1.45，仅在穿层完成后更新拉远目标，0.10 秒时间常数平滑跟进；连续穿层合并目标，不因普通碰撞拉近或反复呼吸。根据穿层半径及短期运动包络留出安全空间。此试片末段缩放约 0.371。
- 小球半径 15、层间距 8、恢复系数 0.985；旋转端点计入切向速度，圆弧内部计入径向收缩速度。每个物理子步收集接触面，按估计碰撞先后排序，迭代处理共同约束；同一表面在一个子步内只施加一次弹性恢复，减少重复加速。仍是 1200 Hz 离散求解，并非完整连续碰撞检测。
- 仅连续浅角度接触才启用辅助折返，不再对普通向外端点撞击直接转向中心。速度在飞行中逐渐趋近 600 px/s，系数 1.2/s；无撞后恒速归一化。仍含游戏速度调节及脱困兜底，不是纯被动物理。
- 撞击两侧分别插值，拖尾在撞击处断开；按冲量显示短闪光、火花及 80 毫秒轻微挤压回弹。没有新增碰壁音效或镜头震动。
- 缺口约 58.4°，层间相位平滑推进 0.025 rad、宽度起伏 ±6%，全部同速旋转；补入 105 px/s，最小内圈半径 165，不按球墙距离暂停。
- 每层一次老吴_07，允许叠加；无 BGM。流沙颗粒仅作视觉效果。

## 验证范围

`node simulation/validate.mjs`：102 个种子的 16 秒短测通过实体边界穿越检查、采样嵌入及镜头安全范围检查；固定种子可复现，镜头目标更新均由穿层事件触发。当前开局连续近墙浅角度运动最长约 0.067 秒，102 个种子最长约 0.383 秒。详情见 `qa/physics.json`。这些结果不保证任意自定义参数及完整千层通关。

重现：依次运行 `node simulation/generate_trace.mjs`、`node simulation/validate.mjs`、`node audio/render_sfx.mjs`、`node renderers/canvas/render.mjs`。运行 `node preview.mjs` 可交互修改种子后应用设置。
